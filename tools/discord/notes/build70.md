# BIBLE puts PS2BBL on your memory card, the controls follow your thumbs, and the orbs now run all night. Real PS2s wanted: here is what to try.

## Boot Lock and BIBLE
- **Settings > General > Boot Loader > Manage** shows what each memory card starts at power on (PS2BBL, FMCB, OSDMenu).
- **BIBLE** is El Isra's PS2BBL 1.2.0, set up by RIPPS2: no wait at power on, RIPPS2 first. It installs on the card you pick; whatever was there before is kept, and CIRCLE at power on still starts it.
- Boot Lock only edits a real PS2BBL now, and cleans up the file build 68 wrote for FMCB cards.

## Controls
- **L1 / R1** switch Launch Disc, Storage and Memory Files from anywhere.
- **Left / Right** switch drives on Storage and the info page, and orb formations on Memory Files.

## Memory Files
- **Orbit Settings** (START grid): cycle, speed, path lines, height, and which formations are in use, all live.
- **HDD Manager** is Square on an APA hard drive: fast now, and removing a partition takes two screens.
- Drives have real names (USB, MX4SIO, iLink, exFAT HDD), and **START DRIVES** starts them whatever Storage's start modes say.
- The orbs, towers and CD visualiser no longer break after 72 minutes: leave it on overnight.

## Discs and PS1
- The CD player takes any CD with sound tracks (CD-Extra, mixed mode, burned CDs).
- The POPSTARTER path fills itself in from a POPSTARTER.ELF on your drives. Ember started from the file browser works.

## Test list
- **Boot Loader > Manage:** photo of what it says each card starts. Is it right?
- **BIBLE on a spare card:** install it, power off, power on. Does RIPPS2 start at once?
- **Power on holding TRIANGLE** (browser), **START** (disc) and, after replacing FMCB, **CIRCLE** (your old FMCB).
- **Boot Lock off and on** with your own PS2BBL: does PS2BBL start what it did before when off?
- **L1 / R1 and Left / Right** everywhere: anything that feels wrong or misses a press?
- **Memory Files:** change formations, watch the name fade, open Orbit Settings and try every row.
- **Leave Memory Files or the file browser open for 2+ hours** (overnight is better). Orbs still smooth?
- **START DRIVES** in the file browser with drives set to Off or Manual in Storage, then leave: is Storage as it was?
- **Drive names** in the file browser: are your USB, MX4SIO, iLink and HDD named right?
- **HDD Manager** (Square on the HDD in the drive list): smooth? Back out of a removal at each screen.
- **POPSTARTER path** (PS emulation settings): did it fill in by itself, and do PS1 games start?
- **Audio CDs**, especially CD-Extra, mixed mode and burned ones: do they play?
- **Ember** from the file browser: does it start and find your games?
- **APA HDD art:** does your cover art show now? Tell us where your ART folder is.
- **Launch 5 games** from different drives: any freeze on the way in?
