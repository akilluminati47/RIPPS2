# BIBLE puts PS2BBL on your memory card, Achievements arrive (SpiritofRA), the controls follow your thumbs, and the orbs now run all night. Real PS2s wanted: here is what to try.

## Boot Lock and BIBLE
- **Settings > General > Boot Loader > Manage** shows what each memory card starts at power on (PS2BBL, FMCB, OSDMenu).
- **BIBLE** is El Isra's PS2BBL 1.2.0, set up by RIPPS2: no wait at power on, RIPPS2 first. It installs on the card you pick; whatever was there before is kept, and CIRCLE at power on still starts it.
- Boot Lock only edits a real PS2BBL now, and cleans up the file build 68 wrote for FMCB cards.

## Achievements (SpiritofRA)
- **Achievements** in the START menu: telemetry and badges, a PC link test, and RetroAchievements for the disc in the tray. The PC side is the xeRAbora client on your network.
- **Start NBD Server** moved to **Settings > Network**, with the same status screen.

## Controls and display
- **L1 / R1** switch Launch Disc, Storage and Memory Files from anywhere; **Left / Right** switch drives and orb formations.
- **RIPFLOW** (the built-in cover carousel, was Coverflow): just the covers in its own Roboto type, the source at the bottom centre, its frame on every tab. Left / Right run the covers (hold to scroll), Up / Down switch sources. Scrolling is **Fast** by default.
- Tooltips and button hints read in lowercase, and tooltips fade away after 4.2 s.
- **720p and 1080i turn Widescreen on by themselves** (4:3 modes turn it off; you can still set it by hand), and the towers and orbs now keep their shape in widescreen.
- Launching keeps the towers and the loading mark moving until the game takes over.

## Colors and More (Settings > Interface)
- **D-pad Glyphs** beside drive and formation names: Hidden (new default), Shown, Fade In, Fade Out.
- **Color Theme** for all three tabs: RIPPS2, Ember, Blood, Ectoplasm, Amethyst, Bone.
- **Button Hints** and **Category Bar**: Shown, Fade When Idle, Hidden.
- **Category Order**: Memory Files first, Launch Disc last. Made for RIPFLOW.

## Memory Files
- **Orbit Settings** (START grid): cycle, speed, path lines, height, and which formations are in use, all live.
- **HDD Manager** is Square on an APA hard drive: fast now, and removing a partition takes two screens.
- Drives have real names (USB, MX4SIO, iLink, exFAT HDD), and **START DRIVES** starts them whatever Storage's start modes say.
- The orbs, towers and CD visualiser no longer break after 72 minutes: leave it on overnight.

## Discs and PS1
- The CD player takes any CD with sound tracks (CD-Extra, mixed mode, burned CDs).
- The POPSTARTER path fills itself in from a POPSTARTER.ELF on your drives. Ember started from the file browser works.

## Test list
- **Boot Loader > Manage:** photo of what it says each card starts. Is it right?
- **BIBLE on a spare card:** install it, power off, power on. Does RIPPS2 start at once?
- **Power on holding TRIANGLE** (browser), **START** (disc) and, after replacing FMCB, **CIRCLE** (your old FMCB).
- **Boot Lock off and on** with your own PS2BBL: does PS2BBL start what it did before when off?
- **Achievements > TEST THE PC LINK** with xeRAbora running on a PC: does it find it?
- **Achievements on a game:** CHECK GAME SUPPORT from its menu, telemetry on, play. Did an unlock pop up?
- **Settings > Network > NBD Server:** does it start and stop like before?
- **L1 / R1 and Left / Right** everywhere: anything that feels wrong or misses a press?
- **Colors and More:** try every Color Theme and the fades. Photo of your favourite look.
- **RIPFLOW** (Interface > Theme) with Category Order swapped: hold Left / Right, switch sources with Up / Down. All good?
- **Memory Files:** change formations, watch the name fade, open Orbit Settings and try every row.
- **Leave Memory Files or the file browser open for 2+ hours** (overnight is better). Orbs still smooth?
- **720p or 1080i:** does Widescreen tick itself, and do the towers and orbs look right?
- **Launch 5 games** from different drives: does the screen keep moving until the game starts?
- **START DRIVES** with drives set to Off or Manual in Storage, then leave: is Storage as it was?
- **Drive names** in the file browser: are your USB, MX4SIO, iLink and HDD named right?
- **HDD Manager** (Square on the HDD): smooth? Back out of a removal at each screen.
- **POPSTARTER path** (PS emulation settings): did it fill in by itself, and do PS1 games start?
- **Audio CDs**, especially CD-Extra, mixed mode and burned ones: do they play?
- **Ember** from the file browser, and **APA HDD art**: working now?
