# Builds 131 to 134: BIBLE signed for RIPPS2, a quiet pause and a clean end for videos, new info pages, the sky on Adapt and RIPGRID, Set Metadata filled in.

## Get it
- **RIPPS2.elf, RIPPS2-lite.elf**, **RIPPS2-languages.zip** and the **theme pack** (edition 128) are attached below, or from the [release page](https://github.com/akilluminati47/RIPPS2/releases/tag/v1.3.4-beta)
- Put it in place of your old RIPPS2.elf; your settings stay where they were.

## BIBLE
- **RIPPS2 carries BIBLE now**, our boot loader built on El Isra's PS2BBL, signed for RIPPS2. **Settings > General > Boot Loader > Manage** installs it on a memory card or the HDD; **BOOT LOCK** starts RIPPS2 at power on.
- **First console binds wanted**: try it on a spare card. If your console refuses it, RIPPS2 puts the card back as it was.

## Video and info pages
- **Pause is silent on a held frame**; a video **ends cleanly**, no repeated sound, no stalled last frames.
- **RIPFLOW**: Square INFO / Triangle OPTIONS beside the source name after 4.2 s on a game; its info page keeps the category bar and shows genre, size, developer and release.
- **RIPPS2's info page** shows the art and screenshots in full colour.

## Themes and settings
- **RIPGRID + sidebar**: L1 / R1 turn pages. **Stars on the right** sit at the row edge (the default on Adapt and OPL themes).
- **Adapt and RIPGRID**: Storage's sky instead of a flat colour, and a sky vignette over the game art.
- **Set Metadata**: title and file name filled in, Cross on FILE NAME renames, asks to turn writing on. **Pastes** report how many and where.

## Test list
- **Install BIBLE** (Manage) on a **spare memory card**: does the console take it?
- **Power on with that card**: does BIBLE start RIPPS2 at once (BOOT LOCK)?
- **Hold CIRCLE at power on**: does what was there before still start?
- **Manage > Restore**: is the old boot loader back?
- **BIBLE on the HDD** (fat PS2 that boots from HDD): does it start RIPPS2?
- **Pause a video** for a few seconds: silence and a still picture, then a clean resume?
- **Play a clip to its end**: any repeated sound or late frames?
- **RIPFLOW**: rest on a game 5 s: do the hints turn to INFO / OPTIONS, and back when you move?
- **RIPFLOW's info page**: the category bar, the bigger title, genre / size / developer / release lines?
- **RIPPS2's info page**: background art and screenshots in full colour, text still readable?
- **RIPGRID with the sidebar**: do L1 / R1 turn pages?
- **Adapt**: stars on the right edge, the sky with no art, the vignette over game art?
- **Set Metadata**: title and file name filled in; rename from FILE NAME?
- **Write Operations off**: does Set Metadata ask to turn them on?
- **Copy a file in Memory Files** and paste: does a box say how many and where?
