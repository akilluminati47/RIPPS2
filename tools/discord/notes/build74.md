# 720p and 1080i that hold up, an info page that no longer hangs, AUDIO found wherever you keep it, and BIBLE on any HDD. Real PS2s wanted: here is what to try.

## 720p and 1080i
- **No more HD crashes**: busy frames could overrun the smaller HD draw memory. The towers draw simpler in HD, and a frame that still runs out drops detail, not the console.
- **Drives and music keep up in HD**: switching to 720p/1080i left the menu outranking everything for the whole session. Fixed.

## Storage
- **Info page hang fixed** (All Games, Favorites): the page could read a list mid-rebuild just as the disc and cover faded in.

## AUDIO anywhere
- Beside RIPPS2 first, then the memory cards, each started drive (top or APPS folder) and the HDD's OPL folder. Boot quickly from a memory card and keep your music on the HDD.

## BIBLE on the internal HDD
- Works without a __sysconf partition (the build 73 error): RIPPS2 goes on __common, the config on a memory card.
- Installing from a memory card keeps that copy first (quicker boot); the HDD copy is the fallback.

## Test list
- **720p, then 1080i** (Settings > Display): browse Storage, open info pages, play music. Crash, stall or stutter?
- **Back to 480p/576i after HD**: music and drives as smooth as before?
- **All Games > info page**, many times, while drives are still loading: any hang?
- **Favorites with Show Recents** > info page: any hang?
- **RIPPS2 on a memory card, AUDIO folder on the HDD** (in OPL's folder or APPS): does the music start once the HDD is up?
- **BIBLE > Internal HDD** (fat PS2 + network adapter, HDD backed up): installs? Power off/on: straight into RIPPS2?
- **Anything from the build 73 list** you did not get to: covers, POPSTARTER, PS1 from Memory Files, HDD Manager.
