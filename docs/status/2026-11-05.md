## One folder for BIBLE: waiting on your signature
BIBLE only read its settings from `SYS-CONF`, so this took a BIBLE change: branch `one-folder`, commit ee9adaf. In the lab, settings only in the system folder start RIPPS2, and an older card with only `SYS-CONF` still works. RIPPS2's install is written and passed on a lab card (a test build that skips the bind): settings and boot sound move in, `SYS-CONF`, `PS2BBL`, other regions' copies and stale files go. It stays off in the normal build until it carries a BIBLE that reads the folder.

Sign it (your keys, your kelftool):

`powershell -ExecutionPolicy Bypass -File "B:\Webpages - Projects\BIBLE-to-sign\sign-ee9adaf.ps1"`

Then the next build carries it and the install turns on. Note: it removes BIBLE's copies for other regions from a card that updates, so that card then boots only on consoles of this region.
