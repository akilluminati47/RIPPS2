## Found and fixed today
- BIBLE's MMCE and MX4SIO builds hung on black: their homebrew MCMAN did not link (IOP link error -200). BIBLE `a1ffb0b` loads RIPPS2's SIO2 stack and builds on RIPPS2's pinned toolchain image.
- RIPPS2's bind failed on the SD2PSX ("card login: not ready"): the card does not log in through ps2sdk's rewrite of `secrman_special`. RIPPS2 now boots KELFBinder's `IOPRP.img` byte for byte (carried as GPL-3 data, `elf/kelfbinder`).
- A bind changes only BIBLE's 32 key bytes (offsets 40 to 71), so RIPPS2 recognizes BIBLE by comparing the rest.
