# RIPPS2

> ### リップしよう: RIPPS2 ビルド 138、v1.3.8 ベータ
> **RIP PS2、ELF キラー。** 単体で動き、決して破壊しない: ほかの ELF は[棚](https://akilluminati47.github.io/RIPPS2/)に無事なまま残り (頼まない限り何も消されません)、ふさわしい休息を取るだけです。
> 1. **[RIPPS2.elf をダウンロード](https://github.com/akilluminati47/RIPPS2/releases/latest/download/RIPPS2.elf)** (常に最新リリース) (ファイル 1 つ、2,730 KB)、必要なら **[テーマパック](https://github.com/akilluminati47/RIPPS2-themes/releases/latest)** (Adapt と Adapt Rx、エディション 136: それぞれ設定 1 つと画像 1 枚。RIPGRID と RIPFLOW は内蔵)、そして RIPPS2 を自分の言語で使うための **[RIPPS2-languages.zip](https://github.com/akilluminati47/RIPPS2/releases/latest/download/RIPPS2-languages.zip)** (33 言語。毎リリースに同梱)。
> 2. USB メモリかメモリーカードにコピーし、FreeMcBoot、PS2BBL、wLaunchELF など homebrew の起動に使っているもので起動します。PCSX2 では **System > Start File** で `RIPPS2.elf` を選びます。
> 3. 感想を聞かせてください: [psx-place のスレッド](https://www.psx-place.com/threads/ripps2-a-ps2-front-end-in-one-elf-launch-disc-storage-memory-files.51316/)、[issue](https://github.com/akilluminati47/RIPPS2/issues)、または開発者 Discord の **#RIPPS2**、[discord.gg/Z7m9u5kby](https://discord.gg/Z7m9u5kby) (招待は 2026 年 12 月 1 日まで有効)。

RIPPS2 は単一の `.elf` に収まった PS2 フロントエンドです: [RiptOPL](https://github.com/NathanNeurotic/Open-PS2-Loader) (Open PS2 Loader のフォーク) を開いて組み直し、rickgaiser の [Neutrino](https://github.com/rickgaiser/neutrino) を 2 つ目のゲームコアとして使い、独自の見た目、ランチャー、ファイルブラウザー、ストレージツールを備えています。ガラスの塔がゲームの後ろに立ち、軌道の隊形がファイルの後ろに並び、すべて PS2 がリアルタイムで描きます。

- **LAUNCH DISC** は PS2、PS1、DVD ビデオのディスクを起動し、起動前にドライブのゲームを教え、音楽 CD を再生している間は塔がスペクトラムアナライザーになります。**RIPDISC** (ビルド 105) はドライブのディスクをリップします: ゲームはストレージへ、CD や DVD ビデオはファイルへ。
- **STORAGE** はゲームライブラリーです: すべてのドライブを 1 つの一覧に (All Games は最初のフレームから全部を表示し、まだ応答していないドライブも含みます)、カバー、画像がスクリーンショットにフェードする情報ページ、ゲームごとの設定、そして R3 で Starred Games に星を付けられます (星は行の先頭に付きます。Settings > Game Sources > Starred Games Star で移動や非表示。R3 を 4.2 秒押し続けるとすべての星を隠すか表示)。L2 + R2 でランダムなゲームへ飛び、Recent Games は最近の起動を覚えています。ゲーム上で三角は **Hide Game**、**Delete** (ゲーム全体: イメージのすべての部分、その CFG、カバー、チート。セーブは頼んだときだけ)、**Set Metadata (Rename)**、ISO や ZSO なら **Compress to ZSO** または **Uncompress to ISO** (実験的: ZSO を読み直して確認するまで ISO は残ります) を開きます。各ドライブのゲームは最後の一覧からすぐに表示され、その後ドライブが読み直されます。
- **MEMORY FILES** は内蔵ファイルブラウザーです: メモリーカード、USB、MMCE、HDD の間でコピー、移動、削除 (コピーはすべて読み直して確認)。OPL の VMC カードイメージをフォルダーとして開く。PSU セーブのエクスポートとインポート。テキストファイルの編集。画像を開き、AVI 動画を**全画面**で**プレイヤー操作**付きで再生 (Cross 再生/一時停止、Circle 停止、L1/R1 10 秒スキップ、L2/R2 音量、START リピート。ガイドは再生中にフェードし、一時停止中は残ります) ([RIPPS2 Media Studio](tools/media-studio) はスマホの MP4 を含むどんな動画もこの形式に変換します)、`.mp3`、`.ogg`、`.wav` を再生、または複数に印を付けてまとめて開けば Launch Disc の CD プレイヤーでディスクのように再生できます。**`.tar` は青いフォルダー**で、開いて画像を貼り付けたり中身をコピーして取り出したりできます (ビルド 125)。`.tar` 上の三角で別の ART の `.tar` をマージします ([下記](#covers-from-one-file-art-pack))。**開いているフォルダーが最初の行**で、項目数、印を付けた数、合計サイズ、ドライブの空きを表示します。そこで Cross か Square を押すとすべてに印を付けます (何かに印があれば外します)。START で設定を開き、そこの **SEARCH FILES** は開始済みのどのドライブでもファイルやフォルダーを名前で探し、その場でツリーを開きます。メモリーカード上の Square で **CARD MANAGER** (カードを VMC にバックアップ、VMC のセーブをカードに書き込み、ゲームのセーブを消去、フォーマット)、APA HDD 上の Square で **HDD MANAGER** (パーティション、そのサイズ、パーティションテーブルを全部確認してからの削除) を開きます。

ビルド 100 から**ベータ**です: 100 のアルファビルドを、ripto、nuno6573、zackcage6、eliminator1403、FifthFox、Mr.sus.60 が実機と PCSX2 でテストし、ベータでは lukeatmynose と ahavasi、そして Discord でテストしてくれる皆さんも加わりました。YouTube での応援にも特に感謝します。いつものローダーも手元に置いて、何が壊れたか教えてください: RIPPS2 を作るのはフィードバックです。**RIPPS2 を更新させる一番の方法は [GitHub の issue](https://github.com/akilluminati47/RIPPS2/issues) です**: DarkNerdShawny は 3 つ立て、v1.1.7 の FreeMcBoot 修正はそのうちの 1 つから生まれました。DarkNerdShawny のようになりましょう。

## 主な機能

- **自分好みにできるテーマ。** 各ゲームのアートの上にすりガラスのパネル、カバー用の **Grid** 要素、右スティックの傾きで画面全体を 1 枚の紙のように動かす機能、そして最初のパック **[RIPPS2-themes](https://github.com/akilluminati47/RIPPS2-themes)**: Adapt と Adapt Rx。どの設定もすべてのキーの用語集から始まり、もっと作りたい人 (やエージェント) のためにチェッカーとキーリファレンスがあります。RIPGRID と RIPFLOW は内蔵で、Open PS2 Loader 用に作られたテーマもそのまま動きます。ゲーム一覧で **SELECT** を 4.2 秒押し続けると、テーマを選ぶパネルが開きます (Settings > Interface > Hold SELECT: List、Cycle で次のテーマへ、または Off)。RIPGRID と RIPFLOW では右スティックを 0.42 秒片側に倒すと、選んだケースが裏表紙へ回り、グリッドはひと払いでページをめくります。
- **カテゴリーを好きな場所に。** Settings > Interface > Layout > Category Layout: LAUNCH DISC、STORAGE、MEMORY FILES を名前で **Across the Top**、アイコンで **Sidebar** (Classic または XL。一覧で Left か Circle で開き、各カテゴリーにページのドロワーがあります)、または **Menu**: バーなしで、カテゴリーは START メニューに、OPL 用テーマと同じです。Theme ではテーマが決めます: OPL 用テーマは Menu、Adapt はサイドバーになります。
- **RIPFLOW**、内蔵のカバーカルーセル (RIPGRID も内蔵)、そしてゲーム起動時のディスク (Layout > Launch Disc): **Pop In**、**Spin**、ディスクを読めるまで大きくしてそのまま保つ **Zoom** (RIPFLOW と Adapt の既定)、または Off。**Hints and Glyphs** (Interface): ガイド、バッジ、4 つのアイコンセット (テーマのもの、RIPPS2 のもの、Standard、White) の配置と並びを自由に。**Colors and Text** (Interface): 10 の Color Themes (RIPPS2、Ember、Blood、Ectoplasm、Amethyst、Bone、Tangerine、Flamingo、Turquoise、Moonlight) または Custom、5 色をめぐる **Color Sweep** (Rainbow、各 Color Theme から作ったもの、または自分の 4 色まで)、そして Text Weight。Layout にはフェードするガイドとカテゴリーバー、画面中央に大きく出るソース名があります。テーマはこれらすべてを自分で選べますが、自分の設定が常に優先されます。
- **必要なものは同梱、持っているものは見つける。** BIBLE は同じ 1 つの `.elf` に入っていて、好きな場所にインストールされます。自分の [Neutrino](https://github.com/rickgaiser/neutrino)、POPSTARTER、POPS ファイル、自分の Ember はドライブ上で一度探して覚え、その場所から起動します。START メニューの **STATUS** はすべてのドライブ、各ランチャーが見つかった場所 (LOOK FOR THEM で探し直し)、homebrew、BIBLE、サウンドを表示し、**SAVE DIAGNOSTICS** はバグ報告用に `DIAG.TXT` を書きます。
- **高速起動。** Settings > Game Sources > Cache > **Fast Boot** は電源投入時に RIPPS2 自身のドライブだけを読みます: `RIPPS2.ELF` の横の設定とサウンド、そして各一覧はキャッシュから。ほかのドライブは、そのページで SELECT を押すかそのゲームを選ぶまで待ちます。RIPPS2 が読み書き中に選んだゲームは、残りを示すパネルの後ろで待ちます (START NOW ですぐ起動)。だから起動が書き込みを途中で止めることはありません。
- **設定を好きな場所に**: Settings > General & System > Save Settings To で、メモリーカードの RIPPS2 セーブ、内蔵 HDD の RIPPS2 フォルダー (exFAT、または APA HDD の OPL パーティション)、USB、MX4SIO、iLink、MMCE ドライブ (起動時に最初に読まれます)、または自分で入力したフォルダーに保存します。
- **テレビが求める位置に映像を。** Settings > Interface > Screen: Video Mode (720p と 1080i まで)、Widescreen、H-POS、V-POS、Overscan。ビルド 124 からビデオモードごとに保存されるので、1080i と 480i はそれぞれ自分の位置合わせを持ちます。
- **BIBLE と BOOT LOCK。** Settings > General & System > Boot Loader は各メモリーカードが電源投入時に何を起動するかを表示し、RIPPS2 用に準備した PS2BBL である **BIBLE** をメモリーカードにインストールします。**Boot Lock** は、コンソールが実際に起動するブートローダーを RIPPS2 を起動するよう設定します: PS2BBL と FreeMcBoot はすぐに起動し、OSDMenu はメニューの先頭に置き、オフにすれば元の状態に戻ります。
- **ゲーム内メニュー** (Settings > Game Launching > In-Game Menu、既定でオン): L1+L2+R1+R2+SELECT+START でゲームを自身の映像の上で無音で一時停止し、その下に Resume、Exit Game、**Screenshot** (RIPSHOT、[下記](#screenshots-in-game-ripshot))、Achievements、Power Off (2 回押すとその場で PS2 の電源を切ります) を出します。RESUME はまったく同じフレームから再開し、Achievements は残りの実績と取り方を一覧します。**Exit Game はコンソール自身の起動経路を通ります:** そのページの IGR Path が空のとき (既定)、リセットはブラウザーへ向かい、インストールされていればブートローダー (FreeMcBoot、PS2BBL、OSDMenu、BIBLE) を、Boot Lock がオンなら RIPPS2 をもう一度起動します。電源投入時とまったく同じです。どれもなければ PS2 ブラウザーです。v1.2.1 からは決して黒い画面になりません: IGR Path はリセットが読み込める場合 (メモリーカードか FAT32 の USB 上の ELF) で、RIPPS2 自身でないときだけ使われ、無視されたときは STATUS が知らせます。
- **Achievements** (SpiritofRA): PC の [xeRAbora](https://github.com/hacan359/xerabora) クライアント経由の RetroAchievements テレメトリー ([v0.1.0-alpha.18](https://github.com/hacan359/xerabora/releases/tag/v0.1.0-alpha.18) に固定)、追跡中のゲームのバッジ、トレイのディスク、そして **YOUR ACCOUNT**: 確認したすべてのゲームと解除したもの。xeRAbora がネットワークに開いているときは **LEFT TO HUNT**: ロック中の実績すべてとその取り方。
- **Cover Art** (Settings > Network): カバーのない PS2 ゲームのカバーを、PS2 自身が xlenore の GitHub の ps2-covers からダウンロードします (ネットワークケーブルとインターネットが必要)。**HD** (280 × 400、HD 画面でよりシャープ) か **Standard** (140 × 200、Open PS2 Loader のカバーと同じ) を選びます。どちらも 8 ビットでディザリング付き。すでにカバーがあるゲームはそれを保ちます (ビルド 125)。**720p と 1080i** は 1 パスで描かれます: そのモードの全ラインを持つ幅 640 ピクセルのフレームを、コンソール自身の表示回路が画面に引き伸ばすので、どのアニメーションも速度を保ちます。**RIPFLOW は 16:9 の映像で 5 枚のカバーを表示し** (720p、1080i、または Widescreen オン)、4:3 では 3 枚、数を選ばない限り自分で広がります (ビルド 125)。**AUDIO** フォルダーはどのドライブ上でも見つかり、塔とオーブは一晩中 60 fps で滑らかに回ります。
- **安全柵**: どのビルドも RiptOPL のホストチェックと RIPPS2 自身のチェックを通り、RIPPS2 のファイルに新しい警告が 1 つでもあれば不合格になります。

## あなたの言語で

ビルド 104 から、RIPPS2 が表示するすべての言葉が翻訳されます。独自の画面とガイドも、Open PS2 Loader の設定も。各リリースには **`RIPPS2-languages.zip`** が付きます: その `LNG` フォルダーを USB ドライブのルート、HDD の OPL パーティション、MMCE カードにコピーし (または中のファイルを `mc0:/RIPPS2` へ)、**Settings > Interface > Language** で言語を選びます。33 の言語が RIPPS2 を完全に読めます。フランス語、スペイン語、ドイツ語、ポルトガル語から、ロシア語、ギリシャ語、トルコ語、ベトナム語、ラオ語、中国語、日本語、韓国語まで、そしてアラビア語とペルシャ語は右から左へ、文字をつなげて。別の文字が必要な言語は、そのフォントがパックの隣に入っています。修正や新しい言語は [`elf/lang`](elf/lang) へ (1 言語につき `<Language>.yml` 1 つ。`python3 elf/lang/ripps2lang.py check` で確認)。

## ディスクをリップする

ディスクをドライブに入れて **LAUNCH DISC** を開きます。数秒後、ガラスのパネルが **RIPDISC** を勧めます: リングが満ちるまで **SELECT** を押し続けます。次のステップでディスクの種類、サイズ、**かかる時間の目安**、保存先が表示されます。確認して **START**。

- **PS2 ゲーム**はドライブの DVD または CD フォルダーの ISO になり、ゲーム一覧に入ります。FAT32 ドライブに入れる 4 GB を超えるゲームは、代わりに Open PS2 Loader 方式の 1 GB の分割ファイルと ul.cfg で保存されます。exFAT ドライブ (USB メモリ、MX4SIO、iLink、内蔵 HDD) では 1 つの ISO のままです。リップを始める前にドライブの空きを確認します。
- **PS1 ゲーム**は `EMBER/games/<Title>/` の BIN と CUE になり、Ember で遊べます。
- **音楽 CD や DVD ビデオ**はファイルへ: Memory Files が **MEDIA** (AUDIO の隣) で開き、ディスクは **RIPPED** としてクリップボードにあります。どのフォルダーでも PASTE でそこにリップします。CD は WAV で届き (1 つを AUDIO にコピーすればメニュー音楽に加わります)、自作の DVD は VIDEO_TS ファイルで届きます。市販の映画はコピーガードがあり、ドライブが読みません。

PS2 の USB は遅く (USB 1.1、毎秒約 1 MB)、DVD 全体を USB メモリに入れると 1 時間以上かかります。exFAT の内蔵 HDD ならその何分の一かです。目安は最初のリップからコンソールの速度を学習します。

## ゲーム内スクリーンショット (RIPSHOT)

ゲーム中に L1+L2+R1+R2+SELECT+START、そして **SCREENSHOT**: メニューを開いた時点の画面のフレームを、メニュー抜きで。**ART** (ゲームのスクリーンショット画像、250 x 188、`_SCR`、`_SCR2`...)、**MEDIA** (フルサイズ、ゲーム名のフォルダーに)、または **BOTH** を選びます。それぞれ作られるファイル、サイズ、残りのショット数を表示します。**SAVE** でメニューがフェードし、**KEEP** か **DELETE** で決めます。

ショットはゲームのフィルムとして `MEDIA/RIPSHOT` (ゲームごとに 6 枚) で待ち、8 ビット PNG に現像されます: Memory Files から手動で (`MEDIA/RIPSHOT` を開き、ショットで VIEW、ACTIONS で現像)、または **Develop Shots: Auto** (Settings > Game Launching > In-Game Menu) でバックグラウンドで自動的に。テーマは `SCRn` キーでゲームのすべてのショットを表示します: RIPPS2 の情報ページのスライドショー、RIPGRID、RIPFLOW、Adapt がそうします。RIPSHOT は USB、exFAT の内蔵 HDD、MX4SIO、iLink 上のゲームで、ビルド 117 からは MMCE でも動きます (SD2PSX の SD カードがフィルムを保持)。APA HDD 上のゲームは後のビルドで対応します。

## 自分のサウンドと音楽

`RIPPS2.elf` の隣に `AUDIO` フォルダーを置きます。効果音はイベント名の `.adp` ファイルで受け付け (RiptOPL のもの: `boot`、`cancel`、`confirm`、`cursor`、`message`、`transition`、`bd_connect`、`bd_disconnect`、RIPPS2 のもの: `page_in`、`page_out`、`error`、`save`、`launch`、`disc`、`random`)、音楽は任意の `.ogg` (タグなし Ogg Vorbis)、16 ビットの `.wav`、または (ビルド 115 から) `.mp3` で受け付けます: `bgm_01 Title.ogg` と `bgm_02 Title.ogg` で順番と曲名が決まり、ビルド 105 からはほかの名前もそのまま一覧されるので、CD からリップした曲を改名する必要はありません。Settings > Audio > Music で曲を選びます。RIPPS2 は AUDIO (と MEDIA) にこれらすべてを説明する `README.txt` を書きます。**[RIPPS2 Media Studio](tools/media-studio)** はこのすべてを PC 上で行います (そして動画を Memory Files が再生する AVI に変換します): どの音や曲にも移動し、元の音と PS2 が再生する音を聴き比べ、それ (またはフォルダーごと) を `output/AUDIO` に変換し、USB メモリと RIPPS2 の Memory Files でそのフォルダーを `RIPPS2.elf` の隣にコピーします。自分の PS2 の BIOS ダンプを指定すれば、コンソールのメニュー音とシステム音楽をそこから作り、すぐ使えます。(`elf/theme/tools/make_adp.py` と `make_sound_pack.py` は今もコマンドラインで同じことをします。) RIPPS2 はサウンドも音楽も同梱しません: ビルド 95 から中身は何もないので、`AUDIO` フォルダーがなければ無音で、**STATUS > SOUNDS** が見つけたものを教えます。

**AUDIO と MEDIA の置き場所。** `AUDIO` は `RIPPS2.elf` の隣、RIPPS2 が起動するドライブに置きます: 起動で最初に読まれ、**Fast Boot** がオンなら (Settings > Game Sources > Cache) 起動音は設定と一緒に、ドライブや一覧が始まる前に読まれるので、塔の最初のフレームが出たときにはもう鳴っています (ビルド 118 から)。RIPPS2 がメモリーカード、`AUDIO` がドライブにある場合: **BIOS Sounds > Rip** の後、START で `boot.adp` (約 360 KB) だけをカードの RIPPS2 の隣にコピーするので、起動音はドライブの準備ができたときではなく柱が昇るときに鳴ります (ビルド 121 から)。そこにはメニューが鳴らすものだけを置きましょう。`MEDIA` (リップした CD や DVD ビデオ、フルサイズのショット) は一番大きなドライブ向けです: 起動時には何も読まれないので、そのドライブの読み込み速度はあまり関係ありません。

## 1 つのファイルからカバーを (ART Pack)

ビルド 118 から、**Settings > Game Sources > Cache > ART Pack** は開始済みのすべてのドライブの `ART` フォルダーを、選んだドライブの `ART` フォルダーにある 1 つの `art.tar` にまとめます。RIPPS2 は各ドライブが自分の画像をどれだけ速く読むかを測り、一番速いものを先頭に置くので X で選べます (たとえば SD2PSX の SD カード)。画像はそのまま入ります (PNG と JPG はすでに圧縮済み: tar は並べるだけで、PC はほかの tar と同じように開けます)。`ART` フォルダーには手を付けません。それ以降、カバーはその 1 つのファイルからインデックス経由で読み込まれ (インデックスはパックと一緒に書かれるので、最初の起動でスキャンは不要)、パックを作ったゲームの `ART` フォルダーには画像ごとに問い合わせることはありません。欠けている画像でもです: 音楽を流しているドライブの読み込みが減り、カバーがカーソルに追いつきます。RIPPS2 が後でダウンロードや撮影した画像はすぐ表示され、PC でコピーした画像はパックを作り直すと表示されます。Memory Files で `art.tar` を別のドライブの `ART` フォルダーにコピーすることもできますが、ブラウズに使うドライブで作りましょう。同じボタンでパックを削除します。

**`.tar` を別の `.tar` にマージ** (ビルド 123)。大きなドライブを一度マスターとしてまとめ、後から新しいゲームの画像だけをまとめて、その小さな `.tar` をマージします。ART フォルダーをすべてまとめ直す必要はありません。Memory Files で `.tar` 上の三角 > **MERGE A .TAR INTO THIS**: その `.tar` が残すものになり、RIPPS2 がマージ候補を一覧します (同じフォルダー、開始済みの各ドライブの ART フォルダーとそのルートから)。Cache > ART Pack は使用中のパックにも、パックを作った直後にも同じことを勧めます。両方にある画像は追加する方のものになり、2 つのゲーム一覧は 1 つになります。マージは残す `.tar` の隣に書かれ、すべてのバイトがドライブに書かれたときだけその名前になります。だから停止、満杯のドライブ、抜かれたカードがあっても、残す方はそのままです。最後にダイアログが両方のファイル名を示し、追加した方を消すか尋ねます (START で消去、Back で保持)。残す方が候補になることはありません。

<a id="your-hardware"></a>

## あなたのハードウェア

- **ネットワークアダプターと内蔵 HDD。** RIPPS2 はどのネットワークアダプターも PS2SDK 自身の DEV9 ドライバー、今のローダーが使うものと同じもので起動し、2 種類を自分で見分けます: ファットモデルの拡張ベイのアダプター (SCPH-10281、SCPH-10350、それをもとにした IDE と SATA アダプター) とスリムの内蔵ポート、そして初期の日本製コンソール (SCPH-10000 から 18000) の PC CARD アダプター。選ぶべき古いドライバーはありません。HDD は APA でも exFAT でも同じように読まれ、HDPro アダプターには専用のドライバーが使われます。SMB のゲーム、UDPBD、画像のダウンロードはすべて同じアダプターを使います。アダプターが表示されないときは、アダプターとコンソールの型番を送ってください。
- **VMC (仮想メモリーカード)。** ゲームの設定 (その VMC の行) で、ゲームのドライブの `VMC` フォルダーにあるカードイメージをスロット 1 か 2 に割り当てます。OPL コアでは USB、MX4SIO、iLink、exFAT の HDD、APA HDD、SMB、MMCE で動きます。FAT32 か exFAT のドライブではカードは連続した 1 つのファイルである必要があり、RIPPS2 は新しいカードをそのように作り、**Rebuild** でそうでない古いカードを直します。Neutrino では USB、MX4SIO、iLink、exFAT の HDD で動きますが APA HDD では動かず、ゲームはそのスロットの本物のカードを使います。SD2PSX は VMC なしでも、ゲームごとに自分でカードを分けられます (設定の GameID)。
- **Neutrino。** RIPPS2 は、どのバージョンでも自分の Neutrino を使います (ビルド 135 から同梱はなく、見つからないゲームは置き場所を案内します): その `neutrino` フォルダーをゲームのドライブかメモリーカードに置くか、Settings > Game Launching > Neutrino Defaults でパスを指定すれば、RIPPS2 はそのバージョンが知っているオプションだけを送ります。1.1.5 から、RIPPS2 が USB ドライブから起動し、ゲームが exFAT の内蔵 HDD にあるときは正しいドライブ番号が渡されます (この組み合わせで Neutrino が閉じてコンソールが再起動していました)。
- **RIPPS2 が知らなかった USB コントローラー** (ビルド 129)。**Settings > Controllers > Set Up A USB Pad**: コントローラーをつなぎ、RIPPS2 が求める各ボタンを押すと、そのコントローラーの `.pad` プロファイルが書かれます (RIPPS2 の隣の `PADS/VVVV_PPPP.pad`、プレーンテキスト: [フォーマット](docs/plans/pad-spec.md))。プロファイルのあるコントローラーはメニューを操作でき、Pad Emulator をオンにすればゲームで遊べます。`PADS/GAMES/<game ID>.pad` でゲームごとにボタンを入れ替えられます。**My Pads** は各プロファイルを確認し、拒否したものの問題点を教えます。
- **SMS のようなアプリ。** アプリは自分のパスから起動します。SMS (Simple Media System) はそれしか読まないので、RIPPS2 は再生するファイルを渡せません。ファイルを受け付ける SMS があれば、RIPPS2 は渡します。

<a id="how-it-is-built"></a>

## ビルドの仕組み

`elf/build.sh` は `elf/RIPTOPL_REF` に記されたコミットの RiptOPL を取得し、`elf/patches` のパッチ群を適用し、`elf/theme` から RIPPS2 のテーマ、フォント、画像を加えて `RIPPS2.elf` をビルドします。GitHub Actions がプッシュのたびに実行し ("Build RIPPS2.elf")、その成果物の ELF がリリースです。

<a id="the-web-version"></a>

## ウェブ版

RIPPS2 はウェブのテーマとして始まり、その版は今もここにあります: **ライブデモ** https://akilluminati47.github.io/RIPPS2/

| 項目 | 開くもの |
| --- | --- |
| **Launch Disc** | 柱、フィールド中央の二重バースト付き |
| **Storage** | 柱の前のエルフの棚 |
| **Memory Files** | オーブ |

PS2 のマークは選択中の項目の下で動き、項目の間を飛びます: 隣へは 1 回転、端から端へはコイン投げのような深いダイブ。ラベルは訪問者のシステム言語に従います (18 言語、`?lang=fr` などで切り替え可能)。メニューのフォントで描けないものは、単語ごとすっきりしたサンセリフに切り替わります。

**エルフの棚:** Storage の陳列棚。塔の前の uOPL の木の板、その上に RIPPS2 のマークが 10 個: 死んだエルフのフェルト帽が、つばを下にして自分の血だまりに立っています。Color Theme ごとに 1 つ (RIPPS2、Ember、Blood、Ectoplasm、Amethyst、Bone、Tangerine、Flamingo、Turquoise、Moonlight)。RIPFLOW がカバーを見せるように一度に 3 つが見え、中央の帽子はカーソルの方を向き (近いほど速く回ります)、バネで揺れます。Left / Right か隣をタップすると棚が回ります。青い RIPPS2 の帽子で止まります。押した帽子は自分の Color Theme を塔に送ります (ELF 自身のカラーマトリクスなので、塔はそのテーマで描かれるとおりに見えます): タップならフィールドを横切る色の噴出で、RIPPS2 の青に戻ります。押し続ければ、離すまでテーマが画面全体に残ります。

**縦向きのスマホ** (`letterbox.js`): サイトは画面上部のレターボックスのプレイヤーで再生され、その上にはカメラの切り欠きと丸い角だけ。横向きの画面のように配置され、収まるように縮小されます。その下にはプレイヤーを指す上向きの矢印、ピンチで拡大するかスマホを回すよう促す光るメモ、16:9 と 4:3 の枠を切り替えるボタン (記憶されます)。右下隅の脚注は RIPPS2 (vision interactive mock-up) と書いています。スマホを回せばフルページに戻り、プレイヤーが表示していたページのままです。`?letterbox=1` でデスクトップでもプレイヤーを表示します。

**柱:** 光る縁、継ぎ目、またたくセル、エネルギーパルスを持つガラスのデータの塔が、反射する床の上に。塔は読み込み時に地面から昇り、その後は呼吸してうねります。カーソルは波を送り、クリックでバーストを起こします。遅い端末では解像度を調整し、画面外では止まり、視差効果を減らす設定を尊重します。

**オーブ:** 12 の隊形 (Browser Orbit、Borromean Rings、Torus Orbit、Icosahedron、Double Helix、Strange Attractor、Trefoil Knot、Mobius Strip、Klein Bottle、Golden Spiral、Lissajous、Seven-Point Star)。それぞれ必要な数のオーブを使い、隊形の間で分かれたり合わさったりします。ELF の Memory Files と同じく、タブが開いたときと隊形が収まるたびに、各形の軌跡が光で描かれ、約 2 秒残ってからフェードします。シーンを押し続けると (または `L`、コントローラーの L2 か Cross を押し続けると) 軌跡全体を静止して見られます。押しながらドラッグで隊形を回し、離すと滑りながら止まります (コントローラーの右スティックでも回せます)。スワイプ、名前の横の Left / Right アイコン、矢印キー、コントローラーの方向ボタンかショルダーボタンで切り替えます。

ローカルで動かすには、フォルダーをサーバーで配信し (ES モジュールにはウェブサーバーが必要)、http://localhost:8000 を開きます:

```bash
python -m http.server 8000
```

`?t=12` を付けると柱のイントロを飛ばし、`?f=3#memory-files` で特定の隊形を開きます (古い `orbs.html` のリンクは Memory Files に届きます)。

## クレジット

RIPPS2 は akilluminati47 が設計と指揮をし、Claude (Anthropic) とともに作っています。テスター: ripto、nuno6573、zackcage6、eliminator1403、FifthFox、Mr.sus.60、lukeatmynose、ahavasi、そして Discord でテストしてくれる皆さん。GitHub の issue: DarkNerdShawny と、issue を立ててくれるすべての人 (issue は RIPPS2 を更新させる一番の方法です: 彼らのように [1 つ立てましょう](https://github.com/akilluminati47/RIPPS2/issues))。YouTube での応援にも特に感謝します: どこから連絡をもらっても、喜んで手伝います。

- [RiptOPL](https://github.com/NathanNeurotic/Open-PS2-Loader) by NathanNeurotic と [Open PS2 Loader](https://github.com/ps2homebrew/Open-PS2-Loader) チーム (AFL-3.0)。RIPPS2 はその上に作られています。彼らの完全なクレジットは RIPPS2 の About ページにあります。
- [Neutrino](https://github.com/rickgaiser/neutrino) by [rickgaiser](https://github.com/rickgaiser) (AFL-3.0)。小さく速いモジュール式のデバイスエミュレーターで、RIPPS2 の 2 つ目のゲームコアです: RIPPS2 はどのバージョンでも自分の Neutrino を見つけて使います。RIPPS2.elf はビルド 134 まで同梱していました ([`elf/neutrino`](elf/neutrino/README.md))。Settings > Game Launching の Default Loader Core で選びます。
- [xeRAbora](https://github.com/hacan359/xerabora) by [hacan359](https://github.com/hacan359): PC の RetroAchievements クライアントと、RIPPS2 が RiptOPL 経由で受け継いだコンソール側の RetroAchievements コード (MIT / AFL-3.0)。**LEFT TO HUNT** はポート 18280 のダッシュボードの `GET /state` エンドポイントを読みます。これは文書化されたコンソールプロトコルの一部ではなく、アルファ間で変わる可能性があるため、RIPPS2 は作者が勧める **[v0.1.0-alpha.18](https://github.com/hacan359/xerabora/releases/tag/v0.1.0-alpha.18)** に固定しています (alpha.10 は不安定で、LEFT TO HUNT が読む `checked_only` キーは alpha.11 以降の `/state` にしかありません)。その版の `/state` コードで確認済みで、ほかの版はテストしていません。
- [ESR](https://gitlab.com/ffgriever/esr/) by ffgriever: Launch Disc は ESR ディスクに自分で用意したものを起動します。
- [Ember](https://github.com/Gageformer/Ember/releases) by Gageformer、PS2 用の PS1 エミュレーター: RIPPS2 はゲームのあるドライブの `EMBER` フォルダーから自分の `ember.elf` を起動します (ビルド 71 から 112 はその Beta-2 ビルドを同梱していました。[`elf/ember`](elf/ember/README.md))。PS1 の BIOS は自分で用意してください。
- [POPSTARTER](https://www.psx-place.com/resources/popstarter.683/) by krHACKen は自分で用意したもので PS1 ゲームを起動し、RIPPS2 はそれをドライブやメモリーカード上で見つけます ([`elf/popstarter`](elf/popstarter/README.md))。
- [PS2BBL](https://github.com/israpps/PlayStation2-Basic-BootLoader) by El Isra (israpps) と [PS2BBL Extended](https://github.com/saildot4k/PlayStation2-Basic-BootLoader-Extended) by saildot4k: BOOT LOCK はその設定を編集してコンソールに RIPPS2 を起動させます (ビルド 116 から FreeMcBoot と OSDMenu の設定も)。ビルド 134 から、RIPPS2.elf は RIPPS2 向けに署名した PS2BBL の派生版 [BIBLE](https://github.com/akilluminati47/BIBLE) を同梱し、**Boot Loader > Manage** がインストールします (ビルド 69 から 133 は El Isra の PS2BBL 1.2.0 を同梱)。GPL-3.0 ライセンスとソースは [`elf/bible`](elf/bible/README.md) にあります。カードへの紐付けには ps2sdk のオープンな SECRMAN (AFL) を使い、鍵は使いません。
- **MMCE カード**: SD2PSX 上の [sd2psXtd](https://sd2psxtd.github.io/) ファームウェア、たとえば [SD2PSXTD](https://github.com/LinkRetro/SD2PSXTD-Hardware) カードを、[mmceman](https://github.com/ps2-mmce/mmceman) (ps2-mmce) 経由で読みます: ゲーム、VMC、設定がカードの SD に。**ファームウェアは最新に保ってください** ([sd2psxtd.github.io/download](https://sd2psxtd.github.io/download))。カード上のゲームの圧縮には sd2psXtd 1.4.0 以降が必要です (完成したイメージを改名で配置します)。RIPPS2 はまずカードに問い合わせるので、古いファームウェアでは何かを始める前にわかり、そこでは圧縮できません。カードは空き容量を報告できないので、1.4.0 でも圧縮前の容量確認はありません: ゲームとその ZSO が並んで入る余裕を残してください (カードがいっぱいになれば作業は止まり、書いたものを消します)。
- [wLaunchELF](https://github.com/ps2homebrew/wLaunchELF) by ps2homebrew チーム、wLaunchELF R3Z by NathanNeurotic: Memory Files のブラウザーとその設定グリッドの動作の手本。
- [Apollo Save Tool](https://github.com/bucanero/apollo-ps2) by bucanero: セーブツール (PSU、カードイメージ) の手本。コードは RIPPS2 独自で、フォーマットから書いています。
- [ps2sdk](https://github.com/ps2dev/ps2sdk) by ps2dev チーム: メモリーカードのファイルシステム (mcman) と USB キーボードドライバー。
- mymc by Ross Ridge と [mymcplus](https://github.com/thestr4ng3r/mymcplus) by Florian Maerkl: RIPPS2 のカードイメージの書き込みはこれらで検証しています。
- [minimp3](https://github.com/lieff/minimp3) by lieff (CC0 1.0、パブリックドメイン): Memory Files と AUDIO での MP3 再生、ビルド 115 から、RiptOPL の `thirdparty/minimp3` に無改変で。
- Planet N Compact by [Iconian Fonts](https://www.iconian.com) (`assets/master.ttf`)、そして Planet N Condensed (`elf/theme/fonts/ripps2_condensed.ttf`、ビルド 115 から `builtin:ripps2condensed` として内蔵、Adapt の一覧のフォント)。[RIPPS2 Sleek](https://github.com/akilluminati47/RIPPS2-fonts) (Regular、Bold、Bold Case) は RIPPS2 のために描かれました。そのリポジトリが TTF と WOFF2 のフォントを OFL で配布しています。
- ウェブ版: [three.js](https://threejs.org) r160、MIT (`vendor/LICENSE` を参照)。[Albert Sans](https://github.com/usted/Albert-Sans)、SIL Open Font License (`vendor/fonts/OFL.txt` を参照)。
- ウェブモックアップのエルフの棚 (Storage、[akilluminati47.github.io/RIPPS2](https://akilluminati47.github.io/RIPPS2/)) は [uOPL](https://github.com/SlimPugGamer/uOPL) の木の板の上に立っています (`gfx/plank.png`、AFL-3.0)。
- RIPPS2 のマーク、青い帽子の死んだエルフはオリジナルです: three.js (MIT) で `media/deadelf/scene.html` からレンダリング (すべての角度と色は `media/deadelf` に)、ベクター版は `assets/ripps2-deadelf.svg` にあります。
- ビルド 83 の紹介リールとショート (YouTube) は、Details (x-Radar Portable、PSP のシステム音楽、Sony)、Wii のニュースチャンネルの戸高一生による Slideshow (Daytime) (Nintendo、2006)、PS2 自身の Menu テーマ (Sony) に合わせて作られています。ビルド 66 の紹介リールは Slideshow (Daytime) に合わせて。ビルド 55 の紹介リールの音楽はオリジナルです。テストに映るゲームの画像はコミュニティの OPL 画像データベースのもので、RIPPS2 の一部ではありません。
