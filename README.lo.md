# RIPPS2

> ### ມາຣິບກັນ: RIPPS2 ບິວ 130, v1.3.0 ເບຕ້າ
> **RIP PS2, ນັກລ່າ ELF.** ເຮັດວຽກໄດ້ດ້ວຍຕົວເອງ ແລະ ບໍ່ເຄີຍທຳລາຍ: ELF ອື່ນຂອງເຈົ້າຍັງຢູ່ຢ່າງປອດໄພເທິງ[ຊັ້ນວາງ](https://akilluminati47.github.io/RIPPS2/) (ບໍ່ມີຫຍັງຖືກລຶບ ເວັ້ນແຕ່ເຈົ້າຂໍ), ພວກມັນພຽງແຕ່ໄດ້ພັກຜ່ອນຕາມທີ່ສົມຄວນ.
> 1. **[ດາວໂຫຼດ RIPPS2.elf](https://github.com/akilluminati47/RIPPS2/releases/latest/download/RIPPS2.elf)** (ລຸ້ນໃໝ່ລ່າສຸດສະເໝີ) (ໄຟລ໌ດຽວ, 2.747 KB; ຫຼື **[RIPPS2-lite.elf](https://github.com/akilluminati47/RIPPS2/releases/latest/download/RIPPS2-lite.elf)**, 2.203 KB, ອັນດຽວກັນແຕ່ບໍ່ມີ PS2BBL ສຳລັບ BIBLE ແລະ ບໍ່ມີ Neutrino), ຖ້າຕ້ອງການກໍ **[ຊຸດທີມ](https://github.com/akilluminati47/RIPPS2-themes/releases/latest)** (Adapt ແລະ Adapt Rx, ສະບັບ 128: ແຕ່ລະອັນມີການຕັ້ງຄ່າໜຶ່ງ ແລະ ຮູບໜຶ່ງ; RIPGRID ແລະ RIPFLOW ມີຢູ່ໃນຕົວ), ແລະ **[RIPPS2-languages.zip](https://github.com/akilluminati47/RIPPS2/releases/latest/download/RIPPS2-languages.zip)** ເພື່ອໃຊ້ RIPPS2 ເປັນພາສາຂອງເຈົ້າ (33 ພາສາ; ມາພ້ອມທຸກລຸ້ນ).
> 2. ສຳເນົາໃສ່ແຟລດ USB ຫຼື ບັດຄວາມຈຳ ແລ້ວເປີດຈາກ FreeMcBoot, PS2BBL, wLaunchELF ຫຼື ສິ່ງທີ່ເຈົ້າໃຊ້ເປີດ homebrew. ໃນ PCSX2: **System > Start File** ແລ້ວເລືອກ `RIPPS2.elf`.
> 3. ບອກພວກເຮົາວ່າເປັນແນວໃດ: [ກະທູ້ psx-place](https://www.psx-place.com/threads/ripps2-a-ps2-front-end-in-one-elf-launch-disc-storage-memory-files.51316/), [issue](https://github.com/akilluminati47/RIPPS2/issues), ຫຼື **#RIPPS2** ໃນ Discord ຂອງນັກພັດທະນາ, [discord.gg/Z7m9u5kby](https://discord.gg/Z7m9u5kby) (ຄຳເຊີນໃຊ້ໄດ້ຮອດວັນທີ 1 ທັນວາ 2026).

RIPPS2 ແມ່ນໜ້າຈໍຫຼັກ PS2 ໃນ `.elf` ດຽວ: [RiptOPL](https://github.com/NathanNeurotic/Open-PS2-Loader) (ສາຂາຂອງ Open PS2 Loader) ທີ່ຖືກເປີດອອກ ແລະ ປະກອບຂຶ້ນໃໝ່, ມີ [Neutrino](https://github.com/rickgaiser/neutrino) ຂອງ rickgaiser ຢູ່ໃນຕົວເປັນແກນເກມທີສອງ, ພ້ອມຮູບລັກ, ຕົວເປີດ, ຕົວທ່ອງໄຟລ໌ ແລະ ເຄື່ອງມືບ່ອນເກັບຂໍ້ມູນຂອງມັນເອງ. ຫໍຄອຍແກ້ວຢືນຢູ່ຫຼັງເກມຂອງເຈົ້າ, ຮູບແບບວົງໂຄຈອນຢູ່ຫຼັງໄຟລ໌ຂອງເຈົ້າ, ແລະ ທັງໝົດຖືກແຕ້ມສົດໂດຍ PS2.

- **LAUNCH DISC** ເປີດແຜ່ນ PS2, PS1 ແລະ DVD ວິດີໂອ, ບອກວ່າເກມໃດຢູ່ໃນເຄື່ອງອ່ານກ່ອນເປີດ, ແລະ ຫຼິ້ນ CD ເພງ ໃນຂະນະທີ່ຫໍຄອຍກາຍເປັນເຄື່ອງວິເຄາະສະເປັກຕຣຳ. **RIPDISC** (ບິວ 105) ຣິບແຜ່ນໃນເຄື່ອງອ່ານ: ເກມໄປບ່ອນເກັບຂໍ້ມູນຂອງເຈົ້າ, CD ຫຼື DVD ວິດີໂອໄປໄຟລ໌ຂອງເຈົ້າ.
- **STORAGE** ແມ່ນຫ້ອງສະໝຸດເກມຂອງເຈົ້າ: ທຸກໄດຣຟ໌ໃນລາຍການດຽວ (All Games ສະແດງທັງໝົດຕັ້ງແຕ່ເຟຣມທຳອິດ, ລວມທັງໄດຣຟ໌ທີ່ຍັງບໍ່ທັນຕອບ), ພ້ອມໜ້າປົກ, ໜ້າຂໍ້ມູນທີ່ຮູບຄ່ອຍໆປ່ຽນເປັນພາບໜ້າຈໍ, ການຕັ້ງຄ່າແຍກແຕ່ລະເກມ, ແລະ R3 ເພື່ອໃສ່ດາວໃຫ້ເກມໃນ Starred Games (ດາວຢູ່ຕົ້ນແຖວ; Settings > Game Sources > Starred Games Star ຍ້າຍ ຫຼື ເຊື່ອງມັນ; ກົດ R3 ຄ້າງໄວ້ 4,2 ວິນາທີ ເພື່ອເຊື່ອງ ຫຼື ສະແດງທຸກດາວ). L2 + R2 ໂດດໄປເກມແບບສຸ່ມ, ແລະ Recent Games ຈື່ການເປີດຫຼ້າສຸດຂອງເຈົ້າ. ສາມຫຼ່ຽມເທິງເກມເປີດ **Hide Game**, **Delete** (ເກມທັງໝົດ: ທຸກສ່ວນຂອງອິມເມຈ, CFG ຂອງມັນ, ໜ້າປົກ ແລະ ລະຫັດໂກງ; ເຊບພຽງເມື່ອເຈົ້າບອກ), **Set Metadata (Rename)**, ແລະ ສຳລັບ ISO ຫຼື ZSO, **Compress to ZSO** ຫຼື **Uncompress to ISO** (ທົດລອງ: ISO ຍັງຢູ່ຈົນກວ່າ ZSO ຈະຖືກອ່ານຄືນ ແລະ ກວດສອບ). ເກມຂອງແຕ່ລະໄດຣຟ໌ສະແດງທັນທີຈາກລາຍການຫຼ້າສຸດຂອງມັນ, ແລ້ວໄດຣຟ໌ຈຶ່ງຖືກອ່ານຄືນ.
- **MEMORY FILES** ແມ່ນຕົວທ່ອງໄຟລ໌ໃນຕົວ: ສຳເນົາ, ຍ້າຍ ແລະ ລຶບລະຫວ່າງບັດຄວາມຈຳ, USB, MMCE ແລະ HDD (ທຸກການສຳເນົາຖືກອ່ານຄືນເພື່ອກວດສອບ); ເປີດອິມເມຈບັດ VMC ຂອງ OPL ເປັນໂຟນເດີ; ສົ່ງອອກ ແລະ ນຳເຂົ້າເຊບ PSU; ແກ້ໄຂໄຟລ໌ຂໍ້ຄວາມ; ເປີດຮູບ, ຫຼິ້ນວິດີໂອ AVI **ເຕັມຈໍ** ພ້ອມ**ການຄວບຄຸມເຄື່ອງຫຼິ້ນ** (Cross ຫຼິ້ນ/ຢຸດຊົ່ວຄາວ, Circle ຢຸດ, L1/R1 ຂ້າມ 10 ວິນາທີ, L2/R2 ລະດັບສຽງ, START ຫຼິ້ນຊ້ຳ; ຄຳແນະນຳຈາງໄປໃນຂະນະຫຼິ້ນ ແລະ ຍັງຢູ່ເມື່ອຢຸດຊົ່ວຄາວ) ([RIPPS2 Media Studio](tools/media-studio) ປ່ຽນວິດີໂອໃດກໍໄດ້, ລວມທັງ MP4 ຈາກໂທລະສັບ, ເປັນໄຟລ໌ແບບນີ້), ແລະ ຫຼິ້ນໄຟລ໌ `.mp3`, `.ogg` ແລະ `.wav`, ຫຼື ໝາຍຫຼາຍອັນແລ້ວເປີດພ້ອມກັນ ເພື່ອໃຫ້ຫຼິ້ນຄືແຜ່ນໜຶ່ງໃນເຄື່ອງຫຼິ້ນ CD ຂອງ Launch Disc; **`.tar` ແມ່ນໂຟນເດີສີຟ້າ** ທີ່ເຈົ້າເປີດໄດ້, ວາງຮູບເຂົ້າໄປ ແລະ ສຳເນົາສະມາຊິກອອກມາ (ບິວ 125); ສາມຫຼ່ຽມເທິງ `.tar` ລວມ `.tar` ART ອີກອັນເຂົ້າໄປ ([ຂ້າງລຸ່ມ](#covers-from-one-file-art-pack)). **ໂຟນເດີທີ່ເປີດຢູ່ແມ່ນແຖວທຳອິດ**, ພ້ອມຈຳນວນລາຍການ, ຈຳນວນທີ່ໝາຍ, ຂະໜາດລວມ ແລະ ພື້ນທີ່ວ່າງຂອງໄດຣຟ໌; Cross ຫຼື Square ເທິງມັນໝາຍທັງໝົດ (ຫຼື ຍົກເລີກທັງໝົດຖ້າມີອັນໃດໝາຍຢູ່ແລ້ວ). START ເປີດການຕັ້ງຄ່າຂອງມັນ, ບ່ອນທີ່ **SEARCH FILES** ຊອກຫາໄຟລ໌ ຫຼື ໂຟນເດີໃດກໍໄດ້ຕາມຊື່ໃນທຸກໄດຣຟ໌ທີ່ເລີ່ມແລ້ວ ແລະ ເປີດຕົ້ນໄມ້ຢູ່ບ່ອນນັ້ນ. Square ເທິງບັດຄວາມຈຳເປີດ **CARD MANAGER** (ສຳຮອງບັດເປັນ VMC, ຂຽນເຊບຂອງ VMC ໃສ່ບັດ, ລຶບເຊບເກມ, ຟໍແມັດ), ແລະ Square ເທິງ APA HDD ເປີດ **HDD MANAGER** (ພາທິຊັນຂອງມັນ, ຂະໜາດ, ແລະ ລຶບອັນໜຶ່ງຫຼັງຈາກກວດຕາຕະລາງພາທິຊັນທັງໝົດ).

ເປັນ **ເບຕ້າ** ຕັ້ງແຕ່ບິວ 100: ຮ້ອຍບິວອັລຟ້າ, ທົດສອບເທິງເຄື່ອງແທ້ ແລະ ໃນ PCSX2 ໂດຍ ripto, nuno6573, zackcage6, eliminator1403, FifthFox ແລະ Mr.sus.60, ແລະ ໃນເບຕ້າຍັງມີ lukeatmynose ແລະ ahavasi, ພ້ອມທຸກຄົນທີ່ທົດສອບໃນ Discord, ຂອບໃຈເປັນພິເສດສຳລັບຄວາມຮັກທັງໝົດໃນ YouTube. ເກັບຕົວໂຫຼດປະຈຳຂອງເຈົ້າໄວ້ໃກ້ມື ແລະ ບອກພວກເຮົາວ່າຫຍັງເສຍ: ຄຳຕິຊົມຄືສິ່ງທີ່ສ້າງ RIPPS2. **ວິທີທີ່ດີທີ່ສຸດໃຫ້ RIPPS2 ອັບເດດແມ່ນ [issue ໃນ GitHub](https://github.com/akilluminati47/RIPPS2/issues)**: DarkNerdShawny ເປີດໄປສາມອັນ, ແລະ ການແກ້ FreeMcBoot ໃນ v1.1.7 ມາຈາກອັນໜຶ່ງໃນນັ້ນ. ຈົ່ງເປັນຄື DarkNerdShawny.

## ຈຸດເດັ່ນ

- **ທີມທີ່ເຈົ້າເຮັດໃຫ້ເປັນຂອງເຈົ້າໄດ້.** ແຜ່ນແກ້ວຝ້າເທິງຮູບຂອງແຕ່ລະເກມ, ອົງປະກອບ **Grid** ສຳລັບໜ້າປົກ, ການອຽງກ້ານຂວາທີ່ເລື່ອນໜ້າຈໍທັງໝົດຄືເຈ້ຍແຜ່ນດຽວ, ແລະ ຊຸດທຳອິດ, **[RIPPS2-themes](https://github.com/akilluminati47/RIPPS2-themes)**: Adapt ແລະ Adapt Rx, ທຸກການຕັ້ງຄ່າເລີ່ມດ້ວຍອະພິທານຂອງທຸກຄີ, ພ້ອມຕົວກວດ ແລະ ເອກະສານອ້າງອີງຄີ ສຳລັບທຸກຄົນ (ຫຼື ເອເຈັນໃດ) ທີ່ຢາກສ້າງເພີ່ມ. RIPGRID ແລະ RIPFLOW ມີຢູ່ໃນຕົວ, ແລະ ທີມທີ່ສ້າງສຳລັບ Open PS2 Loader ໃຊ້ໄດ້ຕາມເດີມ. ກົດ **SELECT** ຄ້າງໄວ້ 4,2 ວິນາທີໃນລາຍການເກມ ເພື່ອເປີດທີມຂອງເຈົ້າໃນແຜງເລືອກ (Settings > Interface > Hold SELECT: List, Cycle ສຳລັບທີມຖັດໄປ, ຫຼື Off). ໃນ RIPGRID ແລະ RIPFLOW ດັນກ້ານຂວາໄປຂ້າງໜຶ່ງ 0,42 ວິນາທີ ເພື່ອໃຫ້ກ່ອງທີ່ເລືອກໝຸນໄປໜ້າປົກຫຼັງ, ແລະ ຕາຂ່າຍພິກໜ້າດ້ວຍການປັດຄັ້ງດຽວ.
- **ໝວດໝູ່ຢູ່ບ່ອນທີ່ເຈົ້າຕ້ອງການ.** Settings > Interface > Layout > Category Layout: LAUNCH DISC, STORAGE ແລະ MEMORY FILES ເປັນຊື່ **Across the Top**, ເປັນໄອຄອນໃນ **Sidebar** (Classic ຫຼື XL; Left ໃນລາຍການ ຫຼື Circle ເພື່ອເປີດ, ແລະ ແຕ່ລະໝວດມີລິ້ນຊັກຂອງໜ້າຕ່າງໆ), ຫຼື **Menu**: ບໍ່ມີແຖບ, ໝວດໝູ່ຢູ່ໃນເມນູ START, ຄືທີມທີ່ສ້າງສຳລັບ OPL. ໃນ Theme ທີມເປັນຜູ້ຕັດສິນ: ທີມສຳລັບ OPL ໄດ້ Menu, Adapt ໄດ້ແຖບຂ້າງ.
- **RIPFLOW**, ວົງໝຸນໜ້າປົກໃນຕົວ (ແລະ RIPGRID, ກໍໃນຕົວ), ແລະ ແຜ່ນເມື່ອເກມເລີ່ມ (Layout > Launch Disc): **Pop In**, **Spin**, ຫຼື **Zoom** ທີ່ຂະຫຍາຍແຜ່ນໃຫ້ໃຫຍ່ພໍອ່ານໄດ້ ແລະ ຖືໄວ້ຢູ່ນັ້ນ (ຄ່າເລີ່ມຕົ້ນຂອງ RIPFLOW ແລະ Adapt), ຫຼື Off. **Hints and Glyphs** (Interface): ຄຳແນະນຳ, ປ້າຍ ແລະ ສີ່ຊຸດໄອຄອນ (ຂອງທີມ, ຂອງ RIPPS2, Standard ແລະ White) ຈັດວາງ ແລະ ລຽງຕາມໃຈ. **Colors and Text** (Interface): ສິບ Color Themes (RIPPS2, Ember, Blood, Ectoplasm, Amethyst, Bone, Tangerine, Flamingo, Turquoise, Moonlight) ຫຼື Custom, **Color Sweep** ທີ່ໄລ່ຜ່ານຫ້າສີ (Rainbow, ອັນທີ່ສ້າງຈາກແຕ່ລະ Color Theme, ຫຼື ສີຂອງເຈົ້າເອງສູງສຸດສີ່ສີ), ແລະ Text Weight. Layout ມີຄຳແນະນຳ ແລະ ແຖບໝວດໝູ່ທີ່ຈາງໄປ, ແລະ ຊື່ແຫຼ່ງທີ່ຂຶ້ນໃຫຍ່ກາງໜ້າຈໍ. ທີມເລືອກທັງໝົດນີ້ເອງໄດ້, ແລະ ການຕັ້ງຄ່າຂອງເຈົ້າຊະນະສະເໝີ.
- **ສິ່ງທີ່ມັນຕ້ອງການ, ມາພ້ອມ; ສິ່ງທີ່ເຈົ້າມີ, ຖືກພົບ.** [Neutrino](https://github.com/rickgaiser/neutrino) (ບິວລ່າສຸດ) ແລະ BIBLE ຢູ່ໃນ `.elf` ດຽວກັນ ແລະ ຕິດຕັ້ງບ່ອນທີ່ເຈົ້າຕ້ອງການ; POPSTARTER, ໄຟລ໌ POPS ແລະ Ember ຂອງເຈົ້າຖືກຊອກໃນໄດຣຟ໌ເທື່ອດຽວ, ຈື່ໄວ້ ແລະ ເປີດຈາກບ່ອນທີ່ມັນຢູ່. **STATUS** ໃນເມນູ START ສະແດງທຸກໄດຣຟ໌, ບ່ອນທີ່ພົບແຕ່ລະຕົວເປີດ (LOOK FOR THEM ຊອກໃໝ່), homebrew, BIBLE ແລະ ສຽງຂອງເຈົ້າ, ແລະ **SAVE DIAGNOSTICS** ຂຽນ `DIAG.TXT` ສຳລັບລາຍງານຂໍ້ຜິດພາດ.
- **ເປີດເຄື່ອງໄວ.** Settings > Game Sources > Cache > **Fast Boot** ອ່ານພຽງໄດຣຟ໌ຂອງ RIPPS2 ເອງຕອນເປີດເຄື່ອງ: ການຕັ້ງຄ່າ ແລະ ສຽງຂ້າງ `RIPPS2.ELF`, ແລະ ແຕ່ລະລາຍການຈາກແຄຊ. ໄດຣຟ໌ອື່ນລໍຖ້າຈົນເຈົ້າກົດ SELECT ໃນໜ້າຂອງມັນ ຫຼື ເລືອກເກມໃດໜຶ່ງຂອງມັນ. ເກມທີ່ເລືອກໃນຂະນະ RIPPS2 ກຳລັງອ່ານ ຫຼື ຂຽນ ຈະລໍຖ້າຢູ່ຫຼັງແຜງທີ່ບອກວ່າຍັງເຫຼືອຫຍັງ (START NOW ໄປທັນທີ), ດັ່ງນັ້ນການເປີດເກມບໍ່ເຄີຍຕັດການຂຽນເຄິ່ງທາງ.
- **ການຕັ້ງຄ່າຢູ່ບ່ອນທີ່ເຈົ້າຕ້ອງການ**: Settings > General & System > Save Settings To ເກັບມັນໄວ້ໃນເຊບ RIPPS2 ເທິງບັດຄວາມຈຳ, ໃນໂຟນເດີ RIPPS2 ເທິງ HDD ພາຍໃນ (exFAT, ຫຼື ພາທິຊັນ OPL ຂອງ APA HDD), ເທິງໄດຣຟ໌ USB, MX4SIO, iLink ຫຼື MMCE (ອ່ານກ່ອນຕອນເປີດເຄື່ອງ), ຫຼື ໃນໂຟນເດີທີ່ເຈົ້າພິມເອງ.
- **ພາບຢູ່ບ່ອນທີ່ໂທລະທັດຂອງເຈົ້າຕ້ອງການ.** Settings > Interface > Screen: Video Mode (ສູງສຸດ 720p ແລະ 1080i), Widescreen, ແລະ H-POS, V-POS ແລະ Overscan, ຕັ້ງແຕ່ບິວ 124 ເກັບແຍກຕາມໂໝດວິດີໂອ, ດັ່ງນັ້ນ 1080i ແລະ 480i ແຕ່ລະອັນມີການຈັດກາງຂອງມັນເອງ.

- **ເມນູໃນເກມ** (Settings > Game Launching > In-Game Menu, ເປີດເປັນຄ່າເລີ່ມຕົ້ນ): L1+L2+R1+R2+SELECT+START ຢຸດເກມຊົ່ວຄາວ, ປິດສຽງ, ເທິງພາບຂອງມັນເອງ, ເໜືອ Resume, Exit Game, **Screenshot** (RIPSHOT, [ຂ້າງລຸ່ມ](#screenshots-in-game-ripshot)), Achievements ແລະ Power Off (ກົດຄັ້ງທີສອງປິດ PS2 ຢູ່ບ່ອນນັ້ນ); RESUME ກັບຄືນເຟຣມດຽວກັນແທ້ໆ, ແລະ Achievements ລາຍຊື່ສິ່ງທີ່ຍັງເຫຼືອໃຫ້ລ່າ ແລະ ວິທີໄດ້ມັນ. **Exit Game ໄປຕາມເສັ້ນທາງເປີດເຄື່ອງຂອງເຄື່ອງເອງ:** ເມື່ອ IGR Path ໃນໜ້ານັ້ນວ່າງ (ຄ່າເລີ່ມຕົ້ນ), ການຣີເຊັດໄປຫາບຣາວເຊີ ເຊິ່ງເປີດບູດໂຫຼດເດີຖ້າມີຕິດຕັ້ງ (FreeMcBoot, PS2BBL, OSDMenu ຫຼື BIBLE), ແລະ ເມື່ອ Boot Lock ເປີດກໍເປີດ RIPPS2 ອີກ, ຄືກັບເຄື່ອງເລີ່ມຕອນເປີດໄຟ; ຖ້າບໍ່ມີຫຍັງເລີຍ, ແມ່ນບຣາວເຊີ PS2. ຕັ້ງແຕ່ v1.2.1 ບໍ່ເຄີຍເປັນຈໍດຳ: IGR Path ຖືກໃຊ້ພຽງເມື່ອການຣີເຊັດໂຫຼດມັນໄດ້ (ELF ເທິງບັດຄວາມຈຳ ຫຼື ໄດຣຟ໌ USB FAT32) ແລະ ມັນບໍ່ແມ່ນ RIPPS2 ເອງ, ແລະ STATUS ບອກເມື່ອອັນໃດຖືກຂ້າມ.

- **Cover Art** (Settings > Network) ທີ່ PS2 ດາວໂຫຼດເອງສຳລັບທຸກເກມ PS2 ທີ່ບໍ່ມີໜ້າປົກ ຈາກ ps2-covers ຂອງ xlenore ໃນ GitHub (ຕ້ອງມີສາຍເຄືອຂ່າຍ ແລະ ອິນເຕີເນັດ): ເລືອກ **HD** (280 × 400, ຄົມກວ່າໃນຈໍ HD) ຫຼື **Standard** (140 × 200, ຄືໜ້າປົກຂອງ Open PS2 Loader), ທັງສອງ 8 ບິດ ມີ dithering; ເກມທີ່ມີໜ້າປົກແລ້ວຈະເກັບມັນໄວ້ (ບິວ 125). **720p ແລະ 1080i** ຖືກແຕ້ມໃນຮອບດຽວ: ເຟຣມກວ້າງ 640 ພິກເຊລທີ່ມີທຸກເສັ້ນຂອງໂໝດນັ້ນ, ເຊິ່ງວົງຈອນສະແດງຜົນຂອງເຄື່ອງເອງຍືດອອກສູ່ໜ້າຈໍ, ດັ່ງນັ້ນທຸກແອນິເມຊັນຮັກສາຄວາມໄວ. **RIPFLOW ສະແດງຫ້າໜ້າປົກໃນພາບ 16:9** (720p, 1080i, ຫຼື ເປີດ Widescreen) ແລະ ສາມໃນ 4:3, ແລະ ຂະຫຍາຍອອກເອງ ເວັ້ນແຕ່ເຈົ້າເລືອກຈຳນວນ (ບິວ 125). ໂຟນເດີ **AUDIO** ຂອງເຈົ້າຖືກພົບໃນໄດຣຟ໌ໃດກໍໄດ້, ແລະ ຫໍຄອຍ ແລະ ລູກແກ້ວໝຸນຕະຫຼອດຄືນທີ່ 60 fps ຄົງທີ່.

## ເປັນພາສາຂອງເຈົ້າ

ຕັ້ງແຕ່ບິວ 104 ທຸກຄຳທີ່ RIPPS2 ສະແດງຖືກແປແລ້ວ, ທັງໜ້າຈໍ ແລະ ຄຳແນະນຳຂອງມັນເອງ ແລະ ການຕັ້ງຄ່າຂອງ Open PS2 Loader. ທຸກລຸ້ນມາພ້ອມ **`RIPPS2-languages.zip`**: ສຳເນົາໂຟນເດີ `LNG` ຂອງມັນໄປຮາກຂອງໄດຣຟ໌ USB, ພາທິຊັນ OPL ຂອງ HDD ຫຼື ບັດ MMCE (ຫຼື ໄຟລ໌ຂ້າງໃນໄປ `mc0:/RIPPS2`), ແລ້ວເລືອກພາສາໃນ **Settings > Interface > Language**. 33 ພາສາອ່ານ RIPPS2 ໄດ້ຄົບຖ້ວນ, ຕັ້ງແຕ່ພາສາຝຣັ່ງ, ສະເປນ, ເຢຍລະມັນ ແລະ ປອກຕຸຍການ ຈົນຮອດພາສາຣັດເຊຍ, ກຣີກ, ຕວກກີ, ຫວຽດນາມ, ລາວ, ຈີນ, ຍີ່ປຸ່ນ ແລະ ເກົາຫຼີ, ພ້ອມພາສາອາຣັບ ແລະ ເປີເຊຍ ຈາກຂວາຫາຊ້າຍ ໂດຍຕົວອັກສອນຕໍ່ກັນ; ພາສາທີ່ຕ້ອງການຕົວອັກສອນອື່ນມີຟອນຂອງມັນຢູ່ຂ້າງໆໃນຊຸດ. ການແກ້ໄຂ ແລະ ພາສາໃໝ່ໄປທີ່ [`elf/lang`](elf/lang) (`<Language>.yml` ໜຶ່ງອັນຕໍ່ພາສາ; `python3 elf/lang/ripps2lang.py check` ກວດພວກມັນ).

## ຣິບແຜ່ນ

ໃສ່ແຜ່ນໃນເຄື່ອງອ່ານ ແລະ ເປີດ **LAUNCH DISC**. ຫຼັງຈາກສອງສາມວິນາທີ ແຜງແກ້ວຈະສະເໜີ **RIPDISC**: ກົດ **SELECT** ຄ້າງໄວ້ຈົນວົງເຕັມ. ຂັ້ນຕອນຕໍ່ໄປບອກວ່າແຜ່ນແມ່ນຫຍັງ, ໃຫຍ່ເທົ່າໃດ, **ຄວນໃຊ້ເວລາເທົ່າໃດ** ແລະ ຈະໄປບ່ອນໃດ; ຢືນຢັນ, ແລ້ວ **START**.

- **ເກມ PS2** ກາຍເປັນ ISO ໃນໂຟນເດີ DVD ຫຼື CD ຂອງໄດຣຟ໌, ໃນລາຍການເກມຂອງເຈົ້າ. ເກມທີ່ໃຫຍ່ກວ່າ 4 GB ທີ່ໄປໄດຣຟ໌ FAT32 ຈະຖືກເກັບເປັນທ່ອນ 1 GB ແບບ Open PS2 Loader ພ້ອມ ul.cfg ແທນ; ໃນໄດຣຟ໌ exFAT (ແຟລດ USB, MX4SIO, iLink ຫຼື HDD ພາຍໃນ) ມັນຍັງເປັນ ISO ດຽວ. ພື້ນທີ່ໄດຣຟ໌ຖືກກວດກ່ອນເລີ່ມຣິບ.
- **ເກມ PS1** ກາຍເປັນ BIN ແລະ CUE ໃນ `EMBER/games/<Title>/`, ຫຼິ້ນດ້ວຍ Ember.
- **CD ເພງ ຫຼື DVD ວິດີໂອ** ໄປຫາໄຟລ໌ຂອງເຈົ້າ: Memory Files ເປີດທີ່ **MEDIA** (ຂ້າງ AUDIO) ແລະ ແຜ່ນຢູ່ໃນຄລິບບອດເປັນ **RIPPED**; PASTE ໃນໂຟນເດີໃດກໍໄດ້ຈະຣິບມັນໄປບ່ອນນັ້ນ. CD ມາເປັນ WAV (ສຳເນົາອັນໜຶ່ງໄປ AUDIO ແລະ ມັນເຂົ້າໄປໃນເພງເມນູ), DVD ທີ່ເຈົ້າສ້າງເອງມາເປັນໄຟລ໌ VIDEO_TS. ໜັງທີ່ຊື້ມາມີການປ້ອງກັນການສຳເນົາ ແລະ ເຄື່ອງອ່ານຈະບໍ່ອ່ານມັນ.

USB ໃນ PS2 ຊ້າ (USB 1.1, ປະມານ 1 MB ຕໍ່ວິນາທີ): DVD ເຕັມແຜ່ນໄປແຟລດໃຊ້ເວລາຫຼາຍກວ່າໜຶ່ງຊົ່ວໂມງ, ໄປ HDD ພາຍໃນ exFAT ພຽງສ່ວນໜຶ່ງຂອງນັ້ນ. ການປະເມີນຮຽນຮູ້ຄວາມໄວຂອງເຄື່ອງເຈົ້າຈາກການຣິບທຳອິດ.

## ພາບໜ້າຈໍໃນເກມ (RIPSHOT)

ໃນເກມ, L1+L2+R1+R2+SELECT+START ແລ້ວ **SCREENSHOT**: ເຟຣມທີ່ຢູ່ໜ້າຈໍຕອນເມນູເປີດ, ບໍ່ມີເມນູ. ເລືອກ **ART** (ຮູບພາບໜ້າຈໍຂອງເກມ, 250 x 188, `_SCR`, `_SCR2`...), **MEDIA** (ຂະໜາດເຕັມ, ໃນໂຟນເດີຊື່ຕາມເກມ) ຫຼື **BOTH**; ແຕ່ລະອັນສະແດງໄຟລ໌ທີ່ມັນສ້າງ, ຂະໜາດ ແລະ ຈຳນວນພາບທີ່ເຫຼືອ. **SAVE** ເຮັດໃຫ້ເມນູຈາງໄປ, **KEEP** ຫຼື **DELETE** ຕັດສິນ.

ພາບລໍຖ້າເປັນຟິມຂອງເກມໃນ `MEDIA/RIPSHOT` (6 ພາບຕໍ່ເກມ) ເພື່ອລ້າງເປັນ PNG 8 ບິດ: ດ້ວຍມືຈາກ Memory Files (ເປີດ `MEDIA/RIPSHOT`: VIEW ເທິງພາບ, ACTIONS ເພື່ອລ້າງມັນ), ຫຼື ອັດຕະໂນມັດໃນເບື້ອງຫຼັງດ້ວຍ **Develop Shots: Auto** (Settings > Game Launching > In-Game Menu). ທີມສະແດງທຸກພາບຂອງເກມດ້ວຍຄີ `SCRn`: ສະໄລໂຊວ໌ໃນໜ້າຂໍ້ມູນຂອງ RIPPS2, RIPGRID, RIPFLOW ແລະ Adapt ເຮັດແບບນັ້ນ. RIPSHOT ໃຊ້ໄດ້ກັບເກມເທິງ USB, HDD ພາຍໃນ exFAT, MX4SIO, iLink ແລະ ຕັ້ງແຕ່ບິວ 117 ເທິງ MMCE (ບັດ SD ໃນ SD2PSX ເກັບຟິມ); ເກມເທິງ APA HDD ຈະມາໃນບິວຕໍ່ໄປ.

## ສຽງ ແລະ ເພງຂອງເຈົ້າເອງ

ວາງໂຟນເດີ `AUDIO` ຂ້າງ `RIPPS2.elf`. ມັນຮັບເອັບເຟັກສຽງເປັນໄຟລ໌ `.adp` ຕັ້ງຊື່ຕາມເຫດການ (ຂອງ RiptOPL: `boot`, `cancel`, `confirm`, `cursor`, `message`, `transition`, `bd_connect`, `bd_disconnect`, ແລະ ຂອງ RIPPS2: `page_in`, `page_out`, `error`, `save`, `launch`, `disc`, `random`), ແລະ ເພງເປັນ `.ogg` ໃດກໍໄດ້ (Ogg Vorbis ບໍ່ມີແທັກ), `.wav` 16 ບິດ ຫຼື (ຕັ້ງແຕ່ບິວ 115) `.mp3`: `bgm_01 Title.ogg` ແລະ `bgm_02 Title.ogg` ກຳນົດລຳດັບ ແລະ ຊື່ເພງ, ແລະ ຕັ້ງແຕ່ບິວ 105 ຊື່ອື່ນໃດກໍຖືກລາຍຊື່ຕາມເດີມ, ດັ່ງນັ້ນເພງທີ່ຣິບຈາກ CD ບໍ່ຕ້ອງປ່ຽນຊື່. Settings > Audio > Music ເລືອກເພງ. RIPPS2 ຂຽນ `README.txt` ໃນ AUDIO (ແລະ MEDIA) ທີ່ອະທິບາຍທັງໝົດນີ້. **[RIPPS2 Media Studio](tools/media-studio)** ເຮັດທັງໝົດນີ້ເທິງຄອມພິວເຕີຂອງເຈົ້າ (ແລະ ປ່ຽນວິດີໂອຂອງເຈົ້າເປັນ AVI ທີ່ Memory Files ຫຼິ້ນໄດ້): ໄປຫາສຽງ ຫຼື ເພງໃດກໍໄດ້, ຟັງມັນແບບເດີມ ແລະ ແບບທີ່ PS2 ຈະຫຼິ້ນ, ແປງມັນ (ຫຼື ທັງໂຟນເດີ) ໄປ `output/AUDIO`, ແລ້ວສຳເນົາໂຟນເດີນັ້ນໄປຂ້າງ `RIPPS2.elf` ດ້ວຍແຟລດ USB ແລະ Memory Files ຂອງ RIPPS2. ຊີ້ມັນໄປຫາ BIOS dump ຈາກ PS2 ຂອງເຈົ້າເອງ ແລ້ວມັນຈະສ້າງສຽງເມນູ ແລະ ເພງລະບົບຂອງເຄື່ອງຈາກນັ້ນ, ພ້ອມໃຊ້. (`elf/theme/tools/make_adp.py` ແລະ `make_sound_pack.py` ຍັງເຮັດແບບດຽວກັນຈາກແຖວຄຳສັ່ງ.) RIPPS2 ບໍ່ມາພ້ອມສຽງ ຫຼື ເພງໃດໆ: ຕັ້ງແຕ່ບິວ 95 ບໍ່ມີຫຍັງຢູ່ໃນມັນ, ດັ່ງນັ້ນຖ້າບໍ່ມີໂຟນເດີ `AUDIO` ມັນຈະງຽບ, ແລະ **STATUS > SOUNDS** ບອກວ່າມັນພົບຫຍັງ.

**ວາງ AUDIO ແລະ MEDIA ໄວ້ໃສ.** ເກັບ `AUDIO` ໄວ້ຂ້າງ `RIPPS2.elf`, ເທິງໄດຣຟ໌ທີ່ RIPPS2 ເປີດຈາກ: ການເປີດເຄື່ອງອ່ານມັນກ່ອນ, ແລະ ເມື່ອເປີດ **Fast Boot** (Settings > Game Sources > Cache) ສຽງເປີດເຄື່ອງຖືກອ່ານພ້ອມການຕັ້ງຄ່າ, ກ່ອນໄດຣຟ໌ ແລະ ລາຍການຈະເລີ່ມ, ດັ່ງນັ້ນມັນດັງຢູ່ແລ້ວເມື່ອເຟຣມທຳອິດຂອງຫໍຄອຍປາກົດ (ຕັ້ງແຕ່ບິວ 118). RIPPS2 ເທິງບັດຄວາມຈຳ ແລະ `AUDIO` ເທິງໄດຣຟ໌: ຫຼັງ **BIOS Sounds > Rip**, START ສຳເນົາພຽງ `boot.adp` (ປະມານ 360 KB) ໄປຂ້າງ RIPPS2 ເທິງບັດ, ເພື່ອໃຫ້ສຽງເປີດເຄື່ອງດັງເມື່ອເສົາລຸກຂຶ້ນ ບໍ່ແມ່ນເມື່ອໄດຣຟ໌ພ້ອມ (ຕັ້ງແຕ່ບິວ 121). ເກັບໄວ້ບ່ອນນັ້ນພຽງສິ່ງທີ່ເມນູຫຼິ້ນ. `MEDIA` (CD ແລະ DVD ວິດີໂອທີ່ຣິບ, ພາບຂະໜາດເຕັມ) ສຳລັບໄດຣຟ໌ທີ່ໃຫຍ່ທີ່ສຸດຂອງເຈົ້າ: ບໍ່ມີຫຍັງໃນນັ້ນຖືກອ່ານຕອນເປີດເຄື່ອງ, ດັ່ງນັ້ນຄວາມໄວອ່ານຂອງໄດຣຟ໌ນັ້ນບໍ່ສຳຄັນປານໃດ.

### ສຽງທີ່ RIPPS2 ຖືກສ້າງມາພ້ອມ

RIPPS2 ມີສຽງຂອງ PS2 ທີ່ບໍ່ເຄີຍອອກຈາກຫ້ອງຮັບແຂກ: **ສຽງຂອງເຄື່ອງ Sony ເອງ**, ເພງລະບົບຂອງ Sony, ແລະ **ເພງໜຶ່ງຂອງ Nintendo** ຕອນທ່ອງເບິ່ງ (ທາງເລືອກຂອງຜູ້ອອກແບບ RIPPS2 ເອງ). ບໍ່ມີອັນໃດມາພ້ອມ RIPPS2; **[RIPPS2 Media Studio](tools/media-studio)** ພາເຈົ້າໄປຮອດນັ້ນຈາກ [BIOS dump ຈາກ PS2 ຂອງເຈົ້າເອງ](https://pcsx2.net/docs/setup/bios/) (ໄຟລ໌ທີ່ PCSX2 ໃຊ້) ແລະ ເພງທີ່ເຈົ້າມີເອງ. **Start** ຣິບສຽງເຄື່ອງເຫຼົ່ານັ້ນເປັນໂຟນເດີ `AUDIO` ທີ່ສົມບູນ; ນີ້ແມ່ນແຜນທີ່ຂອງບ່ອນທີ່ພວກມັນຢູ່. ຫຼື ຂ້າມຄອມພິວເຕີ: **Settings > Audio > BIOS Sounds > Rip** ຂຽນສຽງຂອງເຄື່ອງເອງໂດຍກົງໃສ່ `AUDIO`: ສຽງເມນູ ແລະ (ຕັ້ງແຕ່ບິວ 89) ເພງເປີດເຄື່ອງ ແລະ ເປີດເກມທີ່ຫຼິ້ນຈາກໂນ້ດຂອງ BIOS ເອງ. <a id="covers-from-one-file-art-pack"></a>

## ໜ້າປົກຈາກໄຟລ໌ດຽວ (ART Pack)

ຕັ້ງແຕ່ບິວ 118, **Settings > Game Sources > Cache > ART Pack** ຫໍ່ໂຟນເດີ `ART` ຂອງທຸກໄດຣຟ໌ທີ່ເລີ່ມແລ້ວ ເປັນ `art.tar` ດຽວ ໃນໂຟນເດີ `ART` ຂອງໄດຣຟ໌ທີ່ເຈົ້າເລືອກ. RIPPS2 ວັດແທກວ່າແຕ່ລະໄດຣຟ໌ອ່ານຮູບຂອງມັນເອງໄວເທົ່າໃດ ແລະ ລາຍຊື່ອັນໄວທີ່ສຸດກ່ອນ ເພື່ອໃຫ້ X ເອົາມັນ (ຕົວຢ່າງ ບັດ SD ໃນ SD2PSX). ຮູບເຂົ້າໄປຕາມເດີມ (PNG ແລະ JPG ຖືກບີບອັດແລ້ວ: tar ພຽງວາງພວກມັນຕໍ່ກັນ, ແລະ ຄອມພິວເຕີເປີດມັນຄື tar ອື່ນໆ), ແລະ ໂຟນເດີ `ART` ບໍ່ຖືກແຕະຕ້ອງ. ຕັ້ງແຕ່ນັ້ນ ໜ້າປົກໂຫຼດຈາກໄຟລ໌ດຽວນັ້ນຜ່ານດັດຊະນີ (ຂຽນພ້ອມຊຸດ, ດັ່ງນັ້ນການເປີດເຄື່ອງເທື່ອທຳອິດບໍ່ຕ້ອງສະແກນ), ແລະ ໂຟນເດີ `ART` ຂອງເກມທີ່ຊຸດຖືກສ້າງໃຫ້ບໍ່ເຄີຍຖືກຖາມເທື່ອລະຮູບ, ແມ່ນແຕ່ຮູບທີ່ຂາດ: ອ່ານໜ້ອຍລົງເທິງໄດຣຟ໌ທີ່ກຳລັງຫຼິ້ນເພງ, ແລະ ໜ້າປົກຕາມເຄີເຊີທັນ. ຮູບທີ່ RIPPS2 ດາວໂຫຼດ ຫຼື ຖ່າຍພາຍຫຼັງສະແດງທັນທີ; ຮູບທີ່ເຈົ້າສຳເນົາເທິງຄອມພິວເຕີສະແດງຫຼັງສ້າງຊຸດໃໝ່. ເຈົ້າສຳເນົາ `art.tar` ໄປໂຟນເດີ `ART` ຂອງໄດຣຟ໌ອື່ນດ້ວຍ Memory Files ໄດ້, ແຕ່ໃຫ້ສ້າງມັນເທິງໄດຣຟ໌ທີ່ເຈົ້າໃຊ້ທ່ອງເບິ່ງ. ປຸ່ມດຽວກັນລຶບຊຸດ.

**ລວມ `.tar` ເຂົ້າກັບອີກອັນ** (ບິວ 123). ຫໍ່ໄດຣຟ໌ໃຫຍ່ເທື່ອດຽວເປັນຕົ້ນສະບັບ, ແລ້ວພາຍຫຼັງຫໍ່ພຽງຮູບຂອງເກມໃໝ່ ແລະ ລວມ `.tar` ນ້ອຍນັ້ນເຂົ້າໄປ, ແທນທີ່ຈະຫໍ່ທຸກໂຟນເດີ ART ໃໝ່. ໃນ Memory Files, ສາມຫຼ່ຽມເທິງ `.tar` > **MERGE A .TAR INTO THIS**: `.tar` ນັ້ນແມ່ນອັນທີ່ເກັບໄວ້, ແລະ RIPPS2 ລາຍຊື່ອັນອື່ນເພື່ອລວມເຂົ້າ (ໃນໂຟນເດີດຽວກັນ, ໃນໂຟນເດີ ART ຂອງແຕ່ລະໄດຣຟ໌ທີ່ເລີ່ມແລ້ວ ແລະ ທີ່ຮາກຂອງມັນ). Cache > ART Pack ສະເໜີແບບດຽວກັນສຳລັບຊຸດທີ່ກຳລັງໃຊ້, ແລະ ທັນທີຫຼັງສ້າງຊຸດ. ຮູບທີ່ມີໃນທັງສອງມາຈາກ `.tar` ທີ່ເພີ່ມ, ແລະ ລາຍການເກມສອງອັນກາຍເປັນອັນດຽວ. ການລວມຖືກຂຽນຂ້າງ `.tar` ທີ່ເກັບໄວ້ ແລະ ໄດ້ຊື່ຂອງມັນພຽງເມື່ອທຸກໄບຢູ່ເທິງໄດຣຟ໌, ດັ່ງນັ້ນການຢຸດ, ໄດຣຟ໌ເຕັມ ຫຼື ບັດທີ່ຖືກດຶງອອກ ຈະປ່ອຍອັນທີ່ເກັບໄວ້ຕາມເດີມ. ໃນທີ່ສຸດກ່ອງໂຕ້ຕອບບອກຊື່ທັງສອງໄຟລ໌ ແລະ ຖາມວ່າຈະລຶບອັນທີ່ເພີ່ມບໍ (START ລຶບ, Back ເກັບ); ອັນທີ່ເກັບໄວ້ບໍ່ເຄີຍຖືກສະເໜີໃຫ້ລຶບ.

## ຮາດແວຂອງເຈົ້າ

- **ອະແດບເຕີເຄືອຂ່າຍ ແລະ HDD ພາຍໃນ.** RIPPS2 ເລີ່ມອະແດບເຕີເຄືອຂ່າຍໃດກໍໄດ້ດ້ວຍໄດຣເວີ DEV9 ຂອງ PS2SDK ເອງ, ອັນທີ່ຕົວໂຫຼດທຸກມື້ນີ້ໃຊ້, ແລະ ແຍກສອງປະເພດໄດ້ເອງ: ອະແດບເຕີຊ່ອງຂະຫຍາຍຂອງເຄື່ອງ fat (SCPH-10281, SCPH-10350, ແລະ ອະແດບເຕີ IDE ແລະ SATA ທີ່ສ້າງຈາກພວກມັນ) ແລະ ພອດໃນຕົວຂອງ slim, ແລະ ອະແດບເຕີ PC CARD ຂອງເຄື່ອງຍີ່ປຸ່ນລຸ້ນທຳອິດ (SCPH-10000 ຫາ 18000). ບໍ່ມີໄດຣເວີເກົ່າໃຫ້ເລືອກ. HDD ຖືກອ່ານຄືກັນບໍ່ວ່າຈະເປັນ APA ຫຼື exFAT, ແລະ ອະແດບເຕີ HDPro ໄດ້ໄດຣເວີຂອງມັນເອງ. ເກມ SMB, UDPBD ແລະ ການດາວໂຫຼດຮູບລ້ວນໃຊ້ອະແດບເຕີດຽວກັນ. ຖ້າອະແດບເຕີຂອງເຈົ້າບໍ່ສະແດງ, ສົ່ງລຸ້ນອະແດບເຕີ ແລະ ລຸ້ນເຄື່ອງມາ.
- **VMC (ບັດຄວາມຈຳສະເໝືອນ).** ການຕັ້ງຄ່າຂອງເກມເອງ (ແຖວ VMC ຂອງມັນ) ໃຫ້ອິມເມຈບັດໃນໂຟນເດີ `VMC` ຂອງໄດຣຟ໌ເກມແກ່ມັນ, ໃນຊ່ອງ 1 ຫຼື 2. ກັບແກນ OPL ພວກມັນໃຊ້ໄດ້ເທິງ USB, MX4SIO, iLink, HDD exFAT, APA HDD, SMB ແລະ MMCE; ເທິງໄດຣຟ໌ FAT32 ຫຼື exFAT ບັດຕ້ອງເປັນໄຟລ໌ດຽວຕໍ່ເນື່ອງ, ເຊິ່ງແມ່ນວິທີທີ່ RIPPS2 ສ້າງບັດໃໝ່, ແລະ **Rebuild** ແກ້ບັດເກົ່າທີ່ບໍ່ເປັນແບບນັ້ນ. ກັບ Neutrino ພວກມັນໃຊ້ໄດ້ເທິງ USB, MX4SIO, iLink ແລະ HDD exFAT, ແຕ່ບໍ່ແມ່ນເທິງ APA HDD, ບ່ອນທີ່ເກມໃຊ້ບັດແທ້ໃນຊ່ອງນັ້ນ. SD2PSX ກໍໃຫ້ແຕ່ລະເກມມີບັດຂອງມັນເອງໄດ້ (GameID ໃນການຕັ້ງຄ່າຂອງມັນ), ບໍ່ຕ້ອງໃຊ້ VMC.
- **Neutrino.** RIPPS2 ມາພ້ອມບິວລ່າສຸດຂອງ Neutrino ແລະ ຕິດຕັ້ງມັນເທື່ອທຳອິດທີ່ເກມຕ້ອງການ. Neutrino ຂອງເຈົ້າເອງ, ບໍ່ວ່າລຸ້ນໃດ, ມາກ່ອນ: ວາງໂຟນເດີ `neutrino` ຂອງມັນເທິງໄດຣຟ໌ຂອງເກມ ຫຼື ບັດຄວາມຈຳ, ຫຼື ໃຫ້ເສັ້ນທາງຂອງມັນໃນ Settings > Game Launching > Neutrino Defaults, ແລະ RIPPS2 ສົ່ງພຽງຕົວເລືອກທີ່ລຸ້ນນັ້ນຮູ້ຈັກ. ຕັ້ງແຕ່ 1.1.5, ເມື່ອ RIPPS2 ເລີ່ມຈາກໄດຣຟ໌ USB ແລະ ເກມຢູ່ເທິງ HDD ພາຍໃນ exFAT, ມັນໄດ້ຮັບເລກໄດຣຟ໌ທີ່ຖືກຕ້ອງ (ການປະສົມນີ້ເຄີຍເຮັດໃຫ້ Neutrino ປິດ ແລະ ເຄື່ອງເປີດໃໝ່).
- **ຈອຍ USB ທີ່ RIPPS2 ບໍ່ເຄີຍຮູ້ຈັກ** (ບິວ 129). **Settings > Controllers > Set Up A USB Pad**: ສຽບຈອຍ, ກົດແຕ່ລະປຸ່ມທີ່ RIPPS2 ຂໍ, ແລ້ວມັນຂຽນໂປຣໄຟລ໌ `.pad` ຂອງຈອຍ (`PADS/VVVV_PPPP.pad` ຂ້າງ RIPPS2, ຂໍ້ຄວາມທຳມະດາ: [ຮູບແບບ](docs/plans/pad-spec.md)). ຈອຍທີ່ມີໂປຣໄຟລ໌ໃຊ້ເມນູໄດ້ ແລະ ຫຼິ້ນເກມເມື່ອເປີດ Pad Emulator; `PADS/GAMES/<game ID>.pad` ສະຫຼັບປຸ່ມສຳລັບເກມດຽວ. **My Pads** ກວດທຸກໂປຣໄຟລ໌ ແລະ ບອກວ່າອັນທີ່ມັນປະຕິເສດຜິດຫຍັງ.
- **ແອັບຄື SMS.** ແອັບເລີ່ມຈາກເສັ້ນທາງຂອງມັນເອງ. SMS (Simple Media System) ອ່ານພຽງແຕ່ນັ້ນ, ດັ່ງນັ້ນ RIPPS2 ບໍ່ສາມາດສົ່ງໄຟລ໌ໃຫ້ມັນຫຼິ້ນໄດ້; ຖ້າ SMS ລຸ້ນໃດຮັບໄຟລ໌, RIPPS2 ຈະສົ່ງມັນໃຫ້.

## ມັນຖືກບິວແນວໃດ

## ລຸ້ນເວັບ

RIPPS2 ເລີ່ມຊີວິດເປັນທີມເວັບ, ແລະ ລຸ້ນນັ້ນຍັງຢູ່ທີ່ນີ້: **ເດໂມສົດ** ທີ່ https://akilluminati47.github.io/RIPPS2/

| ທາງເລືອກ | ເປີດຫຍັງ |
| --- | --- |
| **Launch Disc** | ເສົາ, ພ້ອມການລະເບີດຄູ່ກາງເດີ່ນ |
| **Storage** | ຊັ້ນວາງເອວຟ໌, ຢູ່ໜ້າເສົາ |
| **Memory Files** | ລູກແກ້ວ |

ເຄື່ອງໝາຍ PS2 ເຄື່ອນທີ່ຢູ່ລຸ່ມທາງເລືອກທີ່ເລືອກ ແລະ ບິນລະຫວ່າງພວກມັນ: ໝຸນໜຶ່ງຮອບໄປຫາອັນຂ້າງໆ, ແລະ ດຳລົງເລິກແບບໂຍນຫຼຽນເມື່ອໄປຈາກປາຍໜຶ່ງຫາອີກປາຍ. ປ້າຍຕາມພາສາລະບົບຂອງຜູ້ເຂົ້າຊົມ (18 ພາສາ, ປ່ຽນໄດ້ດ້ວຍ `?lang=fr` ແລະ ອື່ນໆ). ສິ່ງທີ່ຟອນເມນູແຕ້ມບໍ່ໄດ້ ຈະປ່ຽນໄປໃຊ້ຟອນ sans ທີ່ສະອາດເທື່ອລະຄຳ.

**ຊັ້ນວາງເອວຟ໌:** ຕູ້ສະແດງຂອງ Storage. ແຜ່ນໄມ້ uOPL ຢູ່ໜ້າຫໍຄອຍ, ແລະ ເທິງນັ້ນມີເຄື່ອງໝາຍ RIPPS2 ສິບເທື່ອ: ໝວກສັກຫຼາດຂອງເອວຟ໌ທີ່ຕາຍແລ້ວ, ປີກໝວກຄວ່ຳລົງໃນແອ່ງເລືອດຂອງມັນເອງ, ໜຶ່ງອັນຕໍ່ Color Theme (RIPPS2, Ember, Blood, Ectoplasm, Amethyst, Bone, Tangerine, Flamingo, Turquoise, Moonlight). ເຫັນສາມອັນພ້ອມກັນ, ຄືກັບທີ່ RIPFLOW ສະແດງໜ້າປົກ: ໝວກກາງໝຸນໄປເບິ່ງເຄີເຊີ (ຍິ່ງໃກ້ຍິ່ງໝຸນໄວ) ແລະ ແກວ່ງເທິງສະປິງຂອງມັນ, ແລະ Left / Right ຫຼື ແຕະອັນຂ້າງໆຈະໝຸນຊັ້ນວາງ. ມັນຢຸດທີ່ໝວກສີຟ້າ RIPPS2. ໝວກທີ່ຖືກກົດສົ່ງ Color Theme ຂອງມັນໄປຫໍຄອຍ (ມາຕຣິກສີຂອງ ELF ເອງ, ດັ່ງນັ້ນຫໍຄອຍເບິ່ງຄືທີ່ທີມນັ້ນແຕ້ມພວກມັນ): ແຕະເປັນການພຸ່ງຂອງສີຂ້າມເດີ່ນ ແລ້ວກັບຄືນສີຟ້າ RIPPS2; ກົດຄ້າງ ແລ້ວທີມຢູ່ທົ່ວພາບຈົນເຈົ້າປ່ອຍ.

**ໂທລະສັບທີ່ຖືຕັ້ງ** (`letterbox.js`): ເວັບຫຼິ້ນໃນເຄື່ອງຫຼິ້ນແບບ letterbox ຢູ່ເທິງສຸດຂອງໜ້າຈໍ, ເທິງນັ້ນມີພຽງຮອຍບາກກ້ອງ ແລະ ມຸມໂຄ້ງ, ຈັດວາງຄືໜ້າຈໍແນວນອນ ແລະ ຫຍໍ້ໃຫ້ພໍດີ. ຂ້າງລຸ່ມມີລູກສອນຊີ້ຂຶ້ນໄປຫາເຄື່ອງຫຼິ້ນ, ບັນທຶກເຫຼື້ອມທີ່ເຊີນໃຫ້ຖ່າງນິ້ວເພື່ອຊູມ ຫຼື ໝຸນໂທລະສັບ, ແລະ ປຸ່ມສະຫຼັບລະຫວ່າງກອບ 16:9 ແລະ ກອບ 4:3 (ຖືກຈື່ໄວ້); ໝາຍເຫດມຸມລຸ່ມຂວາຂຽນວ່າ RIPPS2 (vision interactive mock-up). ໝຸນໂທລະສັບກໍກັບໄປໜ້າເຕັມ, ທີ່ໜ້າດຽວກັບທີ່ເຄື່ອງຫຼິ້ນສະແດງ. `?letterbox=1` ສະແດງເຄື່ອງຫຼິ້ນເທິງຄອມພິວເຕີຕັ້ງໂຕະ.

**ເສົາ:** ຫໍຄອຍຂໍ້ມູນແກ້ວທີ່ມີຂອບເຫຼື້ອມ, ຮອຍຕໍ່, ເຊລກະພິບ ແລະ ຈັງຫວະພະລັງງານ, ເທິງພື້ນທີ່ສະທ້ອນ. ຫໍຄອຍລຸກຂຶ້ນຈາກພື້ນຕອນໂຫຼດ, ແລ້ວຫາຍໃຈ ແລະ ເປັນຄື້ນ; ເຄີເຊີສົ່ງຄື້ນອອກ ແລະ ການຄລິກເຮັດໃຫ້ລະເບີດ. ມັນປັບຄວາມລະອຽດເທິງອຸປະກອນຊ້າ, ຢຸດເມື່ອອອກນອກຈໍ ແລະ ເຄົາລົບການຕັ້ງຄ່າຫຼຸດການເຄື່ອນໄຫວ.

**ລູກແກ້ວ:** ສິບສອງຮູບແບບ (Browser Orbit, Borromean Rings, Torus Orbit, Icosahedron, Double Helix, Strange Attractor, Trefoil Knot, Mobius Strip, Klein Bottle, Golden Spiral, Lissajous ແລະ Seven-Point Star), ແຕ່ລະອັນໃຊ້ລູກແກ້ວເທົ່າທີ່ມັນຕ້ອງການ, ແຍກອອກ ແລະ ລວມກັນລະຫວ່າງພວກມັນ. ຄື Memory Files ໃນ ELF, ເສັ້ນທາງຂອງແຕ່ລະຮູບຖືກແຕ້ມດ້ວຍແສງເມື່ອແທັບເປີດ ແລະ ທຸກເທື່ອທີ່ຮູບແບບເຂົ້າທີ່, ຢູ່ປະມານສອງວິນາທີ ແລ້ວຈາງໄປ. ກົດຄ້າງເທິງສາກ (ຫຼື ກົດ `L` ຄ້າງ, ຫຼື L2 ຫຼື Cross ຂອງຈອຍ) ເພື່ອເຫັນເສັ້ນທາງທັງໝົດຢູ່ນິ່ງ; ລາກໃນຂະນະກົດຄ້າງເພື່ອໝຸນຮູບແບບ, ມັນເລື່ອນໄປຈົນຢຸດຫຼັງປ່ອຍ (ກ້ານຂວາຂອງຈອຍກໍໝຸນມັນໄດ້). ປ່ຽນດ້ວຍການປັດ, ໄອຄອນ Left / Right ຂ້າງຊື່, ປຸ່ມລູກສອນ, ຫຼື ປຸ່ມທິດທາງ ຫຼື ປຸ່ມບ່າຂອງຈອຍ.

ເພື່ອແລ່ນໃນເຄື່ອງ, ໃຫ້ບໍລິການໂຟນເດີດ້ວຍເຊີບເວີ (ໂມດູນ ES ຕ້ອງການເວັບເຊີບເວີ) ແລະ ເປີດ http://localhost:8000:

```bash
python -m http.server 8000
```

ເພີ່ມ `?t=12` ເພື່ອຂ້າມການເປີດຂອງເສົາ, ຫຼື `?f=3#memory-files` ເພື່ອເປີດຮູບແບບສະເພາະ (ລິ້ງ `orbs.html` ເກົ່າໄປຮອດ Memory Files).
