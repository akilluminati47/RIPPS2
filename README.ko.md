# RIPPS2

> ### 립하세요: RIPPS2 빌드 139, v1.3.9 베타
> **RIP PS2, ELF 킬러.** 혼자서 동작하고 절대 망가뜨리지 않습니다: 다른 ELF는 [선반](https://akilluminati47.github.io/RIPPS2/)에 무사히 남아 있고 (요청하지 않으면 아무것도 지우지 않습니다), 그저 마땅한 휴식을 취할 뿐입니다.
> 1. **[RIPPS2.elf 다운로드](https://github.com/akilluminati47/RIPPS2/releases/latest/download/RIPPS2.elf)** (항상 최신 릴리스) (파일 하나, 2,764 KB), 원하면 **[테마 팩](https://github.com/akilluminati47/RIPPS2-themes/releases/latest)** (Adapt와 Adapt Rx, 에디션 136: 각각 설정 하나와 이미지 하나. RIPGRID와 RIPFLOW는 내장), 그리고 RIPPS2를 내 언어로 쓰기 위한 **[RIPPS2-languages.zip](https://github.com/akilluminati47/RIPPS2/releases/latest/download/RIPPS2-languages.zip)** (33개 언어. 모든 릴리스에 포함).
> 2. USB 메모리나 메모리 카드에 복사하고 FreeMcBoot, PS2BBL, wLaunchELF 등 homebrew를 실행할 때 쓰는 것으로 실행합니다. PCSX2에서는 **System > Start File**에서 `RIPPS2.elf`를 고릅니다.
> 3. 어땠는지 알려 주세요: [psx-place 스레드](https://www.psx-place.com/threads/ripps2-a-ps2-front-end-in-one-elf-launch-disc-storage-memory-files.51316/), [issue](https://github.com/akilluminati47/RIPPS2/issues), 또는 개발자 Discord의 **#RIPPS2**, [discord.gg/Z7m9u5kby](https://discord.gg/Z7m9u5kby) (초대는 2026년 12월 1일까지 유효).

RIPPS2는 하나의 `.elf`에 담긴 PS2 프런트엔드입니다: [RiptOPL](https://github.com/NathanNeurotic/Open-PS2-Loader) (Open PS2 Loader 포크)을 열어 다시 짜고, rickgaiser의 [Neutrino](https://github.com/rickgaiser/neutrino)를 두 번째 게임 코어로 쓰며, 고유의 외관, 런처, 파일 브라우저, 저장소 도구를 갖추었습니다. 유리 탑이 게임 뒤에 서고 궤도 대형이 파일 뒤에 늘어서며, 모두 PS2가 실시간으로 그립니다.

- **LAUNCH DISC**는 PS2, PS1, DVD 비디오 디스크를 실행하고, 실행하기 전에 드라이브에 든 게임을 알려 주며, 음악 CD를 재생하는 동안 탑이 스펙트럼 분석기로 바뀝니다. **RIPDISC** (빌드 105)는 드라이브의 디스크를 립합니다: 게임은 저장소로, CD나 DVD 비디오는 파일로.
- **STORAGE**는 게임 라이브러리입니다: 모든 드라이브를 하나의 목록에 (All Games는 첫 프레임부터 전부 보여 주며, 아직 응답하지 않은 드라이브도 포함합니다), 커버, 이미지가 스크린샷으로 페이드되는 정보 페이지, 게임별 설정, 그리고 R3로 Starred Games에 별을 붙입니다 (별은 행 앞에 붙습니다. Settings > Game Sources > Starred Games Star에서 옮기거나 숨김. R3를 4.2초 누르면 모든 별을 숨기거나 보임). L2 + R2는 무작위 게임으로 건너뛰고, Recent Games는 최근 실행을 기억합니다. 게임에서 세모는 **Hide Game**, **Delete** (게임 전체: 이미지의 모든 부분, 그 CFG, 커버, 치트. 세이브는 요청할 때만), **Set Metadata (Rename)**, ISO나 ZSO라면 **Compress to ZSO** 또는 **Uncompress to ISO** (실험적: ZSO를 다시 읽어 확인할 때까지 ISO는 남습니다)를 엽니다. 각 드라이브의 게임은 마지막 목록에서 바로 보이고, 그 뒤 드라이브를 다시 읽습니다.
- **MEMORY FILES**는 내장 파일 브라우저입니다: 메모리 카드, USB, MMCE, HDD 사이에서 복사, 이동, 삭제 (모든 복사는 다시 읽어 확인). OPL의 VMC 카드 이미지를 폴더처럼 열기. PSU 세이브 내보내기와 가져오기. 텍스트 파일 편집. 이미지를 열고, AVI 영상을 **전체 화면**으로 **플레이어 조작**과 함께 재생 (Cross 재생/일시 정지, Circle 정지, L1/R1 10초 건너뛰기, L2/R2 볼륨, START 반복. 안내는 재생 중에 사라지고 일시 정지 중에는 남습니다) ([RIPPS2 Media Studio](tools/media-studio)는 휴대폰의 MP4를 포함한 어떤 영상이든 이 형식으로 바꿉니다), `.mp3`, `.ogg`, `.wav`를 재생하거나, 여러 개에 표시하고 함께 열면 Launch Disc의 CD 플레이어에서 디스크처럼 재생됩니다. **`.tar`는 파란 폴더**로, 열어서 이미지를 붙여 넣거나 안의 항목을 복사해 꺼낼 수 있습니다 (빌드 125). `.tar`에서 세모는 다른 ART `.tar`를 그 안에 합칩니다 ([아래](#covers-from-one-file-art-pack)). **열린 폴더가 첫 행**이며, 항목 수, 표시한 수, 전체 크기, 드라이브 여유 공간을 보여 줍니다. 거기서 Cross나 Square를 누르면 모두 표시합니다 (무언가 표시되어 있으면 모두 해제). START는 설정을 열고, 그곳의 **SEARCH FILES**는 시작된 어느 드라이브에서든 파일이나 폴더를 이름으로 찾아 그 자리에서 트리를 엽니다. 메모리 카드에서 Square는 **CARD MANAGER** (카드를 VMC로 백업, VMC의 세이브를 카드에 쓰기, 게임 세이브 지우기, 포맷)를, APA HDD에서 Square는 **HDD MANAGER** (파티션, 그 크기, 파티션 테이블을 모두 확인한 뒤의 삭제)를 엽니다.

빌드 100부터 **베타**입니다: 100개의 알파 빌드를 ripto, nuno6573, zackcage6, eliminator1403, FifthFox, Mr.sus.60이 실기와 PCSX2에서 테스트했고, 베타에서는 lukeatmynose와 ahavasi, 그리고 Discord에서 테스트하는 모든 분이 함께했습니다. YouTube에서 보내 준 모든 사랑에도 특별히 감사드립니다. 평소 쓰는 로더도 곁에 두고, 무엇이 망가지는지 알려 주세요: RIPPS2를 만드는 것은 피드백입니다. **RIPPS2를 업데이트하게 하는 가장 좋은 방법은 [GitHub issue](https://github.com/akilluminati47/RIPPS2/issues)입니다**: DarkNerdShawny는 세 개를 열었고, v1.1.7의 FreeMcBoot 수정은 그중 하나에서 나왔습니다. DarkNerdShawny처럼 되세요.

## 주요 기능

- **내 것으로 만들 수 있는 테마.** 각 게임의 아트 위에 반투명 유리 패널, 커버를 위한 **Grid** 요소, 오른쪽 스틱 기울기로 화면 전체를 한 장의 종이처럼 움직이는 기능, 그리고 첫 팩 **[RIPPS2-themes](https://github.com/akilluminati47/RIPPS2-themes)**: Adapt와 Adapt Rx. 모든 설정은 모든 키의 용어집으로 시작하며, 더 만들고 싶은 사람 (또는 에이전트)을 위한 검사기와 키 레퍼런스가 있습니다. RIPGRID와 RIPFLOW는 내장이고, Open PS2 Loader용으로 만든 테마도 그대로 동작합니다. 게임 목록에서 **SELECT**를 4.2초 누르면 테마를 고르는 패널이 열립니다 (Settings > Interface > Hold SELECT: List, Cycle로 다음 테마, 또는 Off). RIPGRID와 RIPFLOW에서는 오른쪽 스틱을 0.42초 한쪽으로 밀면 고른 케이스가 뒷면으로 돌아가고, 그리드는 한 번 쓸어 넘겨 페이지를 넘깁니다.
- **카테고리를 원하는 곳에.** Settings > Interface > Layout > Category Layout: LAUNCH DISC, STORAGE, MEMORY FILES를 이름으로 **Across the Top**, 아이콘으로 **Sidebar** (Classic 또는 XL. 목록에서 Left나 Circle로 열고, 각 카테고리에 페이지 서랍이 있습니다), 또는 **Menu**: 바 없이 카테고리는 START 메뉴에, OPL용 테마처럼. Theme에서는 테마가 정합니다: OPL용 테마는 Menu, Adapt는 사이드바가 됩니다.
- **RIPFLOW**, 내장 커버 캐러셀 (RIPGRID도 내장), 그리고 게임이 시작될 때의 디스크 (Layout > Launch Disc): **Pop In**, **Spin**, 디스크를 읽을 수 있을 만큼 키워 그대로 두는 **Zoom** (RIPFLOW와 Adapt의 기본값), 또는 Off. **Hints and Glyphs** (Interface): 안내, 배지, 네 가지 아이콘 세트 (테마의 것, RIPPS2의 것, Standard, White)의 배치와 순서를 자유롭게. **Colors and Text** (Interface): 10가지 Color Themes (RIPPS2, Ember, Blood, Ectoplasm, Amethyst, Bone, Tangerine, Flamingo, Turquoise, Moonlight) 또는 Custom, 다섯 가지 색을 도는 **Color Sweep** (Rainbow, 각 Color Theme으로 만든 것, 또는 내 색 최대 네 가지), 그리고 Text Weight. Layout에는 사라지는 안내와 카테고리 바, 화면 가운데에 크게 뜨는 소스 이름이 있습니다. 테마는 이 모든 것을 스스로 고를 수 있지만, 내 설정이 항상 우선합니다.
- **필요한 것은 함께, 가진 것은 찾아서.** BIBLE은 같은 하나의 `.elf`에 들어 있고 원하는 곳에 설치됩니다. 내 [Neutrino](https://github.com/rickgaiser/neutrino), POPSTARTER, POPS 파일, 내 Ember는 드라이브에서 한 번 찾아 기억하고 있는 그 자리에서 실행합니다. START 메뉴의 **STATUS**는 모든 드라이브, 각 런처를 찾은 곳 (LOOK FOR THEM으로 다시 찾기), homebrew, BIBLE, 사운드를 보여 주고, **SAVE DIAGNOSTICS**는 버그 보고용 `DIAG.TXT`를 씁니다.
- **빠른 부팅.** Settings > Game Sources > Cache > **Fast Boot**는 전원을 켤 때 RIPPS2 자신의 드라이브만 읽습니다: `RIPPS2.ELF` 옆의 설정과 사운드, 그리고 각 목록은 캐시에서. 다른 드라이브는 그 페이지에서 SELECT를 누르거나 그 게임을 고를 때까지 기다립니다. RIPPS2가 읽거나 쓰는 중에 고른 게임은 남은 작업을 알려 주는 패널 뒤에서 기다리므로 (START NOW로 바로 시작) 실행이 쓰기를 중간에 끊는 일은 없습니다.
- **설정을 원하는 곳에**: Settings > General & System > Save Settings To에서 메모리 카드의 RIPPS2 세이브, 내장 HDD의 RIPPS2 폴더 (exFAT, 또는 APA HDD의 OPL 파티션), USB, MX4SIO, iLink, MMCE 드라이브 (부팅 시 가장 먼저 읽힘), 또는 직접 입력한 폴더에 저장합니다.
- **TV가 원하는 위치에 화면을.** Settings > Interface > Screen: Video Mode (720p와 1080i까지), Widescreen, H-POS, V-POS, Overscan. 빌드 124부터 비디오 모드마다 따로 저장되므로 1080i와 480i가 각자의 중앙 정렬을 가집니다.
- **BIBLE과 BOOT LOCK.** Settings > General & System > Boot Loader > **Manage**는 akilluminati47의 부트로더 **BIBLE**(PS2BBL Extended 포크, 모든 빌드를 akilluminati47가 서명)을 메모리 카드, SD2PSX나 MMCE BOOT 카드, 또는 HDD에 설치하고, 이전 버전을 업데이트하며, 전용 메뉴에서 BIBLE의 배경, 스플래시, 비디오 모드를 설정합니다. **Boot Lock**은 콘솔이 실제로 실행하는 부트로더가 RIPPS2를 실행하도록 설정합니다: PS2BBL과 FreeMcBoot는 바로 실행하고, OSDMenu는 메뉴 맨 위에 두며, 끄면 원래 상태로 돌아갑니다.
- **게임 내 메뉴** (Settings > Game Launching > In-Game Menu, 기본값 켜짐): L1+L2+R1+R2+SELECT+START로 게임을 그 화면 위에서 소리 없이 멈추고, 아래에 Resume, Exit Game, **Screenshot** (RIPSHOT, [아래](#screenshots-in-game-ripshot)), Achievements, Power Off (두 번 누르면 그 자리에서 PS2를 끕니다)를 띄웁니다. RESUME은 정확히 같은 프레임으로 돌아가고, Achievements는 남은 업적과 얻는 방법을 나열합니다. **Exit Game은 콘솔 자신의 부팅 경로를 따릅니다:** 그 페이지의 IGR Path가 비어 있으면 (기본값) 리셋은 브라우저로 가서, 설치되어 있으면 부트로더 (FreeMcBoot, PS2BBL, OSDMenu, BIBLE)를, Boot Lock이 켜져 있으면 다시 RIPPS2를 실행합니다. 전원을 켤 때와 똑같습니다. 아무것도 없으면 PS2 브라우저입니다. v1.2.1부터는 절대 검은 화면이 되지 않습니다: IGR Path는 리셋이 불러올 수 있는 경우 (메모리 카드나 FAT32 USB의 ELF)에, RIPPS2 자신이 아닐 때만 쓰이며, 무시되면 STATUS가 알려 줍니다.
- **Achievements** (SpiritofRA): PC의 [xeRAbora](https://github.com/hacan359/xerabora) 클라이언트를 통한 RetroAchievements 텔레메트리 ([v0.1.0-alpha.18](https://github.com/hacan359/xerabora/releases/tag/v0.1.0-alpha.18)에 고정), 추적 중인 게임의 배지, 트레이의 디스크, 그리고 **YOUR ACCOUNT**: 확인한 모든 게임과 해제한 것. xeRAbora가 네트워크에 열려 있으면 **LEFT TO HUNT**: 잠긴 모든 업적과 얻는 방법.
- **Cover Art** (Settings > Network): 커버가 없는 PS2 게임의 커버를 PS2가 직접 xlenore의 GitHub ps2-covers에서 내려받습니다 (네트워크 케이블과 인터넷 필요). **HD** (280 × 400, HD 화면에서 더 선명) 또는 **Standard** (140 × 200, Open PS2 Loader 커버와 같음)를 고르세요. 둘 다 8비트에 디더링. 이미 커버가 있는 게임은 그것을 유지합니다 (빌드 125). **720p와 1080i**는 한 번에 그려집니다: 그 모드의 모든 줄을 가진 폭 640픽셀의 프레임을 콘솔 자신의 디스플레이 회로가 화면에 늘이므로, 모든 애니메이션이 속도를 유지합니다. **RIPFLOW는 16:9 화면에서 커버 다섯 장을 보여 주고** (720p, 1080i, 또는 Widescreen 켜짐) 4:3에서는 세 장을, 수를 고르지 않으면 스스로 넓어집니다 (빌드 125). **AUDIO** 폴더는 어느 드라이브에서든 찾아지며, 탑과 구슬은 밤새 60 fps로 부드럽게 돕니다.
- **안전 난간**: 모든 빌드는 RiptOPL의 호스트 검사와 RIPPS2 자신의 검사를 통과하며, RIPPS2 파일에 새 경고가 하나라도 있으면 실패합니다.

## 디스크 립하기

디스크를 드라이브에 넣고 **LAUNCH DISC**를 엽니다. 몇 초 뒤 유리 패널이 **RIPDISC**를 권합니다: 링이 찰 때까지 **SELECT**를 누르세요. 다음 단계에서 디스크의 종류, 크기, **걸릴 시간**, 저장 위치를 알려 줍니다. 확인한 뒤 **START**.

- **PS2 게임**은 드라이브의 DVD 또는 CD 폴더에 있는 ISO가 되어 게임 목록에 들어갑니다. FAT32 드라이브로 가는 4 GB가 넘는 게임은 대신 Open PS2 Loader 방식의 1 GB 조각과 ul.cfg로 저장됩니다. exFAT 드라이브 (USB 메모리, MX4SIO, iLink, 내장 HDD)에서는 하나의 ISO로 남습니다. 립을 시작하기 전에 드라이브의 여유 공간을 확인합니다.
- **PS1 게임**은 `EMBER/games/<Title>/`의 BIN과 CUE가 되어 Ember로 플레이할 수 있습니다.
- **음악 CD나 DVD 비디오**는 파일로 갑니다: Memory Files가 **MEDIA** (AUDIO 옆)에서 열리고 디스크는 **RIPPED**로 클립보드에 있습니다. 어느 폴더에서든 PASTE하면 그곳에 립합니다. CD는 WAV로 도착하고 (하나를 AUDIO에 복사하면 메뉴 음악에 들어갑니다), 직접 만든 DVD는 VIDEO_TS 파일로 도착합니다. 구입한 영화는 복사 방지가 있어 드라이브가 읽지 않습니다.

PS2의 USB는 느립니다 (USB 1.1, 초당 약 1 MB): DVD 전체를 USB 메모리에 담으면 한 시간 넘게 걸리고, exFAT 내장 HDD라면 그 몇 분의 일입니다. 예상 시간은 첫 립에서 콘솔의 속도를 학습합니다.

## 게임 중 스크린샷 (RIPSHOT)

게임 중에 L1+L2+R1+R2+SELECT+START, 그리고 **SCREENSHOT**: 메뉴를 열었을 때 화면에 있던 프레임을, 메뉴 없이. **ART** (게임의 스크린샷 이미지, 250 x 188, `_SCR`, `_SCR2`...), **MEDIA** (원본 크기, 게임 이름의 폴더에), 또는 **BOTH**를 고르세요. 각각 만들어질 파일, 크기, 남은 샷 수를 보여 줍니다. **SAVE**로 메뉴가 사라지고, **KEEP**이나 **DELETE**로 결정합니다.

샷은 게임의 필름으로 `MEDIA/RIPSHOT` (게임당 6장)에서 기다렸다가 8비트 PNG로 현상됩니다: Memory Files에서 직접 (`MEDIA/RIPSHOT`을 열고, 샷에서 VIEW, ACTIONS로 현상), 또는 **Develop Shots: Auto** (Settings > Game Launching > In-Game Menu)로 백그라운드에서 자동으로. 테마는 `SCRn` 키로 게임의 모든 샷을 보여 줍니다: RIPPS2 정보 페이지의 슬라이드쇼, RIPGRID, RIPFLOW, Adapt가 그렇게 합니다. RIPSHOT은 USB, exFAT 내장 HDD, MX4SIO, iLink의 게임에서, 빌드 117부터는 MMCE에서도 동작합니다 (SD2PSX의 SD 카드가 필름을 보관). APA HDD의 게임은 이후 빌드에서 지원됩니다.

## 내 사운드와 음악

`RIPPS2.elf` 옆에 `AUDIO` 폴더를 두세요. 효과음은 이벤트 이름의 `.adp` 파일로 받고 (RiptOPL의 것: `boot`, `cancel`, `confirm`, `cursor`, `message`, `transition`, `bd_connect`, `bd_disconnect`, RIPPS2의 것: `page_in`, `page_out`, `error`, `save`, `launch`, `disc`, `random`), 음악은 아무 `.ogg` (태그 없는 Ogg Vorbis), 16비트 `.wav`, 또는 (빌드 115부터) `.mp3`로 받습니다: `bgm_01 Title.ogg`와 `bgm_02 Title.ogg`로 순서와 제목이 정해지고, 빌드 105부터는 다른 이름도 그대로 나열되므로 CD에서 립한 곡의 이름을 바꿀 필요가 없습니다. Settings > Audio > Music에서 곡을 고릅니다. RIPPS2는 AUDIO (와 MEDIA)에 이 모든 것을 설명하는 `README.txt`를 씁니다. **[RIPPS2 Media Studio](tools/media-studio)**는 이 모든 일을 PC에서 합니다 (그리고 영상을 Memory Files가 재생하는 AVI로 바꿉니다): 어떤 소리나 곡으로든 이동해, 원래 소리와 PS2가 재생할 소리를 들어 보고, 그것 (또는 폴더 전체)을 `output/AUDIO`로 변환한 뒤, USB 메모리와 RIPPS2의 Memory Files로 그 폴더를 `RIPPS2.elf` 옆에 복사합니다. 내 PS2의 BIOS 덤프를 지정하면 콘솔의 메뉴 소리와 시스템 음악을 거기서 만들어 바로 쓸 수 있습니다. (`elf/theme/tools/make_adp.py`와 `make_sound_pack.py`는 여전히 명령줄에서 같은 일을 합니다.) RIPPS2는 사운드도 음악도 함께 담지 않습니다: 빌드 95부터 안에 아무것도 없으므로 `AUDIO` 폴더가 없으면 조용하고, **STATUS > SOUNDS**가 찾은 것을 알려 줍니다.

**AUDIO와 MEDIA를 둘 곳.** `AUDIO`는 `RIPPS2.elf` 옆, RIPPS2가 부팅하는 드라이브에 두세요: 부팅 때 가장 먼저 읽히고, **Fast Boot**가 켜져 있으면 (Settings > Game Sources > Cache) 부팅 소리가 설정과 함께, 드라이브와 목록이 시작되기 전에 읽히므로 탑의 첫 프레임이 나타날 때 이미 울리고 있습니다 (빌드 118부터). RIPPS2는 메모리 카드에, `AUDIO`는 드라이브에 있는 경우: **BIOS Sounds > Rip** 뒤 START가 `boot.adp` (약 360 KB)만 카드의 RIPPS2 옆에 복사하므로, 부팅 소리가 드라이브가 준비될 때가 아니라 기둥이 솟을 때 울립니다 (빌드 121부터). 그곳에는 메뉴가 울리는 것만 두세요. `MEDIA` (립한 CD와 DVD 비디오, 원본 크기 샷)는 가장 큰 드라이브용입니다: 부팅 때 아무것도 읽지 않으므로 그 드라이브의 읽기 속도는 크게 상관없습니다.

### RIPPS2를 만들 때의 소리

RIPPS2에서는 거실을 떠난 적 없는 PS2의 소리가 납니다: **Sony 콘솔 자신의 소리**, Sony의 시스템 음악, 그리고 둘러볼 때의 **Nintendo 곡 하나** (RIPPS2 디자이너 자신의 선택). 그중 어느 것도 RIPPS2에 담겨 있지 않습니다. **[RIPPS2 Media Studio](tools/media-studio)**가 [내 PS2의 BIOS 덤프](https://pcsx2.net/docs/setup/bios/) (PCSX2가 쓰는 파일)와 내가 가진 음악에서 그곳으로 데려갑니다. **Start**는 그 콘솔 소리를 완전한 `AUDIO` 폴더로 립합니다. 이것이 그 배치도입니다. 또는 PC를 건너뛰고: **Settings > Audio > BIOS Sounds > Rip**이 콘솔 자신의 소리를 바로 `AUDIO`에 씁니다: 메뉴 소리와 (빌드 89부터) BIOS 자신의 악보로 연주되는 부팅과 게임 시작 음악. 그 옆의 BIOS Music은 메뉴 음악, 시계의 곡 (또는 빨간 화면의 곡, 또는 둘 다: 빌드 112)을 립합니다. **[v1.1.2 사운드 투어](https://akilluminati47.github.io/RIPPS2/media/b112/ripps2-v112-sounds.mp4)**는 부팅 소리부터 게임 실행까지 모두 한 번에 들려줍니다.

<a id="covers-from-one-file-art-pack"></a>

## 파일 하나로 커버를 (ART Pack)

빌드 118부터 **Settings > Game Sources > Cache > ART Pack**은 시작된 모든 드라이브의 `ART` 폴더를, 고른 드라이브의 `ART` 폴더에 있는 하나의 `art.tar`로 묶습니다. RIPPS2는 각 드라이브가 자기 이미지를 얼마나 빨리 읽는지 재고 가장 빠른 것을 맨 앞에 두므로 X로 고를 수 있습니다 (예를 들어 SD2PSX의 SD 카드). 이미지는 그대로 들어갑니다 (PNG와 JPG는 이미 압축되어 있어서 tar는 나란히 놓을 뿐이고, PC는 다른 tar처럼 엽니다). `ART` 폴더는 건드리지 않습니다. 그 뒤로 커버는 그 하나의 파일에서 인덱스를 통해 불러오며 (인덱스는 팩과 함께 쓰이므로 첫 부팅에 스캔이 필요 없음), 팩을 만든 게임의 `ART` 폴더에는 이미지마다 묻지 않습니다. 빠진 이미지조차도: 음악을 재생하는 드라이브의 읽기가 줄고 커버가 커서를 따라잡습니다. RIPPS2가 나중에 내려받거나 찍은 이미지는 바로 보이고, PC에서 복사한 이미지는 팩을 다시 만든 뒤 보입니다. Memory Files로 `art.tar`를 다른 드라이브의 `ART` 폴더에 복사할 수도 있지만, 둘러보는 드라이브에서 만드세요. 같은 버튼으로 팩을 지웁니다.

**`.tar`를 다른 `.tar`에 합치기** (빌드 123). 큰 드라이브를 한 번 마스터로 묶은 뒤, 나중에는 새 게임의 이미지만 묶어서 그 작은 `.tar`를 합치세요. ART 폴더를 모두 다시 묶을 필요가 없습니다. Memory Files에서 `.tar`에서 세모 > **MERGE A .TAR INTO THIS**: 그 `.tar`가 남길 것이 되고, RIPPS2가 합칠 후보를 나열합니다 (같은 폴더, 시작된 각 드라이브의 ART 폴더와 그 루트에서). Cache > ART Pack은 사용 중인 팩에도, 팩을 만든 직후에도 같은 것을 권합니다. 양쪽에 있는 이미지는 추가하는 쪽에서 오고, 두 게임 목록은 하나가 됩니다. 합친 결과는 남길 `.tar` 옆에 쓰이고 모든 바이트가 드라이브에 있을 때만 그 이름을 가지므로, 멈춤, 가득 찬 드라이브, 뽑힌 카드가 있어도 남길 쪽은 그대로입니다. 마지막에 대화 상자가 두 파일 이름을 보여 주고 추가한 쪽을 지울지 묻습니다 (START는 지우고 Back은 유지). 남길 쪽은 결코 후보가 되지 않습니다.

<a id="your-hardware"></a>

## 당신의 하드웨어

- **네트워크 어댑터와 내장 HDD.** RIPPS2는 어떤 네트워크 어댑터든 PS2SDK 자신의 DEV9 드라이버, 요즘 로더가 쓰는 것과 같은 것으로 시작하며, 두 종류를 스스로 구별합니다: 팻 모델 확장 베이의 어댑터 (SCPH-10281, SCPH-10350, 그것으로 만든 IDE와 SATA 어댑터)와 슬림의 내장 포트, 그리고 초기 일본 콘솔 (SCPH-10000부터 18000)의 PC CARD 어댑터. 고를 예전 드라이버는 없습니다. HDD는 APA든 exFAT든 똑같이 읽히고, HDPro 어댑터는 전용 드라이버를 씁니다. SMB 게임, UDPBD, 이미지 다운로드는 모두 같은 어댑터를 씁니다. 어댑터가 보이지 않으면 어댑터와 콘솔의 모델 번호를 보내 주세요.
- **VMC (가상 메모리 카드).** 게임 자신의 설정 (그 VMC 행)에서 게임 드라이브의 `VMC` 폴더에 있는 카드 이미지를 슬롯 1이나 2에 줍니다. OPL 코어에서는 USB, MX4SIO, iLink, exFAT HDD, APA HDD, SMB, MMCE에서 동작합니다. FAT32나 exFAT 드라이브에서는 카드가 연속된 하나의 파일이어야 하며, RIPPS2는 새 카드를 그렇게 만들고 **Rebuild**로 그렇지 않은 오래된 카드를 고칩니다. Neutrino에서는 USB, MX4SIO, iLink, exFAT HDD에서 동작하지만 APA HDD에서는 동작하지 않으며, 그곳에서는 게임이 그 슬롯의 진짜 카드를 씁니다. SD2PSX는 VMC 없이도 게임마다 스스로 카드를 나눌 수 있습니다 (설정의 GameID).
- **Neutrino.** RIPPS2는 어떤 버전이든 내 Neutrino를 씁니다 (빌드 135부터는 담고 있지 않으며, 찾지 못한 게임은 둘 곳을 알려 줍니다): 그 `neutrino` 폴더를 게임의 드라이브나 메모리 카드에 두거나, Settings > Game Launching > Neutrino Defaults에서 경로를 주면, RIPPS2는 그 버전이 아는 옵션만 보냅니다. 1.1.5부터 RIPPS2가 USB 드라이브에서 시작하고 게임이 exFAT 내장 HDD에 있으면 올바른 드라이브 번호가 전달됩니다 (이 조합에서 Neutrino가 닫히고 콘솔이 재부팅되었습니다).
- **RIPPS2가 몰랐던 USB 컨트롤러** (빌드 129). **Settings > Controllers > Set Up A USB Pad**: 컨트롤러를 꽂고 RIPPS2가 요청하는 각 버튼을 누르면 그 컨트롤러의 `.pad` 프로필이 쓰입니다 (RIPPS2 옆의 `PADS/VVVV_PPPP.pad`, 일반 텍스트: [형식](docs/plans/pad-spec.md)). 프로필이 있는 컨트롤러는 메뉴를 조작하고, Pad Emulator를 켜면 게임을 플레이합니다. `PADS/GAMES/<game ID>.pad`로 게임마다 버튼을 바꿀 수 있습니다. **My Pads**는 각 프로필을 확인하고 거부한 것의 문제를 알려 줍니다.
- **SMS 같은 앱.** 앱은 자신의 경로에서 시작합니다. SMS (Simple Media System)는 그것만 읽으므로 RIPPS2는 재생할 파일을 넘길 수 없습니다. 파일을 받는 SMS가 있다면 RIPPS2가 넘깁니다.

<a id="how-it-is-built"></a>

## 빌드 방식

`elf/build.sh`는 `elf/RIPTOPL_REF`에 적힌 커밋의 RiptOPL을 가져와 `elf/patches`의 패치 묶음을 적용하고, `elf/theme`에서 RIPPS2의 테마, 글꼴, 이미지를 더해 `RIPPS2.elf`를 빌드합니다. GitHub Actions가 푸시할 때마다 실행하며 ("Build RIPPS2.elf"), 그 결과물 ELF가 릴리스입니다.

<a id="the-web-version"></a>

## 웹 버전

RIPPS2는 웹 테마로 시작했고, 그 버전은 지금도 여기 있습니다: **라이브 데모** https://akilluminati47.github.io/RIPPS2/

| 항목 | 여는 것 |
| --- | --- |
| **Launch Disc** | 기둥, 필드 가운데의 이중 폭발과 함께 |
| **Storage** | 기둥 앞의 엘프 선반 |
| **Memory Files** | 구슬 |

PS2 마크는 선택한 항목 아래에서 움직이며 항목 사이를 날아다닙니다: 이웃으로는 한 바퀴, 끝에서 끝으로는 동전 던지기 같은 깊은 다이빙. 라벨은 방문자의 시스템 언어를 따릅니다 (18개 언어, `?lang=fr` 등으로 바꿀 수 있음). 메뉴 글꼴로 그릴 수 없는 것은 단어 단위로 깔끔한 산세리프로 바뀝니다.

**엘프 선반:** Storage의 진열장. 탑 앞의 uOPL 나무판, 그 위에 RIPPS2 마크가 열 개: 죽은 엘프의 펠트 모자가 챙을 아래로 하고 자기 피 웅덩이에 서 있습니다. Color Theme마다 하나 (RIPPS2, Ember, Blood, Ectoplasm, Amethyst, Bone, Tangerine, Flamingo, Turquoise, Moonlight). RIPFLOW가 커버를 보여 주듯 한 번에 세 개가 보이며, 가운데 모자는 커서를 향해 돌고 (가까울수록 빨리 돕니다) 스프링 위에서 흔들립니다. Left / Right나 이웃을 탭하면 선반이 돕니다. 파란 RIPPS2 모자에서 멈춥니다. 누른 모자는 자기 Color Theme을 탑에 보냅니다 (ELF 자신의 색 행렬이므로 탑은 그 테마가 그리는 그대로 보입니다): 탭하면 필드를 가로지르는 색의 분출 후 RIPPS2 파랑으로 돌아오고, 누르고 있으면 놓을 때까지 테마가 화면 전체에 남습니다.

**세로로 든 휴대폰** (`letterbox.js`): 사이트는 화면 위쪽의 레터박스 플레이어에서 재생되며, 그 위에는 카메라 노치와 둥근 모서리뿐입니다. 가로 화면처럼 배치되고 맞게 축소됩니다. 그 아래에는 플레이어를 가리키는 위쪽 화살표, 두 손가락으로 확대하거나 휴대폰을 돌리라는 빛나는 메모, 16:9와 4:3 틀을 바꾸는 버튼 (기억됨)이 있습니다. 오른쪽 아래 각주는 RIPPS2 (vision interactive mock-up)라고 적혀 있습니다. 휴대폰을 돌리면 전체 페이지로 돌아가며, 플레이어가 보여 주던 페이지 그대로입니다. `?letterbox=1`은 데스크톱에서도 플레이어를 보여 줍니다.

**기둥:** 빛나는 모서리, 이음매, 반짝이는 셀, 에너지 펄스를 지닌 유리 데이터 탑이 반사하는 바닥 위에. 탑은 불러올 때 땅에서 솟은 뒤 숨 쉬고 출렁입니다. 커서는 물결을 보내고 클릭은 폭발을 일으킵니다. 느린 기기에서는 해상도를 맞추고, 화면 밖에서는 멈추며, 동작 줄이기 설정을 존중합니다.

**구슬:** 열두 가지 대형 (Browser Orbit, Borromean Rings, Torus Orbit, Icosahedron, Double Helix, Strange Attractor, Trefoil Knot, Mobius Strip, Klein Bottle, Golden Spiral, Lissajous, Seven-Point Star). 각각 필요한 만큼의 구슬을 쓰며, 대형 사이에서 갈라지고 합쳐집니다. ELF의 Memory Files처럼, 탭이 열릴 때와 대형이 자리 잡을 때마다 각 모양의 궤적이 빛으로 그려지고 약 2초 남았다가 사라집니다. 장면을 누르고 있으면 (또는 `L`, 컨트롤러의 L2나 Cross를 누르고 있으면) 궤적 전체를 멈춘 채로 봅니다. 누른 채 끌면 대형이 돌고, 놓으면 미끄러지다 멈춥니다 (컨트롤러의 오른쪽 스틱으로도 돕니다). 스와이프, 이름 옆의 Left / Right 아이콘, 화살표 키, 컨트롤러의 방향 버튼이나 숄더 버튼으로 바꿉니다.

로컬에서 실행하려면 폴더를 서버로 제공하고 (ES 모듈에는 웹 서버가 필요) http://localhost:8000 을 엽니다:

```bash
python -m http.server 8000
```

`?t=12`를 붙이면 기둥 인트로를 건너뛰고, `?f=3#memory-files`로 특정 대형을 엽니다 (예전 `orbs.html` 링크는 Memory Files로 갑니다).

GPL-3.0 라이선스와 소스는 [`elf/bible`](elf/bible/README.md)에 있습니다. 빌드 138부터 카드 연결은 El Isra의 [KELFBinder](https://github.com/israpps/KELFBinder) IOPRP 이미지를 부팅합니다 (GPL-3.0, [`elf/kelfbinder`](elf/kelfbinder/README.md)에 데이터로 포함). 암호화는 본체가 하며 키는 필요 없습니다.

RIPPS2는 먼저 카드에 물어보므로, 오래된 펌웨어라면 무엇이든 시작하기 전에 알 수 있고 그곳에서는 압축할 수 없습니다. 카드는 여유 공간을 알려 줄 수 없으므로 1.4.0에서도 압축 전 공간 확인은 없습니다: 게임과 그 ZSO가 나란히 들어갈 공간을 남겨 두세요 (카드가 가득 차면 작업이 멈추고 쓴 것을 지웁니다).
- [wLaunchELF](https://github.com/ps2homebrew/wLaunchELF), ps2homebrew 팀, 그리고 wLaunchELF R3Z, NathanNeurotic: Memory Files 브라우저와 그 설정 그리드의 동작 모델.
