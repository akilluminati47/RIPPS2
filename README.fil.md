# RIPPS2

> ### I-rip na: RIPPS2 build 135, v1.3.5 beta
> **RIP PS2, ang pumapatay ng ELF.** Kaya nang mag-isa at hindi kailanman nakasisira: ligtas pa ring nakalagay sa [estante](https://akilluminati47.github.io/RIPPS2/) ang iba mong ELF (walang binubura maliban kung hilingin mo), nakakakuha lang sila ng pahingang nararapat sa kanila.
> 1. **[I-download ang RIPPS2.elf](https://github.com/akilluminati47/RIPPS2/releases/latest/download/RIPPS2.elf)** (laging ang pinakabagong release) (isang file, 2,580 KB), at kung gusto mo ang **[theme pack](https://github.com/akilluminati47/RIPPS2-themes/releases/latest)** (Adapt at Adapt Rx, edisyon 128: tig-isang config at isang larawan; built in na ang RIPGRID at RIPFLOW), at ang **[RIPPS2-languages.zip](https://github.com/akilluminati47/RIPPS2/releases/latest/download/RIPPS2-languages.zip)** para sa RIPPS2 sa sarili mong wika (33 wika; kasama sa bawat release).
> 2. Kopyahin ito sa USB stick o memory card at patakbuhin mula sa FreeMcBoot, PS2BBL, wLaunchELF, o anumang ginagamit mo sa homebrew. Sa PCSX2: **System > Start File** at piliin ang `RIPPS2.elf`.
> 3. Sabihin sa amin kung kumusta: ang [thread sa psx-place](https://www.psx-place.com/threads/ripps2-a-ps2-front-end-in-one-elf-launch-disc-storage-memory-files.51316/), [isang issue](https://github.com/akilluminati47/RIPPS2/issues), o ang **#RIPPS2** sa Discord ng mga developer, [discord.gg/Z7m9u5kby](https://discord.gg/Z7m9u5kby) (may bisa ang imbitasyon hanggang Disyembre 1, 2026).
>

Ang RIPPS2 ay isang PS2 front end sa iisang `.elf`: ang [RiptOPL](https://github.com/NathanNeurotic/Open-PS2-Loader) (isang fork ng Open PS2 Loader) na binuksan at binuo muli, kasama ang [Neutrino](https://github.com/rickgaiser/neutrino) ni rickgaiser bilang pangalawang game core, at may sarili nitong itsura, mga launcher, file browser, at mga storage tool. Nakatayo ang mga toreng salamin sa likod ng mga laro mo, nakahanay ang mga orbital formation sa likod ng mga file mo, at lahat ay iginuguhit nang live ng PS2.

- Pinapatakbo ng **LAUNCH DISC** ang mga disc ng PS2, PS1, at DVD video, sinasabi kung anong laro ang nasa drive bago ito patakbuhin, at nagpapatugtog ng audio CD habang nagiging spectrum analyser ang mga tore. Nire-rip ng **RIPDISC** (build 105) ang disc sa drive: ang laro sa storage mo, ang CD o DVD video sa mga file mo.
- Ang **STORAGE** ang iyong game library: lahat ng drive sa iisang listahan (ipinapakita ng All Games ang lahat mula sa unang frame, pati ang drive na hindi pa sumasagot), may mga cover, info page na ang larawan ay unti-unting nagiging screenshot, mga setting para sa bawat laro, at R3 para lagyan ng bituin ang laro sa Starred Games (nasa simula ng hanay ang bituin; inililipat o itinatago ito ng Settings > Game Sources > Starred Games Star; pindutin nang matagal ang R3 nang 4.2 segundo para itago o ipakita ang lahat ng bituin). Tumatalon ang L2 + R2 sa random na laro, at tinatandaan ng Recent Games ang mga huling pinatakbo mo. Binubuksan ng Triangle sa isang laro ang **Hide Game**, **Delete** (ang buong laro: bawat bahagi ng image, ang CFG nito, mga cover at cheat; ang mga save kung sasabihin mo lang), **Set Metadata (Rename)**, at para sa ISO o ZSO, **Compress to ZSO** o **Uncompress to ISO** (eksperimental: nananatili ang ISO hanggang mabasa muli at masuri ang ZSO). Agad lumalabas ang mga laro ng bawat drive mula sa huling listahan nito, saka binabasa muli ang drive.
- Ang **MEMORY FILES** ay built-in na file browser: kopyahin, ilipat, at burahin sa pagitan ng memory card, USB, MMCE, at HDD (binabasa muli ang bawat kopya para masuri); buksan ang mga VMC card image ng OPL bilang folder; mag-export at mag-import ng PSU save; mag-edit ng text file; magbukas ng larawan, magpatugtog ng AVI video **nang full screen** na may **kontrol ng player** (Cross play/pause, Circle stop, L1/R1 lumaktaw ng 10 segundo, L2/R2 volume, START ulitin; naglalaho ang mga gabay habang tumutugtog at nananatili kapag naka-pause) (kino-convert ng [RIPPS2 Media Studio](tools/media-studio) ang anumang video, pati MP4 ng telepono, sa ganoong file), at magpatugtog ng mga file na `.mp3`, `.ogg`, at `.wav`, o markahan ang ilan at buksan nang sabay para tumugtog na parang isang disc sa CD player ng Launch Disc; **ang `.tar` ay isang asul na folder** na mabubuksan mo, malalagyan ng larawan, at makokopyahan ng mga laman palabas (build 125); pinagsasama ng Triangle sa isang `.tar` ang isa pang ART `.tar` dito ([sa ibaba](#covers-from-one-file-art-pack)). **Ang bukas na folder ang unang hanay**, kasama ang bilang ng entry, bilang ng minarkahan, kabuuang laki, at libreng espasyo ng drive; minamarkahan ng Cross o Square dito ang lahat (o wala, kung may minarkahan na). Binubuksan ng START ang mga setting nito, kung saan hinahanap ng **SEARCH FILES** ang anumang file o folder ayon sa pangalan sa bawat nasimulang drive at binubuksan ang tree doon mismo. Binubuksan ng Square sa memory card ang **CARD MANAGER** (i-back up ang card sa VMC, isulat ang mga save ng VMC sa card, burahin ang mga save ng laro, i-format), at binubuksan ng Square sa APA HDD ang **HDD MANAGER** (ang mga partition nito, ang mga laki nito, at ang pagbura ng isa matapos ang buong pagsusuri ng partition table).

Nasa **beta** mula build 100: isandaang alpha build, sinubukan sa console at sa PCSX2 nina ripto, nuno6573, zackcage6, eliminator1403, FifthFox, at Mr.sus.60, at sa beta pati nina lukeatmynose at ahavasi, at ng lahat ng sumusubok sa Discord, na may espesyal na pasasalamat sa lahat ng pagmamahal sa YouTube. Itabi ang karaniwan mong loader at sabihin sa amin kung ano ang nasisira: ang feedback ang bumubuo sa RIPPS2. **Ang pinakamagandang paraan para ma-update ang RIPPS2 ay [isang issue sa GitHub](https://github.com/akilluminati47/RIPPS2/issues)**: tatlo ang binuksan ni DarkNerdShawny, at galing sa isa sa mga iyon ang ayos sa FreeMcBoot sa v1.1.7. Maging tulad ni DarkNerdShawny.

## Mga tampok

- **Mga theme na maaari mong gawing sarili mo.** Mga panel na frosted glass sa ibabaw ng art ng bawat laro, isang elementong **Grid** para sa mga cover, pagtagilid ng kanang stick na gumagalaw sa buong screen na parang isang pahina, at ang unang pack, **[RIPPS2-themes](https://github.com/akilluminati47/RIPPS2-themes)**: Adapt at Adapt Rx, bawat config ay nagsisimula sa glosaryo ng lahat ng key, may checker at key reference para sa sinuman (o anumang agent) na gustong gumawa pa. Built in ang RIPGRID at RIPFLOW, at gumagana nang ganoon din ang mga theme na ginawa para sa Open PS2 Loader. Pindutin nang matagal ang **SELECT** nang 4.2 segundo sa listahan ng laro para buksan ang mga theme mo sa isang panel na mapagpipilian (Settings > Interface > Hold SELECT: List, Cycle para sa susunod na theme, o Off). Sa RIPGRID at RIPFLOW, itulak ang kanang stick sa isang gilid nang 0.42 segundo para umikot ang napiling case sa likurang cover nito, at nililipat ng grid ang mga pahina sa isang hagod.
- **Mga kategorya kung saan mo gusto.** Settings > Interface > Layout > Category Layout: LAUNCH DISC, STORAGE, at MEMORY FILES bilang mga pangalan **Across the Top**, bilang mga icon sa **Sidebar** (Classic o XL; binubuksan ito ng Left sa listahan o ng Circle, at may drawer ng mga pahina ang bawat kategorya), o **Menu**: walang bar, nasa START menu ang mga kategorya, gaya ng theme na ginawa para sa OPL. Sa Theme, ang theme ang nagpapasya: Menu ang nakukuha ng theme para sa OPL, sidebar naman ang Adapt.
- **RIPFLOW**, ang built-in na cover carousel (at RIPGRID, built in din), at isang disc kapag nagsisimula ang laro (Layout > Launch Disc): **Pop In**, **Spin**, o **Zoom** na pinalalaki ang disc hanggang mabasa at hinahawakan doon (default ng RIPFLOW at Adapt), o Off. **Hints and Glyphs** (Interface): mga gabay, badge, at apat na set ng icon (sa theme, sa RIPPS2, Standard, at White) na inaayos at pinagsusunod-sunod ayon sa gusto mo. **Colors and Text** (Interface): sampung Color Themes (RIPPS2, Ember, Blood, Ectoplasm, Amethyst, Bone, Tangerine, Flamingo, Turquoise, Moonlight) o Custom, isang **Color Sweep** na dumaraan sa limang kulay (Rainbow, isang gawa mula sa bawat Color Theme, o hanggang apat na sarili mong kulay), at Text Weight. May mga gabay at category bar ang Layout na naglalaho, at pangalan ng source na lumalaki sa gitna ng screen. Kayang piliin ng mga theme ang lahat ng ito, at palaging nananaig ang mga setting mo.
- **Ang kailangan nito, kasama na; ang mayroon ka, natatagpuan.** Nasa loob ng iisang `.elf` ang BIBLE at naiinstall ito kung saan mo gusto; hinahanap nang isang beses sa mga drive mo ang sarili mong [Neutrino](https://github.com/rickgaiser/neutrino), POPSTARTER, mga POPS file, at sarili mong Ember, tinatandaan, at pinapatakbo kung nasaan sila. Ipinapakita ng **STATUS** sa START menu ang bawat drive, kung saan natagpuan ang bawat launcher (naghahanap muli ang LOOK FOR THEM), homebrew, BIBLE, at ang mga tunog mo, at isinusulat ng **SAVE DIAGNOSTICS** ang `DIAG.TXT` para sa bug report.
- **Mabilis na boot.** Ang Settings > Game Sources > Cache > **Fast Boot** ay binabasa lang ang sariling drive ng RIPPS2 sa pag-on: ang mga setting at tunog sa tabi ng `RIPPS2.ELF`, at bawat listahan mula sa cache nito. Naghihintay ang ibang drive hanggang pindutin mo ang SELECT sa pahina nila o pumili ng isa sa kanilang mga laro. Ang larong pinili habang nagbabasa o nagsusulat ang RIPPS2 ay naghihintay sa likod ng panel na nagsasabi kung ano pa ang natitira (agad tumatakbo sa START NOW), kaya hindi kailanman napuputol ng paglulunsad ang isang pagsusulat.
- **Ang mga setting mo kung saan mo gusto**: iniimbak ito ng Settings > General & System > Save Settings To sa RIPPS2 save ng memory card, sa folder na RIPPS2 sa internal HDD (exFAT, o ang OPL partition ng APA HDD), sa USB, MX4SIO, iLink, o MMCE drive (unang binabasa sa boot), o sa folder na ita-type mo.
- **Ang larawan kung saan ito gusto ng TV mo.** Settings > Interface > Screen: Video Mode (hanggang 720p at 1080i), Widescreen, at H-POS, V-POS, at Overscan, na mula build 124 ay hiwalay na iniimbak para sa bawat video mode, kaya may kanya-kanyang pagsentro ang 1080i at 480i.
- **BIBLE at BOOT LOCK.** Ipinapakita ng Settings > General & System > Boot Loader kung ano ang pinapatakbo ng bawat memory card sa pag-on at iniinstall ang **BIBLE**, ang PS2BBL na inihanda para sa RIPPS2, sa memory card. Inaayos ng **Boot Lock** ang bootloader na talagang pinapatakbo ng console mo para patakbuhin ang RIPPS2: agad itong pinapatakbo ng PS2BBL at FreeMcBoot, inilalagay ito ng OSDMenu sa unahan ng menu nito, at ibinabalik ng pag-off ang dati.
- **Menu sa loob ng laro** (Settings > Game Launching > In-Game Menu, naka-on bilang default): pinapahinto ng L1+L2+R1+R2+SELECT+START ang laro, walang tunog, sa ibabaw ng sarili nitong larawan, sa itaas ng Resume, Exit Game, **Screenshot** (RIPSHOT, [sa ibaba](#screenshots-in-game-ripshot)), Achievements, at Power Off (pinapatay ng ikalawang pindot ang PS2 doon mismo); ibinabalik ng RESUME ang eksaktong parehong frame, at inililista ng Achievements kung ano pa ang hahanapin at paano ito makukuha. **Dumadaan ang Exit Game sa sariling boot path ng console:** kapag blangko ang IGR Path sa pahinang iyon (default), pumupunta ang reset sa browser, na nagpapatakbo ng bootloader kung may naka-install (FreeMcBoot, PS2BBL, OSDMenu, o BIBLE), at kapag naka-on ang Boot Lock ay RIPPS2 muli, eksakto gaya ng pagsisimula ng console sa pag-on; kung wala, ang PS2 browser. Mula v1.2.1 hindi kailanman itim na screen: ginagamit lang ang IGR Path kapag kaya itong i-load ng reset (ELF sa memory card o FAT32 USB drive) at hindi ito ang RIPPS2 mismo, at sinasabi ng STATUS kapag may nilaktawan.
- **Achievements** (SpiritofRA): RetroAchievements telemetry sa pamamagitan ng [xeRAbora](https://github.com/hacan359/xerabora) client sa PC mo (naka-pin sa [v0.1.0-alpha.18](https://github.com/hacan359/xerabora/releases/tag/v0.1.0-alpha.18)), mga badge sa mga sinusubaybayang laro, ang disc sa tray, at **YOUR ACCOUNT**: bawat larong nasuri mo kasama ang na-unlock mo, at kapag bukas sa network ang xeRAbora, **LEFT TO HUNT**: bawat naka-lock na achievement at kung paano ito makukuha.
- **Cover Art** (Settings > Network) na ang PS2 mismo ang nagda-download para sa bawat PS2 game na walang cover, mula sa ps2-covers ni xlenore sa GitHub (kailangan ng network cable at internet): piliin ang **HD** (280 × 400, mas matalas sa HD screen) o **Standard** (140 × 200, gaya ng mga cover ng Open PS2 Loader), parehong 8-bit na may dithering; pinananatili ng larong may cover na ang cover nito (build 125). **Iginuguhit ang 720p at 1080i sa isang pass**: isang frame na 640 pixel ang lapad na may lahat ng linya ng mode na iyon, na iniuunat sa screen ng sariling display circuit ng console, kaya napananatili ng bawat animation ang bilis nito. **Limang cover ang ipinapakita ng RIPFLOW sa 16:9 na larawan** (720p, 1080i, o naka-on ang Widescreen) at tatlo sa 4:3, at kusang lumalapad maliban kung pipili ka ng bilang (build 125). Natatagpuan ang **AUDIO** folder mo sa anumang drive, at umiikot buong gabi ang mga tore at bola sa matatag na 60 fps.
- **Mga harang pangkaligtasan**: dumaraan ang bawat build sa mga host check ng RiptOPL at sa sariling mga check ng RIPPS2, at isang bagong babala lang sa isang RIPPS2 file ay sapat para bumagsak ito.

## Sa sarili mong wika

Mula build 104, isinalin ang bawat salitang ipinapakita ng RIPPS2, ang sarili nitong mga screen at gabay pati ang mga setting ng Open PS2 Loader. Kasama ng bawat release ang **`RIPPS2-languages.zip`**: kopyahin ang `LNG` folder nito sa root ng USB drive, sa OPL partition ng HDD, o sa MMCE card (o ang mga file sa loob nito sa `mc0:/RIPPS2`), saka piliin ang wika sa **Settings > Interface > Language**. 33 wika ang bumabasa nang buo sa RIPPS2, mula French, Spanish, German, at Portuguese hanggang Russian, Greek, Turkish, Vietnamese, Lao, Chinese, Japanese, at Korean, at Arabic at Persian mula kanan pakaliwa na magkakadugtong ang mga titik; may sariling font sa tabi nito sa pack ang wikang nangangailangan ng ibang sulat. Pumupunta sa [`elf/lang`](elf/lang) ang mga ayos at bagong wika (isang `<Language>.yml` bawat wika; sinusuri ang mga ito ng `python3 elf/lang/ripps2lang.py check`).

## Mag-rip ng disc

Ilagay ang disc sa drive at buksan ang **LAUNCH DISC**. Pagkalipas ng ilang segundo, nag-aalok ng **RIPDISC** ang isang glass panel: pindutin nang matagal ang **SELECT** hanggang mapuno ang singsing. Sinasabi ng susunod na hakbang kung ano ang disc, gaano kalaki, **gaano katagal ito dapat tumagal** at saan ito pupunta; kumpirmahin, saka **START**.

- **Ang PS2 game** ay nagiging ISO sa DVD o CD folder ng isang drive, sa listahan ng mga laro mo. Ang larong mas malaki sa 4 GB na pupunta sa FAT32 drive ay iniimbak bilang mga 1 GB na bahagi sa istilong Open PS2 Loader na may ul.cfg; sa exFAT drive (USB stick, MX4SIO, iLink, o internal HDD) nananatili itong iisang ISO. Sinusuri ang espasyo ng drive bago magsimula ang rip.
- **Ang PS1 game** ay nagiging BIN at CUE sa `EMBER/games/<Title>/`, na nilalaro gamit ang Ember.
- **Ang audio CD o DVD video** ay napupunta sa mga file mo: bumubukas ang Memory Files sa **MEDIA** (katabi ng AUDIO) at nasa clipboard ang disc bilang **RIPPED**; ang PASTE sa anumang folder ay nire-rip ito doon. Dumarating ang CD bilang WAV (kopyahin ang isa sa AUDIO at kasama na ito sa musika ng menu), ang sarili mong DVD bilang mga VIDEO_TS file. May copy protection ang mga biniling pelikula at hindi ito babasahin ng drive.

Mabagal ang USB sa PS2 (USB 1.1, mga 1 MB bawat segundo): mahigit isang oras ang buong DVD sa USB stick, at maliit na bahagi lang niyon sa exFAT internal HDD. Natututunan ng tantiya ang bilis ng console mo mula sa una mong rip.

<a id="your-own-sounds-and-music"></a>

## Sarili mong mga tunog at musika

Maglagay ng `AUDIO` folder sa tabi ng `RIPPS2.elf`. Tumatanggap ito ng mga sound effect bilang mga `.adp` file na ipinangalan sa kanilang event (sa RiptOPL: `boot`, `cancel`, `confirm`, `cursor`, `message`, `transition`, `bd_connect`, `bd_disconnect`, at sa RIPPS2: `page_in`, `page_out`, `error`, `save`, `launch`, `disc`, `random`), at musika bilang anumang `.ogg` (Ogg Vorbis na walang tag), 16-bit na `.wav`, o (mula build 115) `.mp3`: itinatakda ng `bgm_01 Title.ogg` at `bgm_02 Title.ogg` ang pagkakasunod at pamagat, at mula build 105 nakalista nang ganoon din ang anumang ibang pangalan, kaya hindi kailangang palitan ang pangalan ng track na na-rip mula sa CD. Pinipili ng Settings > Audio > Music ang track. Nagsusulat ang RIPPS2 ng `README.txt` sa AUDIO (at MEDIA) na nagsasabi ng lahat ng ito. Ginagawa ng **[RIPPS2 Media Studio](tools/media-studio)** ang lahat ng ito sa PC mo (at kino-convert ang mga video mo sa AVI na pinapatugtog ng Memory Files): pumunta sa anumang tunog o kanta, pakinggan ito nang orihinal at kung paano ito patutugtugin ng PS2, i-convert ito (o ang buong folder) sa `output/AUDIO`, at kopyahin ang folder na iyon sa tabi ng `RIPPS2.elf` gamit ang USB stick at ang Memory Files sa RIPPS2. Ituro ito sa BIOS dump mula sa sarili mong PS2 at gagawin nito mula roon ang mga tunog ng menu at system music ng console, handa nang gamitin. (Ginagawa pa rin ng `elf/theme/tools/make_adp.py` at `make_sound_pack.py` ang pareho mula sa command line.) Walang kasamang tunog o musika ang RIPPS2: mula build 95 wala nang laman ito, kaya kung walang `AUDIO` folder ay tahimik ito, at sinasabi ng **STATUS > SOUNDS** kung ano ang natagpuan nito.

**Saan ilalagay ang AUDIO at MEDIA.** Ilagay ang `AUDIO` sa tabi ng `RIPPS2.elf`, sa drive kung saan nagbo-boot ang RIPPS2: ito ang unang binabasa ng boot, at kapag naka-on ang **Fast Boot** (Settings > Game Sources > Cache) binabasa ang boot sound kasama ng mga setting, bago magsimula ang mga drive at listahan, kaya tumutugtog na ito pagsulpot ng unang frame ng mga tore (mula build 118). RIPPS2 sa memory card at `AUDIO` sa isang drive: pagkatapos ng **BIOS Sounds > Rip**, kinokopya lang ng START ang `boot.adp` (mga 360 KB) sa tabi ng RIPPS2 sa card, para tumunog ang boot sound habang umaangat ang mga haligi at hindi kapag handa na ang drive (mula build 121). Doon ilagay lang ang pinapatugtog ng mga menu. Ang `MEDIA` (mga na-rip na CD at DVD video, mga kuha sa buong laki) ay para sa pinakamalaki mong drive: walang binabasa roon sa boot, kaya hindi gaanong mahalaga ang bilis ng pagbasa ng drive na iyon.

<a id="covers-from-one-file-art-pack"></a>

## Mga cover mula sa iisang file (ART Pack)

Mula build 118, iniimpake ng **Settings > Game Sources > Cache > ART Pack** ang `ART` folder ng bawat nasimulang drive sa iisang `art.tar` sa `ART` folder ng drive na pipiliin mo. Sinusukat ng RIPPS2 kung gaano kabilis binabasa ng bawat drive ang sarili nitong mga larawan at inililista muna ang pinakamabilis para makuha ito ng X (halimbawa ang SD card sa SD2PSX). Pumapasok ang mga larawan nang ganoon (naka-compress na ang PNG at JPG: pinagtatabi lang sila ng tar, at binubuksan ito ng PC gaya ng anumang tar), at hindi ginagalaw ang mga `ART` folder. Mula noon nilo-load ang mga cover mula sa iisang file na iyon sa pamamagitan ng index (isinusulat kasama ng pack, kaya hindi na kailangang i-scan sa unang boot), at hindi kailanman tinatanong nang larawan por larawan ang `ART` folder ng larong ginawan ng pack, kahit ang nawawalang larawan: mas kaunting pagbasa sa drive na nagpapatugtog ng musika, at nakakasabay ang mga cover sa cursor. Agad lumalabas ang mga larawang dina-download o kinukuha ng RIPPS2 pagkatapos; ang kinopya mo sa PC ay lumalabas pagkatapos gawin muli ang pack. Maaari mong kopyahin ang `art.tar` sa `ART` folder ng ibang drive gamit ang Memory Files, pero gawin ito sa drive na ginagamit mo sa pagba-browse. Binubura ng parehong button ang pack.

**Pagsamahin ang isang `.tar` sa isa pa** (build 123). I-impake nang isang beses ang malaking drive bilang master, saka sa susunod ang mga larawan lang ng mga bagong laro at isama ang maliit na `.tar` na iyon, sa halip na i-impake muli ang bawat ART folder. Sa Memory Files, Triangle sa isang `.tar` > **MERGE A .TAR INTO THIS**: ang `.tar` na iyon ang itinatabi, at inililista ng RIPPS2 ang iba pang maisasama (sa parehong folder, sa ART folder ng bawat nasimulang drive at sa root nito). Inaalok din ng Cache > ART Pack ang pareho para sa pack na ginagamit, at agad pagkagawa ng pack. Ang larawang nasa pareho ay kinukuha mula sa idinagdag na `.tar`, at nagiging isa ang dalawang listahan ng laro. Isinusulat ang pinagsama sa tabi ng itinatabing `.tar` at kinukuha lang ang pangalan nito kapag nasa drive na ang bawat byte, kaya iniiwan ng paghinto, punong drive, o hinugot na card ang itinatabi gaya ng dati. Sa dulo, binabanggit ng isang dialog ang dalawang pangalan ng file at nagtatanong kung buburahin ang idinagdag (binubura ng START, itinatabi ng Back); hindi kailanman inaalok ang itinatabi.

<a id="your-hardware"></a>

## Ang hardware mo

- **Mga network adapter at internal HDD.** Sinisimulan ng RIPPS2 ang anumang network adapter gamit ang sariling DEV9 driver ng PS2SDK, ang ginagamit ng mga loader ngayon, at kusang pinag-iiba ang dalawang uri: mga expansion-bay adapter ng fat console (SCPH-10281, SCPH-10350, at mga IDE at SATA adapter na ginawa mula sa mga iyon) at ang built-in port ng slim, at ang PC CARD adapter ng mga unang console sa Japan (SCPH-10000 hanggang 18000). Walang lumang driver na pipiliin. Pareho ang pagbasa sa HDD APA man o exFAT, at may sariling driver ang HDPro adapter. Iisang adapter ang ginagamit ng mga SMB game, UDPBD, at pag-download ng art. Kung hindi lumalabas ang adapter mo, ipadala ang modelo ng adapter at ng console.
- **VMC (mga virtual memory card).** Binibigyan ito ng sariling mga setting ng laro (ang mga VMC row nito) ng card image sa `VMC` folder ng drive ng laro, sa slot 1 o 2. Sa OPL core gumagana sila sa USB, MX4SIO, iLink, HDD na may exFAT, APA HDD, SMB, at MMCE; sa FAT32 o exFAT drive kailangang iisang tuloy-tuloy na file ang card, ganoon ginagawa ng RIPPS2 ang mga bagong card, at inaayos ng **Rebuild** ang mas lumang card na hindi ganoon. Sa Neutrino gumagana sila sa USB, MX4SIO, iLink, at HDD na may exFAT, pero hindi sa APA HDD, kung saan ginagamit ng laro ang tunay na card sa slot na iyon. Kaya rin ng SD2PSX na bigyan ang bawat laro ng sarili nitong card (GameID sa mga setting nito), walang VMC.
- **Neutrino.** Ginagamit ng RIPPS2 ang sarili mong Neutrino, anumang bersyon (mula build 135 wala na itong dala, at sinasabi ng larong walang mahanap kung saan ito ilalagay): ilagay ang `neutrino` folder nito sa drive ng laro o sa memory card, o ibigay ang path nito sa Settings > Game Launching > Neutrino Defaults, at ipinapadala lang ng RIPPS2 ang mga opsyong alam ng bersyong iyon. Mula 1.1.5, kapag nagsimula ang RIPPS2 mula sa USB drive at nasa exFAT internal HDD ang laro, tama na ang drive number na ibinibigay dito (ang kombinasyong ito dati ay nagsasara ng Neutrino at nagre-reboot ng console).
- **Mga USB pad na hindi kilala ng RIPPS2** (build 129). **Settings > Controllers > Set Up A USB Pad**: isaksak ang pad, pindutin ang bawat button na hinihingi ng RIPPS2, at isinusulat nito ang `.pad` profile ng pad (`PADS/VVVV_PPPP.pad` sa tabi ng RIPPS2, plain text: [ang format](docs/plans/pad-spec.md)). Kayang patakbuhin ng pad na may profile ang menu at maglaro kapag naka-on ang Pad Emulator; pinagpapalit ng `PADS/GAMES/<game ID>.pad` ang mga button para sa isang laro. Sinusuri ng **My Pads** ang bawat profile at sinasabi kung ano ang mali sa tinanggihan nito.
- **Mga app gaya ng SMS.** Nagsisimula ang isang app mula sa sarili nitong path. Iyon lang ang binabasa ng SMS (Simple Media System), kaya hindi ito mabibigyan ng RIPPS2 ng file na patutugtugin; kung may bersyon ng SMS na tumatanggap ng file, ipapasa ito ng RIPPS2.

<a id="how-it-is-built"></a>

## Paano ito binubuo

Kinukuha ng `elf/build.sh` ang RiptOPL sa commit na nakasaad sa `elf/RIPTOPL_REF`, inilalapat ang serye ng patch sa `elf/patches`, idinadagdag ang theme, mga font, at art ng RIPPS2 mula sa `elf/theme`, at binubuo ang `RIPPS2.elf`. Pinapatakbo ito ng GitHub Actions sa bawat push ("Build RIPPS2.elf"); ang ELF na artifact nito ang release.

<a id="the-web-version"></a>

## Ang bersyon sa web

Nagsimula ang RIPPS2 bilang isang web theme, at narito pa rin ang bersyong iyon: **live demo** sa https://akilluminati47.github.io/RIPPS2/

| Opsyon | Ano ang binubuksan nito |
| --- | --- |
| **Launch Disc** | Ang mga haligi, na may dobleng pagsabog sa gitna ng field |
| **Storage** | Ang estante ng duwende, sa harap ng mga haligi |
| **Memory Files** | Ang mga bola |

Gumagalaw ang PS2 mark sa ilalim ng napiling opsyon at lumilipad sa pagitan nila: isang ikot papunta sa katabi, at mas malalim na sisid na parang hagis ng barya kapag pumupunta mula dulo hanggang dulo. Sinusunod ng mga label ang wika ng system ng bisita (18 wika, napapalitan gamit ang `?lang=fr` at iba pa). Anumang hindi maiguhit ng font ng menu ay lumilipat sa malinis na sans font nang buong salita.

**Ang estante ng duwende:** ang display case ng Storage. Ang tablang kahoy ng uOPL sa harap ng mga tore, at sa ibabaw nito ang RIPPS2 mark nang sampung beses: ang felt na sumbrero ng patay na duwende, nakataob ang gilid sa sarili nitong lawa ng dugo, isa para sa bawat Color Theme (RIPPS2, Ember, Blood, Ectoplasm, Amethyst, Bone, Tangerine, Flamingo, Turquoise, Moonlight). Tatlo ang nakikita nang sabay, gaya ng pagpapakita ng RIPFLOW ng mga cover: umiikot ang gitnang sumbrero para tumingin sa cursor (mas malapit, mas mabilis umikot) at umiindayog sa spring nito, at pinaiikot ng Left / Right o pag-tap sa katabi ang estante. Humihinto ito sa asul na sumbrero ng RIPPS2. Ipinapadala ng napindot na sumbrero ang Color Theme nito sa mga tore (ang sariling color matrix ng ELF, kaya mukhang gaya ng pagguhit ng theme na iyon ang mga tore): ang tap ay isang bugso ng kulay na tumatawid sa field at bumabalik sa asul ng RIPPS2; kapag pinindot nang matagal, nananatili ang theme sa buong larawan hanggang bitawan mo.

**Mga teleponong hawak nang patayo** (`letterbox.js`): tumatakbo ang site sa letterboxed player sa itaas ng screen, sa itaas nito ay ang camera notch at kurbadong sulok lang, nakaayos na parang landscape screen at pinaliit para magkasya. Sa ilalim ay may arrow na nakaturo pataas sa player, isang kumikinang na paalala na mag-pinch para mag-zoom o iikot ang telepono, at isang button na nagpapalit sa pagitan ng 16:9 at 4:3 na frame (natatandaan); nakasulat sa footnote sa kanang ibabang sulok ang RIPPS2 (vision interactive mock-up). Ibinabalik ng pag-ikot ng telepono ang buong pahina, sa pahinang ipinapakita ng player. Ipinapakita ng `?letterbox=1` ang player sa desktop.

**Ang mga haligi:** mga salaming tore ng data na may kumikinang na gilid, dugtungan, kumikislap na cell, at pulso ng enerhiya, sa sahig na sumasalamin. Umaangat mula sa lupa ang mga tore sa pag-load, saka humihinga at umaalon; nagpapadala ng alon ang cursor at nagdudulot ng pagsabog ang click. Inaangkop nito ang resolution sa mabagal na device, humihinto kapag nasa labas ng screen, at iginagalang ang setting na bawasan ang galaw.

**Ang mga bola:** labindalawang formation (Browser Orbit, Borromean Rings, Torus Orbit, Icosahedron, Double Helix, Strange Attractor, Trefoil Knot, Mobius Strip, Klein Bottle, Golden Spiral, Lissajous, at Seven-Point Star), bawat isa ay may kasing-daming bola na kailangan nito, naghihiwalay at nagsasama sa pagitan nila. Gaya ng Memory Files sa ELF, iginuguhit sa liwanag ang landas ng bawat hugis kapag bumukas ang tab at tuwing pumupuwesto ang isang formation, nananatili nang mga dalawang segundo at naglalaho. Pindutin nang matagal ang eksena (o pindutin nang matagal ang `L`, o ang L2 o Cross ng pad) para makita ang buong landas nang nakatigil; i-drag habang pinipindot para paikutin ang formation, na dumudulas hanggang huminto pagbitaw (pinaiikot din ito ng kanang stick ng pad). Palitan sa pag-swipe, sa mga icon na Left / Right sa tabi ng pangalan, sa mga arrow key, o sa mga direction o shoulder button ng pad.

Para patakbuhin nang lokal, i-serve ang folder gamit ang server (kailangan ng web server ang mga ES module) at buksan ang http://localhost:8000:

```bash
python -m http.server 8000
```

Idagdag ang `?t=12` para laktawan ang intro ng mga haligi, o `?f=3#memory-files` para magbukas ng partikular na formation (umaabot sa Memory Files ang mga lumang link na `orbs.html`).

- [PS2BBL](https://github.com/israpps/PlayStation2-Basic-BootLoader) ni El Isra (israpps) at [PS2BBL Extended](https://github.com/saildot4k/PlayStation2-Basic-BootLoader-Extended) ni saildot4k: ine-edit ng BOOT LOCK ang config nila para patakbuhin ng console ang RIPPS2 (mula build 116 pati ang config ng FreeMcBoot at OSDMenu). Mula sa build 134, dala ng RIPPS2.elf ang [BIBLE](https://github.com/akilluminati47/BIBLE), ang aming bersyon ng PS2BBL na pinirmahan para sa RIPPS2, para i-install ng **Boot Loader > Manage** (ang mga build 69 hanggang 133 ay may PS2BBL 1.2.0 ni El Isra). Nasa [`elf/bible`](elf/bible/README.md) ang GPL-3.0 na lisensya at source nito; gumagamit ang pag-bind sa card ng bukas na SECRMAN ng ps2sdk (AFL), walang susi.
- **Mga MMCE card**: ang [sd2psXtd](https://sd2psxtd.github.io/) firmware sa SD2PSX, gaya ng [SD2PSXTD](https://github.com/LinkRetro/SD2PSXTD-Hardware) card, binabasa sa pamamagitan ng [mmceman](https://github.com/ps2-mmce/mmceman) (ps2-mmce): mga laro, VMC, at setting sa SD ng card. **Panatilihing bago ang firmware** ([sd2psxtd.github.io/download](https://sd2psxtd.github.io/download)). Kailangan ng sd2psXtd 1.4.0 o mas bago para mag-compress ng laro sa card (inilalagay nito ang tapos na image sa puwesto sa pamamagitan ng pagpapalit ng pangalan); nagtatanong muna ang RIPPS2 sa card, kaya sa mas lumang firmware malalaman mo bago magsimula ang anuman, at hindi ka makakapag-compress doon. Hindi kayang iulat ng card ang libre nitong espasyo, kaya kahit sa 1.4.0 walang pagsusuri ng espasyo bago mag-compress: mag-iwan ng puwang para magkatabi ang laro at ang ZSO nito (kung mapuno ang card, humihinto ang trabaho at binubura ang naisulat nito).
- [wLaunchELF](https://github.com/ps2homebrew/wLaunchELF) ng koponan ng ps2homebrew, at wLaunchELF R3Z ni NathanNeurotic: mga modelo ng gawi para sa Memory Files browser at sa settings grid nito.
- [Apollo Save Tool](https://github.com/bucanero/apollo-ps2) ni bucanero: modelo para sa mga save tool (PSU, card image). Sariling code ng RIPPS2 ito, isinulat mula sa mga format.
- [ps2sdk](https://github.com/ps2dev/ps2sdk) ng koponan ng ps2dev: ang file system ng memory card (mcman) at ang USB keyboard driver.
- mymc ni Ross Ridge at [mymcplus](https://github.com/thestr4ng3r/mymcplus) ni Florian Maerkl: sinusuri gamit ang mga ito ang pagsulat ng card image ng RIPPS2.
- [minimp3](https://github.com/lieff/minimp3) ni lieff (CC0 1.0, public domain): pagpapatugtog ng MP3 sa Memory Files at AUDIO, mula build 115, walang binago sa `thirdparty/minimp3` ng RiptOPL.
- Planet N Compact ng [Iconian Fonts](https://www.iconian.com) (`assets/master.ttf`), at Planet N Condensed (`elf/theme/fonts/ripps2_condensed.ttf`, mula build 115 built in bilang `builtin:ripps2condensed`, ang font ng mga listahan ng Adapt). Iginuhit para sa RIPPS2 ang [RIPPS2 Sleek](https://github.com/akilluminati47/RIPPS2-fonts) (Regular, Bold, Bold Case); nasa sarili nitong repo ang mga font bilang TTF at WOFF2 sa ilalim ng OFL.
- Ang bersyon sa web: [three.js](https://threejs.org) r160, MIT (tingnan ang `vendor/LICENSE`); [Albert Sans](https://github.com/usted/Albert-Sans), SIL Open Font License (tingnan ang `vendor/fonts/OFL.txt`).
- Nakatayo ang estante ng duwende ng web mock-up (Storage, [akilluminati47.github.io/RIPPS2](https://akilluminati47.github.io/RIPPS2/)) sa tablang kahoy ng [uOPL](https://github.com/SlimPugGamer/uOPL) (`gfx/plank.png`, AFL-3.0).
- Orihinal ang RIPPS2 mark, ang patay na duwende na may asul na sumbrero: nirender sa three.js (MIT) mula sa `media/deadelf/scene.html` (bawat anggulo at kulay sa `media/deadelf`), na may vector na bersyon sa `assets/ripps2-deadelf.svg`.
- Ginawa ang build 83 reel at Short (sa YouTube) kasabay ng Details (x-Radar Portable, system music ng PSP, Sony), Slideshow (Daytime) ni Kazumi Totaka mula sa News Channel ng Wii (Nintendo, 2006), at ang sariling Menu theme ng PS2 (Sony); ang build 66 reel kasabay ng Slideshow (Daytime); orihinal ang musika ng build 55 reel.
