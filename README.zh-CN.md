# RIPPS2

> ### 开始提取：RIPPS2 构建 139，v1.3.9 测试版
> **RIP PS2，ELF 杀手。** 独立运行，从不破坏：你的其他 ELF 安然留在[架子](https://akilluminati47.github.io/RIPPS2/)上（除非你要求，否则什么都不会删除），只是得到它们应得的休息。
> 1. **[下载 RIPPS2.elf](https://github.com/akilluminati47/RIPPS2/releases/latest/download/RIPPS2.elf)**（始终是最新版本）（一个文件，2,764 KB），需要的话再下载 **[主题包](https://github.com/akilluminati47/RIPPS2-themes/releases/latest)**（Adapt 和 Adapt Rx，第 136 版：各一个配置和一张图片；RIPGRID 和 RIPFLOW 为内置），以及 **[RIPPS2-languages.zip](https://github.com/akilluminati47/RIPPS2/releases/latest/download/RIPPS2-languages.zip)**，用你的语言使用 RIPPS2（33 种语言；每个版本都附带）。
> 2. 把它复制到 U 盘或记忆卡，用 FreeMcBoot、PS2BBL、wLaunchELF 或你平时运行 homebrew 的工具启动。在 PCSX2 中：**System > Start File** 并选择 `RIPPS2.elf`。
> 3. 告诉我们效果如何：[psx-place 帖子](https://www.psx-place.com/threads/ripps2-a-ps2-front-end-in-one-elf-launch-disc-storage-memory-files.51316/)、[一个 issue](https://github.com/akilluminati47/RIPPS2/issues)，或开发者 Discord 的 **#RIPPS2**，[discord.gg/Z7m9u5kby](https://discord.gg/Z7m9u5kby)（邀请有效期至 2026 年 12 月 1 日）。
>

RIPPS2 是装在单个 `.elf` 中的 PS2 前端：把 [RiptOPL](https://github.com/NathanNeurotic/Open-PS2-Loader)（Open PS2 Loader 的分支）拆开重组，以 rickgaiser 的 [Neutrino](https://github.com/rickgaiser/neutrino) 作为第二个游戏核心，并拥有自己的外观、启动器、文件浏览器和存储工具。玻璃塔矗立在你的游戏后面，轨道阵列排列在你的文件后面，全部由 PS2 实时绘制。

- **LAUNCH DISC** 启动 PS2、PS1 和 DVD 视频光盘，在启动前告诉你光驱里是什么游戏，播放音乐 CD 时高塔会变成频谱分析仪。**RIPDISC**（构建 105）提取光驱中的光盘：游戏存到你的存储设备，CD 或 DVD 视频存到你的文件。
- **STORAGE** 是你的游戏库：所有驱动器在同一个列表中（All Games 从第一帧起就显示全部，包括尚未响应的驱动器），封面、图片淡入截图的信息页、每个游戏的独立设置，以及用 R3 把游戏加星到 Starred Games（星标位于行首；Settings > Game Sources > Starred Games Star 可移动或隐藏它；按住 R3 4.2 秒可隐藏或显示所有星标）。L2 + R2 跳到随机游戏，Recent Games 记住你最近的启动。在游戏上按三角打开 **Hide Game**、**Delete**（整个游戏：镜像的所有部分、它的 CFG、封面和金手指；存档仅在你要求时），**Set Metadata (Rename)**，对 ISO 或 ZSO 还有 **Compress to ZSO** 或 **Uncompress to ISO**（实验性：在 ZSO 被重新读取并校验之前 ISO 会保留）。每个驱动器的游戏立即从其上次的列表显示，然后重新读取该驱动器。
- **MEMORY FILES** 是内置文件浏览器：在记忆卡、USB、MMCE 和 HDD 之间复制、移动和删除（每次复制都会重新读取校验）；把 OPL 的 VMC 卡镜像当作文件夹打开；导出和导入 PSU 存档；编辑文本文件；打开图片，**全屏**播放 AVI 视频并带有**播放控制**（Cross 播放/暂停，Circle 停止，L1/R1 跳 10 秒，L2/R2 音量，START 循环；提示在播放时淡出，暂停时保留）（[RIPPS2 Media Studio](tools/media-studio) 能把任何视频，包括手机拍的 MP4，转换成这种文件），播放 `.mp3`、`.ogg` 和 `.wav` 文件，或标记多个一起打开，在 Launch Disc 的 CD 播放器中像一张光盘一样播放；**`.tar` 是一个蓝色文件夹**，你可以打开它、往里粘贴图片、把成员复制出来（构建 125）；在 `.tar` 上按三角可把另一个 ART 的 `.tar` 合并进来（[见下文](#covers-from-one-file-art-pack)）。**打开的文件夹是第一行**，显示项目数、已标记数、总大小和驱动器剩余空间；在它上面按 Cross 或 Square 标记全部（若已有标记则全部取消）。START 打开它的设置，其中的 **SEARCH FILES** 可在任何已启动的驱动器上按名称查找文件或文件夹并就地展开目录树。在记忆卡上按 Square 打开 **CARD MANAGER**（把卡备份为 VMC、把 VMC 的存档写入卡、清除游戏存档、格式化），在 APA HDD 上按 Square 打开 **HDD MANAGER**（它的分区、大小，以及在完整检查分区表后删除一个分区）。

从构建 100 起进入**测试版**：一百个 alpha 构建，由 ripto、nuno6573、zackcage6、eliminator1403、FifthFox 和 Mr.sus.60 在主机和 PCSX2 上测试，测试版阶段还有 lukeatmynose 和 ahavasi，以及所有在 Discord 上测试的人，特别感谢 YouTube 上的所有支持。把你常用的加载器留在手边，告诉我们哪里坏了：是反馈造就了 RIPPS2。**让 RIPPS2 更新的最好方式是 [GitHub 上的 issue](https://github.com/akilluminati47/RIPPS2/issues)**：DarkNerdShawny 提了三个，v1.1.7 的 FreeMcBoot 修复就来自其中之一。向 DarkNerdShawny 学习。

## 亮点

- **可以自定义的主题。** 每个游戏的图片上覆盖磨砂玻璃面板，一个用于封面的 **Grid** 元素，右摇杆倾斜可像一张纸一样移动整个画面，还有第一个主题包 **[RIPPS2-themes](https://github.com/akilluminati47/RIPPS2-themes)**：Adapt 和 Adapt Rx，每个配置都以所有键的词汇表开头，并为想做更多主题的人（或智能体）提供检查器和键参考。RIPGRID 和 RIPFLOW 为内置，为 Open PS2 Loader 制作的主题原样可用。在游戏列表中按住 **SELECT** 4.2 秒，你的主题会在一个可选择的面板中打开（Settings > Interface > Hold SELECT：List，Cycle 切换到下一个主题，或 Off）。在 RIPGRID 和 RIPFLOW 中，把右摇杆向一侧推 0.42 秒，选中的盒子会翻到背面封面，网格则一划翻页。
- **分类放在你想要的位置。** Settings > Interface > Layout > Category Layout：LAUNCH DISC、STORAGE 和 MEMORY FILES 以名称显示在 **Across the Top**，以图标显示在 **Sidebar**（Classic 或 XL；在列表中按 Left 或 Circle 打开，每个分类都有其页面的抽屉），或 **Menu**：没有栏，分类在 START 菜单中，和 OPL 主题一样。选 Theme 时由主题决定：为 OPL 制作的主题得到 Menu，Adapt 得到侧边栏。
- **RIPFLOW**，内置的封面轮播（RIPGRID 也是内置的），以及游戏启动时的光盘（Layout > Launch Disc）：**Pop In**、**Spin**，或 **Zoom**，把光盘放大到可以看清并保持住（RIPFLOW 和 Adapt 的默认），或 Off。**Hints and Glyphs** (Interface)：自由布局和排序提示、徽章以及四套图标（主题的、RIPPS2 的、Standard 和 White）。**Colors and Text** (Interface)：十种 Color Themes（RIPPS2、Ember、Blood、Ectoplasm、Amethyst、Bone、Tangerine、Flamingo、Turquoise、Moonlight）或 Custom，一个在五种颜色间循环的 **Color Sweep**（Rainbow、由每个 Color Theme 生成的，或最多四种你自己的颜色），以及 Text Weight。Layout 中有会淡出的提示和分类栏，以及在画面中央放大出现的来源名称。主题可以自行选择以上全部，而你的设置永远优先。
- **需要的已附带；你有的会被找到。** BIBLE 在同一个 `.elf` 里，可安装到你想要的位置；你自己的 [Neutrino](https://github.com/rickgaiser/neutrino)、POPSTARTER、POPS 文件和你自己的 Ember 会在驱动器上搜索一次、记住，并从原位置运行。START 菜单中的 **STATUS** 显示所有驱动器、每个启动器在哪里找到（LOOK FOR THEM 重新搜索）、homebrew、BIBLE 和你的声音，**SAVE DIAGNOSTICS** 会写出 `DIAG.TXT` 用于错误报告。
- **快速启动。** Settings > Game Sources > Cache > **Fast Boot** 开机时只读取 RIPPS2 自己所在的驱动器：`RIPPS2.ELF` 旁边的设置和声音，每个列表则从缓存读取。其他驱动器会等到你在它们的页面上按 SELECT 或选择它们的某个游戏。在 RIPPS2 读写时选择的游戏，会在一个显示剩余工作的面板后面等待（START NOW 立即启动），因此启动永远不会把写入中途打断。
- **设置保存在你想要的位置**：Settings > General & System > Save Settings To 可把它们保存在记忆卡上的 RIPPS2 存档、内置 HDD 上的 RIPPS2 文件夹（exFAT，或 APA HDD 的 OPL 分区）、USB、MX4SIO、iLink 或 MMCE 驱动器上（开机时最先读取），或你输入的文件夹中。
- **画面放在电视需要的位置。** Settings > Interface > Screen：Video Mode（最高 720p 和 1080i）、Widescreen，以及 H-POS、V-POS 和 Overscan，从构建 124 起按视频模式分别保存，所以 1080i 和 480i 各有自己的居中。
- **BIBLE 和 BOOT LOCK。** Settings > General & System > Boot Loader > **Manage** 把 akilluminati47 的引导程序 **BIBLE**（PS2BBL Extended 的分支，每个版本都由 akilluminati47 签名）安装到记忆卡、SD2PSX 或 MMCE 的 BOOT 卡或硬盘上，更新旧版，并在它自己的菜单里设置 BIBLE 的背景、启动画面和视频模式。**Boot Lock** 设置你主机实际运行的引导程序去运行 RIPPS2：PS2BBL 和 FreeMcBoot 会立即运行它，OSDMenu 把它放在菜单首位，关闭则恢复原来的状态。
- **游戏内菜单**（Settings > Game Launching > In-Game Menu，默认开启）：L1+L2+R1+R2+SELECT+START 让游戏在自己的画面上静音暂停，下方显示 Resume、Exit Game、**Screenshot**（RIPSHOT，[见下文](#screenshots-in-game-ripshot)）、Achievements 和 Power Off（再按一次就地关闭 PS2）；RESUME 精确回到同一帧，Achievements 列出还剩哪些成就以及如何获得。**Exit Game 走主机自己的启动路径:** 当该页的 IGR Path 为空（默认）时，重置会进入浏览器，若已安装引导程序则运行它（FreeMcBoot、PS2BBL、OSDMenu 或 BIBLE），若 Boot Lock 开启则再次运行 RIPPS2，和主机开机时完全一样；都没有则进入 PS2 浏览器。从 v1.2.1 起永远不会黑屏：IGR Path 仅在重置能加载它（记忆卡或 FAT32 U 盘上的 ELF）且不是 RIPPS2 本身时才使用，被忽略时 STATUS 会告诉你。
- **Achievements** (SpiritofRA)：通过电脑上的 [xeRAbora](https://github.com/hacan359/xerabora) 客户端实现 RetroAchievements 遥测（固定为 [v0.1.0-alpha.18](https://github.com/hacan359/xerabora/releases/tag/v0.1.0-alpha.18)），被追踪游戏上的徽章、托盘中的光盘，以及 **YOUR ACCOUNT**：你检查过的每个游戏及已解锁的内容；当 xeRAbora 对网络开放时，还有 **LEFT TO HUNT**：每个未解锁的成就及获得方法。
- **Cover Art** (Settings > Network)：PS2 自己从 xlenore 在 GitHub 上的 ps2-covers 为每个没有封面的 PS2 游戏下载封面（需要网线和互联网）：选择 **HD**（280 × 400，在 HD 画面上更清晰）或 **Standard**（140 × 200，和 Open PS2 Loader 的封面一样），都是 8 位并带抖动；已有封面的游戏会保留原封面（构建 125）。**720p 和 1080i** 一次绘制完成：一个 640 像素宽、包含该模式所有行的帧，由主机自己的显示电路拉伸到屏幕上，因此每个动画都保持速度。**RIPFLOW 在 16:9 画面上显示五张封面**（720p、1080i 或开启 Widescreen），4:3 上显示三张，除非你选择数量，否则会自动展开（构建 125）。你的 **AUDIO** 文件夹在任何驱动器上都能找到，高塔和光球整夜以稳定的 60 fps 旋转。
- **安全护栏**：每个构建都要通过 RiptOPL 的主机检查和 RIPPS2 自己的检查，RIPPS2 文件中出现任何新警告都会使其失败。

## 用你的语言

从构建 104 起，RIPPS2 显示的每个词都已翻译，包括它自己的画面和提示，以及 Open PS2 Loader 的设置。每个版本都附带 **`RIPPS2-languages.zip`**：把其中的 `LNG` 文件夹复制到 U 盘根目录、HDD 的 OPL 分区或 MMCE 卡（或把里面的文件复制到 `mc0:/RIPPS2`），然后在 **Settings > Interface > Language** 中选择语言。33 种语言可完整阅读 RIPPS2，从法语、西班牙语、德语和葡萄牙语到俄语、希腊语、土耳其语、越南语、老挝语、中文、日语和韩语，阿拉伯语和波斯语则从右到左、字母相连；需要其他文字的语言，其字体放在包中旁边。修正和新语言请提交到 [`elf/lang`](elf/lang)（每种语言一个 `<Language>.yml`；`python3 elf/lang/ripps2lang.py check` 会检查它们）。

## 提取光盘

把光盘放进光驱并打开 **LAUNCH DISC**。几秒后，一个玻璃面板会提供 **RIPDISC**：按住 **SELECT** 直到圆环填满。下一步会告诉你光盘是什么、有多大、**大约需要多久**以及会存到哪里；确认后按 **START**。

- **PS2 游戏**会变成驱动器 DVD 或 CD 文件夹中的 ISO，出现在你的游戏列表里。超过 4 GB 且要存到 FAT32 驱动器的游戏，会改为以 Open PS2 Loader 方式的 1 GB 分块加 ul.cfg 保存；在 exFAT 驱动器（U 盘、MX4SIO、iLink 或内置 HDD）上则保持为单个 ISO。开始提取前会检查驱动器的空间。
- **PS1 游戏**会变成 `EMBER/games/<Title>/` 中的 BIN 和 CUE，可用 Ember 游玩。
- **音乐 CD 或 DVD 视频**会存到你的文件：Memory Files 在 **MEDIA**（AUDIO 旁边）打开，光盘以 **RIPPED** 的身份在剪贴板中；在任何文件夹中 PASTE 就会提取到那里。CD 以 WAV 形式得到（复制一个到 AUDIO，它就会加入菜单音乐），你自制的 DVD 以 VIDEO_TS 文件得到。购买的电影有复制保护，光驱无法读取。

PS2 上的 USB 很慢（USB 1.1，约每秒 1 MB）：一整张 DVD 存到 U 盘要一个多小时，存到 exFAT 内置 HDD 则只需其几分之一。预估时间会从你的第一次提取中学习主机的速度。

## 你自己的声音和音乐

在 `RIPPS2.elf` 旁边放一个 `AUDIO` 文件夹。它接受以事件命名的 `.adp` 音效文件（RiptOPL 的：`boot`、`cancel`、`confirm`、`cursor`、`message`、`transition`、`bd_connect`、`bd_disconnect`，以及 RIPPS2 的：`page_in`、`page_out`、`error`、`save`、`launch`、`disc`、`random`），音乐则接受任何 `.ogg`（无标签的 Ogg Vorbis）、16 位 `.wav` 或（从构建 115 起）`.mp3`：`bgm_01 Title.ogg` 和 `bgm_02 Title.ogg` 决定顺序和标题，从构建 105 起其他名称也会按原样列出，所以从 CD 提取的曲目无需改名。Settings > Audio > Music 选择曲目。RIPPS2 会在 AUDIO（和 MEDIA）中写一个说明这一切的 `README.txt`。**[RIPPS2 Media Studio](tools/media-studio)** 在你的电脑上完成全部工作（并把你的视频转换成 Memory Files 能播放的 AVI）：跳到任何声音或歌曲，听它原本的样子和 PS2 将播放的样子，把它（或整个文件夹）转换到 `output/AUDIO`，再用 U 盘和 RIPPS2 的 Memory Files 把该文件夹复制到 `RIPPS2.elf` 旁边。把它指向你自己 PS2 的 BIOS 转储，它就会从中生成主机的菜单音效和系统音乐，可直接使用。（`elf/theme/tools/make_adp.py` 和 `make_sound_pack.py` 仍可在命令行中完成同样的工作。）RIPPS2 不附带任何声音或音乐：从构建 95 起里面什么都没有，所以没有 `AUDIO` 文件夹时它是静音的，**STATUS > SOUNDS** 会告诉你它找到了什么。

**AUDIO 和 MEDIA 放在哪里。** 把 `AUDIO` 放在 `RIPPS2.elf` 旁边，即 RIPPS2 启动所在的驱动器上：启动时最先读取它，开启 **Fast Boot** (Settings > Game Sources > Cache) 时，开机声会和设置一起在驱动器和列表启动前读取，所以高塔第一帧出现时它已在播放（从构建 118 起）。RIPPS2 在记忆卡上而 `AUDIO` 在某个驱动器上：执行 **BIOS Sounds > Rip** 后，START 只把 `boot.adp`（约 360 KB）复制到卡上 RIPPS2 旁边，这样开机声会在柱子升起时响起，而不是等驱动器就绪（从构建 121 起）。那里只放菜单会播放的东西。`MEDIA`（提取的 CD 和 DVD 视频、原尺寸截图）适合放在你最大的驱动器上：启动时不读取其中任何内容，因此该驱动器的读取速度无关紧要。

<a id="covers-from-one-file-art-pack"></a>

## 一个文件提供所有封面（ART Pack）

从构建 118 起，**Settings > Game Sources > Cache > ART Pack** 会把每个已启动驱动器的 `ART` 文件夹打包成你所选驱动器 `ART` 文件夹中的单个 `art.tar`。RIPPS2 会测量每个驱动器读取自己图片的速度，并把最快的放在最前面，让 X 直接选中（例如 SD2PSX 中的 SD 卡）。图片原样放入（PNG 和 JPG 已经压缩过：tar 只是把它们并排放，电脑可以像打开任何 tar 一样打开它），`ART` 文件夹保持不动。此后封面通过索引从那一个文件加载（索引与包一起写入，所以第一次启动无需扫描），并且永远不会逐张图片地查询为其打包的游戏的 `ART` 文件夹，即使是缺失的图片：正在播放音乐的驱动器读取更少，封面能跟上光标。RIPPS2 之后下载或拍摄的图片会立即显示；你在电脑上复制的图片在重新打包后显示。你可以用 Memory Files 把 `art.tar` 复制到另一个驱动器的 `ART` 文件夹，但最好在你浏览所用的驱动器上打包。同一个按钮可删除该包。

**把一个 `.tar` 合并到另一个**（构建 123）。先把一个大驱动器打包一次作为主包，之后只打包新游戏的图片，再把那个小 `.tar` 合并进去，而不必重新打包所有 ART 文件夹。在 Memory Files 中，在 `.tar` 上按三角 > **MERGE A .TAR INTO THIS**：这个 `.tar` 就是要保留的那个，RIPPS2 会列出其他可合并的（同一文件夹中、每个已启动驱动器的 ART 文件夹及其根目录中）。Cache > ART Pack 也会为正在使用的包，以及刚打包完时，提供同样的选项。两边都有的图片取自新加入的 `.tar`，两个游戏列表合而为一。合并结果写在保留的 `.tar` 旁边，只有在每个字节都写入驱动器后才会取用它的名字，所以中途停止、驱动器写满或卡被拔出，保留的那个都保持原样。最后会弹出对话框，写明两个文件名并询问是否删除新加入的那个（START 删除，Back 保留）；保留的那个永远不会被提议删除。

<a id="your-hardware"></a>

## 你的硬件

- **网络适配器和内置 HDD。** RIPPS2 用 PS2SDK 自己的 DEV9 驱动，也就是如今加载器所用的那个，启动任何网络适配器，并自行区分两种类型：胖机扩展槽的适配器（SCPH-10281、SCPH-10350，以及由它们改造的 IDE 和 SATA 适配器）和薄机的内置端口，以及早期日版主机（SCPH-10000 到 18000）的 PC CARD 适配器。没有旧驱动需要选择。HDD 无论是 APA 还是 exFAT 都同样读取，HDPro 适配器则使用它自己的驱动。SMB 游戏、UDPBD 和图片下载都使用同一个适配器。如果你的适配器没有显示，请发送适配器和主机的型号。
- **VMC（虚拟记忆卡）。** 游戏自己的设置（它的 VMC 行）会给它一个位于游戏所在驱动器 `VMC` 文件夹中的卡镜像，放在插槽 1 或 2。在 OPL 核心下，它们适用于 USB、MX4SIO、iLink、exFAT HDD、APA HDD、SMB 和 MMCE；在 FAT32 或 exFAT 驱动器上，卡必须是一个连续的文件，RIPPS2 新建的卡就是这样，**Rebuild** 可修复不是这样的旧卡。在 Neutrino 下，它们适用于 USB、MX4SIO、iLink 和 exFAT HDD，但不适用于 APA HDD，在那里游戏会使用该插槽中的真实记忆卡。SD2PSX 也可以自己为每个游戏分配独立的卡（其设置中的 GameID），无需 VMC。
- **Neutrino。** RIPPS2 使用你自己的 Neutrino，无论什么版本（从构建 135 起不再附带，找不到时游戏会告诉你放在哪里）：把它的 `neutrino` 文件夹放在游戏所在驱动器或记忆卡上，或在 Settings > Game Launching > Neutrino Defaults 中给出路径，RIPPS2 只会向它发送该版本认识的选项。从 1.1.5 起，当 RIPPS2 从 USB 驱动器启动而游戏在 exFAT 内置 HDD 上时，会传给它正确的驱动器编号（这种组合曾导致 Neutrino 关闭、主机重启）。
- **RIPPS2 不认识的 USB 手柄**（构建 129）。**Settings > Controllers > Set Up A USB Pad**：插上手柄，按下 RIPPS2 要求的每个按钮，它就会写出该手柄的 `.pad` 配置文件（RIPPS2 旁边的 `PADS/VVVV_PPPP.pad`，纯文本：[格式](docs/plans/pad-spec.md)）。有配置文件的手柄可以操作菜单，开启 Pad Emulator 后可以玩游戏；`PADS/GAMES/<game ID>.pad` 可为单个游戏调换按钮。**My Pads** 会检查每个配置文件，并说明被拒绝的哪里有问题。
- **像 SMS 这样的应用。** 应用从它自己的路径启动。SMS (Simple Media System) 只读取这个路径，所以 RIPPS2 无法交给它一个文件去播放；如果某个版本的 SMS 接受文件，RIPPS2 会把文件传过去。

<a id="how-it-is-built"></a>

## 如何构建

`elf/build.sh` 获取 `elf/RIPTOPL_REF` 中指定提交的 RiptOPL，应用 `elf/patches` 中的补丁系列，加入 `elf/theme` 中 RIPPS2 的主题、字体和图片，并构建 `RIPPS2.elf`。GitHub Actions 在每次推送时运行它（"Build RIPPS2.elf"）；其产物 ELF 就是发布版。

<a id="the-web-version"></a>

## 网页版

RIPPS2 最初是一个网页主题，那个版本至今仍在这里：**在线演示** https://akilluminati47.github.io/RIPPS2/

| 选项 | 打开什么 |
| --- | --- |
| **Launch Disc** | 柱子，场地中央伴有双重爆发 |
| **Storage** | 柱子前面的精灵架 |
| **Memory Files** | 光球 |

PS2 标志在所选项目下方移动，并在项目之间飞行：到相邻项目转一圈，从一端到另一端则是更深的抛硬币式俯冲。标签跟随访客的系统语言（18 种语言，可用 `?lang=fr` 等切换）。菜单字体无法绘制的内容会以整个单词为单位改用干净的无衬线字体。

**精灵架:** Storage 的展示架。高塔前面的一块 uOPL 木板，上面有十个 RIPPS2 标志：一顶死去精灵的毡帽，帽檐朝下立在自己的血泊中，每个 Color Theme 一顶（RIPPS2、Ember、Blood、Ectoplasm、Amethyst、Bone、Tangerine、Flamingo、Turquoise、Moonlight）。一次可见三顶，就像 RIPFLOW 展示封面一样：中间的帽子转向光标（越近转得越快）并在弹簧上摇摆，Left / Right 或点按相邻的帽子会转动架子。它停在蓝色的 RIPPS2 帽子上。按下的帽子会把自己的 Color Theme 送到高塔上（使用 ELF 自己的颜色矩阵，所以高塔看起来和该主题绘制的一样）：点按是一道穿过场地的色彩喷发，然后回到 RIPPS2 蓝；按住则主题会覆盖整个画面直到你松开。

**竖握的手机** (`letterbox.js`)：网站在屏幕顶部的信箱式播放器中播放，上方只有摄像头凹口和圆角，像横屏一样排布并缩放以适应。下方有一个指向播放器的向上箭头、一条提示双指缩放或旋转手机的发光说明，以及一个在 16:9 和 4:3 画框之间切换的按钮（会被记住）；右下角的脚注写着 RIPPS2 (vision interactive mock-up)。旋转手机会回到完整页面，停在播放器所显示的页面。`?letterbox=1` 可在桌面上显示播放器。

**柱子:** 带有发光边缘、接缝、闪烁单元和能量脉冲的玻璃数据塔，立在反光的地面上。加载时高塔从地面升起，然后呼吸起伏；光标会推出波纹，点击会引发爆发。它会在慢速设备上调整分辨率，在屏幕外暂停，并遵守减少动态效果的设置。

**光球:** 十二种阵列（Browser Orbit、Borromean Rings、Torus Orbit、Icosahedron、Double Helix、Strange Attractor、Trefoil Knot、Mobius Strip、Klein Bottle、Golden Spiral、Lissajous 和 Seven-Point Star），每种使用所需数量的光球，在阵列之间分开又合拢。和 ELF 的 Memory Files 一样，标签打开时以及每次阵列就位时，每个形状的轨迹都会以光芒描绘出来，停留约两秒后淡出。按住场景（或按住 `L`，或手柄的 L2 或 Cross）可静止地看到整条轨迹；按住时拖动可旋转阵列，松开后滑行至停止（手柄的右摇杆也可旋转）。用滑动、名称旁的 Left / Right 图标、方向键，或手柄的方向键或肩键切换。

要在本地运行，请用服务器提供该文件夹（ES 模块需要网页服务器）并打开 http://localhost:8000:

```bash
python -m http.server 8000
```

添加 `?t=12` 可跳过柱子的开场，或用 `?f=3#memory-files` 打开特定阵列（旧的 `orbs.html` 链接会跳到 Memory Files）。
